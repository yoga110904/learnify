## AI itu menebak dengan hati-hati

Model klasifikasi tidak pernah benar-benar "tahu". Dia mengeluarkan **peluang**: 92% kucing, 8% anjing. Jadi kita perlu bahasa untuk bicara tentang ketidakpastian.

## Dasar probabilitas

Peluang selalu antara 0 dan 1, dan total seluruh kemungkinan = 1.

```python
import numpy as np
peluang = np.array([0.7, 0.2, 0.1])
peluang.sum()          # 1.0
peluang.argmax()       # 0 -> kelas dengan peluang tertinggi
```

Aturan dasar:

| Aturan | Rumus | Kapan dipakai |
|---|---|---|
| Komplemen | P(bukan A) = 1 − P(A) | "berapa peluang gagal?" |
| Gabungan (saling lepas) | P(A atau B) = P(A) + P(B) | dua hal tak bisa bersamaan |
| Irisan (independen) | P(A dan B) = P(A) × P(B) | dua hal tak saling mempengaruhi |

## Probabilitas bersyarat

Notasi **P(A|B)** dibaca "peluang A **jika diketahui** B sudah terjadi".

Contoh: peluang seseorang sakit itu 1%. Tapi kalau diketahui hasil tesnya positif, peluangnya berubah. Itulah inti dari belajar dari data — mengubah keyakinan setelah melihat bukti.

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

## Teorema Bayes

$$P(A|B) = \frac{P(B|A) \times P(A)}{P(B)}$$

Bacanya:

- **P(A)** — *prior*: keyakinan awal sebelum lihat bukti
- **P(B|A)** — *likelihood*: seberapa mungkin bukti ini muncul kalau A benar
- **P(A|B)** — *posterior*: keyakinan setelah lihat bukti

### Contoh klasik yang mengejutkan

Sebuah penyakit menyerang 1% populasi. Tesnya 90% akurat (positif benar 90%, positif palsu 10%). Kamu dites dan hasilnya **positif**. Berapa peluang kamu benar-benar sakit?

Kebanyakan orang menjawab 90%. Mari hitung:

```python
p_sakit = 0.01
p_positif_jika_sakit = 0.90
p_positif_jika_sehat = 0.10

# total peluang hasil positif
p_positif = (p_positif_jika_sakit * p_sakit +
             p_positif_jika_sehat * (1 - p_sakit))

p_sakit_jika_positif = p_positif_jika_sakit * p_sakit / p_positif
print(round(p_sakit_jika_positif, 3))    # 0.083
```

Cuma **8,3%**. Kenapa? Karena orang sehat jauh lebih banyak, jadi 10% positif palsu dari kelompok besar itu mengalahkan 90% positif benar dari kelompok kecil.

Pelajarannya untuk AI: **pada kelas yang langka, akurasi tinggi bisa sangat menyesatkan.** Ini alasan kita butuh precision dan recall, bukan cuma akurasi.

## Naive Bayes

Algoritma klasifikasi yang langsung menerapkan rumus ini. "Naive" karena dia menganggap semua fitur saling independen — asumsi yang hampir selalu salah, tapi hasilnya tetap bagus dan sangat cepat, terutama untuk klasifikasi teks (filter spam klasik memakai ini).

```python
# inti idenya:
# P(spam | kata-kata) ∝ P(spam) × P(kata1|spam) × P(kata2|spam) × ...
```

Karena mengalikan banyak angka kecil bisa membuat hasilnya jadi nol (*underflow*), implementasi nyata menjumlahkan logaritmanya:

```python
import numpy as np
np.log(0.001) + np.log(0.002)     # aman
0.001 * 0.002                      # makin kecil, makin berisiko
```

## Ekspektasi

Nilai rata-rata yang diharapkan dalam jangka panjang:

$$E[X] = \sum x_i \times P(x_i)$$

```python
hasil = np.array([0, 1, 2])
peluang = np.array([0.5, 0.3, 0.2])
(hasil * peluang).sum()      # 0.7
```

## Ringkasan

- Model klasifikasi menghasilkan peluang, bukan kepastian.
- P(A|B) adalah keyakinan tentang A setelah melihat bukti B.
- Teorema Bayes membalik arah: dari P(B|A) menjadi P(A|B).
- Pada kelas langka, akurasi tinggi bisa menipu — perhatikan positif palsu.

## Kesalahan umum

- Menyamakan P(positif|sakit) dengan P(sakit|positif).
- Mengabaikan prior saat kelasnya sangat tidak seimbang.
- Mengalikan banyak peluang kecil tanpa memakai logaritma.
