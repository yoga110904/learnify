## Menarik garis lewat data

Regresi linear mencari garis lurus yang paling pas menggambarkan hubungan fitur dengan target.

$$y = w_1x_1 + w_2x_2 + \dots + b$$

- `w` (*weight/koefisien*) — seberapa besar pengaruh tiap fitur
- `b` (*bias/intercept*) — nilai dasar saat semua fitur nol

Sederhana, cepat, dan **bisa dijelaskan** — itu alasan dia masih dipakai di perbankan dan kesehatan, tempat keputusan harus bisa dipertanggungjawabkan.

## Contoh lengkap

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# luas rumah (m²) -> harga (juta)
X = np.array([[50], [60], [70], [80], [90]])
y = np.array([500, 600, 700, 800, 900])

model = LinearRegression()
model.fit(X, y)

print(model.coef_)        # [10.]  -> tiap m² menambah 10 juta
print(model.intercept_)   # 0.0
print(model.predict([[75]]))   # [750.]
```

⚠️ `X` **harus 2 dimensi**, bahkan untuk satu fitur. Kalau `X` cuma 1 dimensi, scikit-learn menolak:

```python
X = np.array([50, 60, 70])
X.reshape(-1, 1)      # ✅ jadi (3, 1)
```

## Membaca koefisien

```python
X = np.array([[50, 1],     # [luas, jumlah_kamar]
              [60, 2],
              [70, 2],
              [80, 3]])
y = np.array([500, 640, 720, 850])

model = LinearRegression().fit(X, y)
for nama, w in zip(['luas', 'kamar'], model.coef_):
    print(f"{nama}: {w:.2f}")
```

Bacanya: *"tiap kenaikan 1 satuan fitur ini, target naik sebesar w — dengan asumsi fitur lain tetap."*

⚠️ Koefisien hanya bisa dibandingkan kalau skala fiturnya sama. Luas (puluhan) dan jumlah kamar (satuan) punya skala berbeda, jadi koefisien besar belum tentu berarti lebih penting. Standardisasi dulu kalau mau membandingkan.

## Mengukur kualitas

### MSE & RMSE

```python
from sklearn.metrics import mean_squared_error

pred = model.predict(X)
mse = mean_squared_error(y, pred)
rmse = mse ** 0.5
```

MSE merata-ratakan kuadrat kesalahan. Karena dikuadratkan, kesalahan besar dihukum lebih berat. RMSE mengembalikannya ke satuan asli — "rata-rata meleset 25 juta" jauh lebih mudah dipahami.

### MAE

```python
from sklearn.metrics import mean_absolute_error
mean_absolute_error(y, pred)
```

Rata-rata selisih mutlak. Lebih tahan outlier dibanding MSE.

### R²

```python
model.score(X, y)      # sama dengan r2_score(y, pred)
```

Berapa persen variasi target yang berhasil dijelaskan model:

| R² | Artinya |
|---|---|
| 1,0 | sempurna |
| 0,8 | menjelaskan 80% variasi |
| 0,0 | sama saja dengan menebak rata-rata |
| negatif | lebih buruk daripada menebak rata-rata |

## Kapan regresi linear gagal?

Kalau hubungannya tidak lurus. Regresi linear pada data melengkung akan menghasilkan R² rendah.

Solusinya bisa menambah fitur polinomial:

```python
from sklearn.preprocessing import PolynomialFeatures
X2 = PolynomialFeatures(degree=2).fit_transform(X)   # tambah x²
```

Atau ganti model ke yang memang bisa menangkap hubungan non-linear.

## Regularisasi

Kalau fiturnya banyak, model bisa menghafal data latih. Regularisasi menahan koefisien agar tidak liar:

```python
from sklearn.linear_model import Ridge, Lasso

Ridge(alpha=1.0)    # mengecilkan semua koefisien (L2)
Lasso(alpha=0.1)    # bisa membuat koefisien jadi 0 -> seleksi fitur (L1)
```

## Ringkasan

- Regresi linear mencari garis `y = wx + b` yang paling pas.
- `X` harus 2 dimensi; pakai `reshape(-1, 1)` untuk satu fitur.
- RMSE dalam satuan asli, R² dalam persentase variasi yang dijelaskan.
- Ridge dan Lasso menahan koefisien agar model tidak menghafal.

## Kesalahan umum

- Memberi `X` 1 dimensi ke `fit()`.
- Membandingkan koefisien fitur yang skalanya berbeda.
- Memaksa model linear pada hubungan yang jelas melengkung.
