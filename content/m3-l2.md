## Data yang bertahan setelah program ditutup

Variabel hilang begitu program selesai. Supaya data awet, simpan ke file.

## `with open(...)`

```python
with open("catatan.txt", "w") as f:
    f.write("baris pertama\n")
    f.write("baris kedua\n")

with open("catatan.txt", "r") as f:
    isi = f.read()
print(isi)
```

`with` otomatis menutup file walaupun terjadi error di tengah jalan. Selalu pakai `with`.

### Mode file

| Mode | Arti |
|---|---|
| `"r"` | baca (default). Error kalau file nggak ada |
| `"w"` | tulis — **menimpa** isi lama |
| `"a"` | append — menambah di akhir |
| `"x"` | buat baru, error kalau sudah ada |

⚠️ `"w"` menghapus isi lama tanpa nanya. Salah pilih mode = data hilang.

### Cara membaca

```python
with open("catatan.txt") as f:
    isi = f.read()          # seluruh file jadi satu string

with open("catatan.txt") as f:
    baris = f.readlines()   # list per baris (masih ada \n)

with open("catatan.txt") as f:
    for baris in f:         # ⭐ hemat memori untuk file besar
        print(baris.strip())
```

Untuk teks berbahasa Indonesia/emoji, tambahkan `encoding="utf-8"`:

```python
open("data.txt", "w", encoding="utf-8")
```

## CSV — tabel dalam bentuk teks

File `nilai.csv`:

```
nama,nilai
Budi,80
Ani,90
```

```python
import csv

with open("nilai.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["nama", "nilai"])
    w.writerow(["Budi", 80])

with open("nilai.csv") as f:
    for row in csv.DictReader(f):     # tiap baris jadi dict
        print(row["nama"], row["nilai"])
```

`csv.DictReader` memakai baris pertama sebagai nama kolom. Nilainya **selalu string** — konversi sendiri kalau butuh angka.

Kalau isinya sudah berupa string (bukan file), bisa dibaca lewat `io.StringIO`:

```python
import csv, io
for row in csv.DictReader(io.StringIO("nama,nilai\nBudi,80")):
    print(row)
```

## JSON — format standar API

```python
import json

data = {"nama": "Salsa", "skor": [80, 90]}

# objek Python  ->  file
with open("data.json", "w") as f:
    json.dump(data, f, indent=2)

# file  ->  objek Python
with open("data.json") as f:
    kembali = json.load(f)

# objek  <->  string (huruf s = string)
teks = json.dumps(data)       # '{"nama": "Salsa", ...}'
obj = json.loads(teks)        # kembali jadi dict
```

Hafal pola ini: **`dump`/`load` untuk file, `dumps`/`loads` untuk string.** Waktu tes API nanti, `json.loads` adalah teman harianmu.

## Ringkasan

- Selalu buka file dengan `with` supaya otomatis tertutup.
- Mode `"w"` menimpa, `"a"` menambah.
- `csv.DictReader` mengubah tiap baris jadi dict.
- `json.dump/load` untuk file, `json.dumps/loads` untuk string.

## Kesalahan umum

- Memakai `"w"` padahal maksudnya `"a"` → isi lama hilang.
- Lupa mengonversi nilai CSV dari string ke angka.
- Lupa `encoding="utf-8"` sehingga karakter non-ASCII rusak.
