## Kalau list itu absen, dictionary itu kamus

Di list kamu cari data pakai nomor urut. Di **dictionary** kamu cari pakai **kata kunci** — persis kamus: cari kata, dapat artinya.

```python
siswa = {
    "nama": "Salsa",
    "umur": 21,
    "aktif": True
}
print(siswa["nama"])    # Salsa
```

Formatnya `{kunci: nilai, ...}`. Kunci biasanya string, nilainya bebas.

Kenapa tidak pakai list saja?

```python
siswa = ["Salsa", 21, True]
print(siswa[1])        # 21 — tapi ini apa? umur? nilai? tahun?
print(siswa["umur"])   # 💥 list tidak bisa begini
```

Dict membuat data **menjelaskan dirinya sendiri**. Ini jadi sangat penting saat datanya punya 20 kolom.

## Menambah, mengubah, menghapus

```python
siswa["kota"] = "Bandung"     # tambah kunci baru
siswa["umur"] = 22            # ubah nilai kunci yang ada
del siswa["aktif"]            # hapus
nilai = siswa.pop("kota")     # ambil sekaligus hapus
nilai = siswa.pop("x", None)  # dengan default, aman kalau tidak ada
siswa.clear()                 # kosongkan
```

Perhatikan: menugaskan ke kunci yang sudah ada = **mengubah**, ke kunci baru = **menambah**. Tidak ada method `add` terpisah.

## `.get()` — akses yang tidak bikin crash

```python
print(siswa["email"])           # 💥 KeyError: 'email'
print(siswa.get("email"))       # None  — aman
print(siswa.get("email", "-"))  # "-"   — pakai default
```

Ini sangat penting waktu memproses data dari API: field-nya belum tentu selalu ada.

Kapan pakai yang mana?

| Situasi | Pilihan |
|---|---|
| Kunci **harus** ada, kalau tidak berarti bug | `d["kunci"]` |
| Kunci mungkin tidak ada, itu wajar | `d.get("kunci", default)` |

`setdefault` mengambil nilai **dan** menyisipkannya kalau belum ada:

```python
d = {}
d.setdefault("daftar", []).append("a")
print(d)     # {'daftar': ['a']}
```

## Looping dictionary

```python
d = {"a": 1, "b": 2}

for k in d:               # default: looping KUNCI
    print(k)              # a b

for k in d.keys():        # sama saja, lebih eksplisit
    print(k)

for v in d.values():
    print(v)              # 1 2

for k, v in d.items():    # ⭐ paling sering dipakai
    print(k, "=", v)      # a = 1 / b = 2
```

Sejak Python 3.7, dict **menjaga urutan penyisipan**. Jadi urutan looping-nya bisa diandalkan.

⚠️ Jangan menambah atau menghapus kunci sambil melakukan loop:

```python
for k in d:
    del d[k]     # 💥 RuntimeError: dictionary changed size during iteration
```

Buat salinan kuncinya dulu: `for k in list(d):`

## Pola menghitung frekuensi

Ini pola klasik yang muncul di mana-mana:

```python
kalimat = "aku dan kamu dan dia"
hitung = {}
for kata in kalimat.split():
    hitung[kata] = hitung.get(kata, 0) + 1
print(hitung)
# {'aku': 1, 'dan': 2, 'kamu': 1, 'dia': 1}
```

Bacanya: *ambil nilai lama (kalau belum ada anggap 0), tambah 1, simpan lagi.*

Python punya versi siap pakainya:

```python
from collections import Counter
print(Counter(kalimat.split()))
print(Counter(kalimat.split()).most_common(2))   # 2 kata tersering
```

## Menggabungkan dictionary

```python
a = {"x": 1, "y": 2}
b = {"y": 99, "z": 3}

print({**a, **b})     # {'x': 1, 'y': 99, 'z': 3}   yang kanan menang
print(a | b)          # sama (Python 3.9+)

a.update(b)           # mengubah a di tempat
```

Pola `{**default, **pengaturan_user}` sangat umum untuk menggabungkan konfigurasi.

## Method berguna lainnya

```python
d = {"a": 1, "b": 2}

print(list(d.keys()))      # ['a', 'b']
print(list(d.values()))    # [1, 2]
print(list(d.items()))     # [('a', 1), ('b', 2)]
print(len(d))              # 2
print("a" in d)            # True   -> mengecek KUNCI, bukan nilai
print(1 in d.values())     # True   -> baru mengecek nilai
```

Membalik dict (nilai jadi kunci):

```python
print({v: k for k, v in d.items()})    # {1: 'a', 2: 'b'}
```

Hanya aman kalau nilainya unik dan hashable.

## Aturan kunci

Kunci harus bertipe **immutable**: string, angka, atau tuple. List tidak bisa.

```python
{"a": 1}          # ✅
{(1, 2): "titik"} # ✅
{1: "satu"}       # ✅
{[1, 2]: "x"}     # 💥 TypeError: unhashable type: 'list'
```

Kunci juga **unik** — menulis kunci yang sama dua kali membuat yang terakhir menang:

```python
print({"a": 1, "a": 2})    # {'a': 2}
```

Dan hati-hati: `1`, `1.0`, dan `True` dianggap kunci yang sama karena nilainya setara.

## Ringkasan

- Dictionary menyimpan pasangan kunci–nilai; data jadi menjelaskan dirinya sendiri.
- `.get(kunci, default)` aman dari `KeyError`; `d[kunci]` dipakai kalau kunci wajib ada.
- `.items()` untuk looping kunci dan nilai sekaligus; dict menjaga urutan penyisipan.
- `{**a, **b}` menggabungkan dict, yang kanan menang.
- Kunci harus immutable dan unik.

## Kesalahan umum

- Mengakses kunci yang belum tentu ada dengan `d["x"]` → `KeyError`.
- Menambah/menghapus kunci sambil melakukan loop pada dict yang sama.
- Mengira `"a" in d` mengecek nilai (padahal mengecek kunci).
- Memakai list sebagai kunci.
