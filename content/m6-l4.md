## Meringkas array jadi angka

```python
import numpy as np
x = np.array([3, 1, 4, 1, 5])

x.sum()      # 14
x.mean()     # 2.8
x.min()      # 1
x.max()      # 5
x.std()      # 1.6
x.argmin()   # 1   -> INDEX nilai terkecil
x.argmax()   # 4   -> INDEX nilai terbesar
```

Bedakan baik-baik: `max` memberi **nilainya**, `argmax` memberi **posisinya**. `argmax` adalah cara model klasifikasi menentukan jawabannya:

```python
probabilitas = np.array([0.1, 0.7, 0.2])
kelas = probabilitas.argmax()     # 1 -> kelas dengan peluang tertinggi
```

## `axis` — arah perhitungan

Ini konsep yang paling sering bikin bingung, padahal cuma satu aturan:

> **`axis` adalah dimensi yang DILENYAPKAN.**

```python
x = np.array([[1, 2, 3],
              [4, 5, 6]])       # shape (2, 3)

x.sum()            # 21       semua dijumlah -> skalar
x.sum(axis=0)      # [5 7 9]  shape (3,) -> baris lenyap, sisa kolom
x.sum(axis=1)      # [6 15]   shape (2,) -> kolom lenyap, sisa baris
```

Cara mengingat untuk tabel data (baris = sampel, kolom = fitur):

| Perintah | Artinya |
|---|---|
| `axis=0` | hitung **turun ke bawah** → satu nilai per **kolom/fitur** |
| `axis=1` | hitung **ke samping** → satu nilai per **baris/sampel** |

Contoh nyata:

```python
nilai = np.array([[80, 90, 70],     # Budi
                  [60, 75, 85]])    # Ani

nilai.mean(axis=0)   # rata-rata TIAP MATA PELAJARAN
nilai.mean(axis=1)   # rata-rata TIAP SISWA
```

## `keepdims` — menjaga bentuk untuk broadcasting

```python
x = np.array([[1, 2, 3],
              [4, 5, 6]])

x.sum(axis=1)                  # shape (2,)   -> [6 15]
x.sum(axis=1, keepdims=True)   # shape (2, 1) -> [[6], [15]]
```

Kenapa penting? Karena yang bentuknya `(2, 1)` bisa langsung di-broadcast kembali ke `(2, 3)`:

```python
x / x.sum(axis=1, keepdims=True)    # tiap baris dibagi totalnya
```

Ini persis cara menghitung **softmax** di neural network nanti. Tanpa `keepdims`, kamu akan kena error broadcasting.

## Agregasi boolean

Karena `True` bernilai 1 dan `False` bernilai 0:

```python
x = np.array([10, 25, 5, 40])

(x > 20).sum()    # 2      berapa banyak yang lolos
(x > 20).mean()   # 0.5    berapa persen yang lolos
(x > 20).any()    # True   ada yang lolos?
(x > 20).all()    # False  semuanya lolos?
```

`(prediksi == label).mean()` adalah cara paling singkat menghitung **akurasi** model.

## Mengabaikan nilai kosong

Kalau data punya `NaN` (nilai hilang), agregasi biasa ikut jadi `NaN`:

```python
x = np.array([1, 2, np.nan])
x.mean()        # nan
np.nanmean(x)   # 1.5   -> versi yang mengabaikan NaN
```

Ada juga `np.nansum`, `np.nanmax`, dan `np.isnan(x)` untuk mendeteksinya.

## Ringkasan

- `sum/mean/std/min/max` meringkas array; `argmin/argmax` memberi posisinya.
- `axis` adalah dimensi yang dilenyapkan: `axis=0` per kolom, `axis=1` per baris.
- `keepdims=True` menjaga dimensi supaya bisa langsung di-broadcast.
- `(kondisi).sum()` menghitung jumlah, `(kondisi).mean()` menghitung proporsi.

## Kesalahan umum

- Tertukar `axis=0` dan `axis=1`.
- Tertukar `max` (nilai) dengan `argmax` (posisi).
- Lupa `keepdims=True` saat hasil agregasi mau dipakai membagi array aslinya.
