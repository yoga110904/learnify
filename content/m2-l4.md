## Loop yang muat dalam satu baris

Pola ini muncul terus-terusan:

```python
hasil = []
for x in data:
    hasil.append(x * 2)
```

Python punya cara ringkas untuk itu — **list comprehension**:

```python
hasil = [x * 2 for x in data]
```

Bacanya dari tengah: *untuk setiap `x` di `data`, ambil `x * 2`.*

## Pola dasar

```
[ ekspresi  for item in iterable  if kondisi ]
```

```python
angka = [1, 2, 3, 4, 5, 6]

[x * x for x in angka]                  # [1, 4, 9, 16, 25, 36]
[x for x in angka if x % 2 == 0]        # [2, 4, 6]
[x * x for x in angka if x % 2 == 0]    # [4, 16, 36]
[x for x in range(6) if x % 2 == 0]     # [0, 2, 4]
```

Contoh nyata membersihkan data:

```python
nama = ["  budi ", "ANI", " citra"]
rapi = [n.strip().title() for n in nama]
print(rapi)   # ['Budi', 'Ani', 'Citra']
```

## `if ... else` di dalam comprehension

Kalau butuh dua kemungkinan nilai, `if/else` ditaruh **di depan** (bentuk ternary):

```python
angka = [1, 2, 3, 4]
[("genap" if x % 2 == 0 else "ganjil") for x in angka]
# ['ganjil', 'genap', 'ganjil', 'genap']
```

Ingat bedanya:

- `if` **di belakang** = filter (menyaring, jumlah elemen bisa berkurang).
- `if/else` **di depan** = memilih nilai (jumlah elemen tetap).

## Dict & set comprehension

```python
angka = [1, 2, 3]

{x: x * x for x in angka}          # {1: 1, 2: 4, 3: 9}
{x % 3 for x in range(10)}         # {0, 1, 2}   (set, otomatis unik)
```

Membalik dictionary:

```python
d = {"a": 1, "b": 2}
{v: k for k, v in d.items()}       # {1: 'a', 2: 'b'}
```

## Comprehension bersarang

Bisa, tapi hati-hati keterbacaan:

```python
matriks = [[1, 2], [3, 4]]
datar = [x for baris in matriks for x in baris]
print(datar)    # [1, 2, 3, 4]
```

Urutan `for`-nya sama seperti kalau ditulis nested loop biasa, dari luar ke dalam.

## Kapan JANGAN pakai comprehension

Comprehension bagus kalau **muat dibaca sekali lihat**. Kalau sudah begini:

```python
hasil = [transform(x) if cek(x) else fallback(x) for y in data for x in y if x and x.aktif]
```

...tulis saja loop biasa. Kode dibaca jauh lebih sering daripada ditulis.

## Ringkasan

- `[ekspresi for item in data]` menggantikan pola loop + append.
- `if` di belakang menyaring; `if/else` di depan memilih nilai.
- Ada juga dict comprehension `{k: v for ...}` dan set comprehension.
- Berhenti pakai comprehension begitu barisnya sulit dibaca.

## Kesalahan umum

- Menaruh `if/else` di posisi filter → `SyntaxError`.
- Membuat comprehension tiga tingkat yang tidak terbaca.
- Memakai comprehension hanya untuk efek samping (misalnya `print`) — pakai loop biasa.
