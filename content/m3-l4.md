## `datetime` — waktu dan tanggal

```python
from datetime import datetime, date, timedelta

sekarang = datetime.now()
print(sekarang)                    # 2026-09-20 14:30:05.123456
print(sekarang.year, sekarang.month)

hari_ini = date.today()
print(hari_ini + timedelta(days=7))   # seminggu lagi
```

Ubah **string → tanggal** dengan `strptime` (p = parse), dan **tanggal → string** dengan `strftime` (f = format):

```python
t = datetime.strptime("2026-01-31", "%Y-%m-%d")
print(t.strftime("%d/%m/%Y"))      # 31/01/2026
```

Kode format yang sering dipakai: `%Y` tahun 4 digit, `%m` bulan, `%d` tanggal, `%H:%M:%S` jam.

Selisih dua tanggal menghasilkan `timedelta`:

```python
a = date(2026, 1, 1)
b = date(2026, 1, 31)
print((b - a).days)        # 30
print(abs((a - b).days))   # 30 — abs() biar selalu positif
```

## `random` — keacakan

```python
import random

random.randint(1, 6)                 # bilangan bulat 1..6 (6 IKUT)
random.random()                      # float 0.0 .. 1.0
random.choice(["a", "b", "c"])       # ambil satu acak
random.sample(range(1, 50), 6)       # 6 angka unik
random.shuffle(daftar)               # acak di tempat

random.seed(42)                      # hasil acak jadi bisa diulang
```

`seed` penting waktu testing: supaya hasil "acak"-nya konsisten dan test-nya nggak flaky.

## `os` dan `pathlib` — file & folder

Gaya modern pakai `pathlib`:

```python
from pathlib import Path

p = Path("data") / "nilai.csv"     # otomatis benar di Windows & Mac
print(p.exists(), p.suffix, p.stem)

Path("output").mkdir(exist_ok=True)
for f in Path(".").glob("*.py"):
    print(f.name)
```

Dari `os` yang masih sering dipakai:

```python
import os
os.getenv("API_KEY", "default")   # baca environment variable
```

`os.getenv` adalah cara benar menyimpan password/token — jangan pernah menulisnya langsung di kode.

## `collections` — struktur data siap pakai

```python
from collections import Counter, defaultdict

Counter("aab")                     # Counter({'a': 2, 'b': 1})
Counter(["x", "y", "x"]).most_common(1)   # [('x', 2)]
```

`Counter` menggantikan seluruh pola hitung frekuensi yang kita tulis manual di Modul 2.

```python
d = defaultdict(list)
d["a"].append(1)      # kunci "a" otomatis dibuat berisi list kosong
print(dict(d))        # {'a': [1]}
```

Tanpa `defaultdict`, baris itu akan `KeyError`.

## Ringkasan

- `datetime` + `timedelta` untuk hitung-hitungan tanggal; `strptime`/`strftime` untuk konversi string.
- `random.seed()` membuat hasil acak bisa diulang saat testing.
- `pathlib.Path` adalah cara modern menangani path lintas OS.
- `Counter` dan `defaultdict` memangkas banyak kode manual.

## Kesalahan umum

- Tertukar `strptime` (parse) dan `strftime` (format).
- Mengira `random.randint(1, 6)` tidak memasukkan angka 6 (padahal ikut).
- Menyambung path pakai `+ "/" +` yang gagal di Windows.
