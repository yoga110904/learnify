## Tiga cara menjalankan Python

Sebelum ngoding beneran, kamu perlu tahu "di mana" kode itu dijalankan. Ada tiga tempat:

### 1. REPL — buat coba-coba cepat

REPL singkatan dari *Read–Eval–Print Loop*. Ketik `python` (atau `python3`) di terminal, lalu muncul prompt `>>>`:

```
>>> 2 + 3
5
>>> nama = "Salsa"
>>> print(nama)
Salsa
>>> exit()
```

Cocok buat ngetes satu baris. Begitu ditutup, semuanya hilang.

### 2. File `.py` — buat program beneran

Bikin file `app.py`, isi:

```python
print("Halo dari file")
```

Lalu jalankan di terminal:

```
python app.py
```

Kalau di Mac/Linux kadang harus `python3 app.py`.

### 3. Editor / IDE — tempat kerja sehari-hari

**VS Code** adalah pilihan paling umum dan gratis:

1. Install **Python 3** dari [python.org](https://www.python.org/downloads/) — centang **"Add Python to PATH"** waktu install di Windows.
2. Install **VS Code**.
3. Di VS Code, buka tab Extensions, install ekstensi **Python** dari Microsoft.
4. Buka folder proyek, bikin file `.py`, tekan tombol ▶️ di pojok kanan atas.

> Di kelas ini kamu nggak wajib install apa-apa dulu — editor di sebelah kanan sudah menjalankan Python asli langsung di browser.

## Cek instalasi

```
python --version
```

Kalau keluar `Python 3.12.x` (angka boleh beda asal diawali 3), berarti aman.

## Komentar

Komentar adalah catatan buat manusia; Python mengabaikannya total.

```python
# ini komentar satu baris
harga = 15000   # komentar juga bisa di belakang kode

"""
Kalau butuh beberapa baris,
orang biasa pakai triple-quote seperti ini.
"""
print(harga)
```

Gunakan komentar buat menjelaskan **kenapa**, bukan **apa**:

```python
# ❌ kurang berguna
x = x + 1   # tambah 1 ke x

# ✅ berguna
x = x + 1   # kompensasi index yang dimulai dari 0
```

## Error pertama kamu (dan itu normal)

```python
print("Halo"
```

```
SyntaxError: '(' was never closed
```

Baca error dari **baris paling bawah**: di situ jenis error dan penjelasannya. `SyntaxError` = Python nggak ngerti tulisan kamu, biasanya kurang kurung, kutip, atau titik dua.

## Ringkasan

- REPL buat eksperimen singkat, file `.py` buat program sesungguhnya.
- Jalankan file dengan `python nama_file.py`.
- Komentar satu baris pakai `#`.
- Error bukan tanda kamu gagal — itu petunjuk paling jujur dari Python.

## Kesalahan umum

- Menjalankan file dengan `run app.py` (nggak ada perintah itu).
- Lupa `Add Python to PATH` di Windows, akibatnya `python` nggak dikenali terminal.
