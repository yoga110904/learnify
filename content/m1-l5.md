## Program yang bisa mengambil keputusan

Sampai sekarang program kita jalan lurus dari atas ke bawah. Sekarang kita kasih dia percabangan — kayak Google Maps yang bilang "kalau macet, lewat jalan alternatif".

```python
umur = 20

if umur >= 17:
    print("Boleh bikin SIM")
else:
    print("Belum cukup umur")
```

Struktur dasarnya:

```
if  <kondisi>:
    <dijalankan kalau kondisi True>
else:
    <dijalankan kalau kondisi False>
```

Dua hal wajib: **titik dua** `:` di akhir baris, dan **indentasi** (menjorok) di baris dalamnya.

## Indentasi itu sintaks, bukan hiasan

Bahasa lain pakai kurung kurawal `{}` buat menandai blok. Python pakai **spasi**.

```python
if True:
    print("A")     # bagian dari if
    print("B")     # bagian dari if
print("C")         # di luar if, selalu jalan
```

Standarnya **4 spasi**. Yang penting konsisten — campur tab dan spasi bikin `IndentationError`.

## `elif` untuk banyak pilihan

`elif` = "else if". Python mengecek dari atas, dan **berhenti di kecocokan pertama**.

```python
nilai = 82

if nilai >= 85:
    print("A")
elif nilai >= 70:
    print("B")
elif nilai >= 55:
    print("C")
else:
    print("D")
# Output: B
```

Urutannya penting. Kalau dibalik jadi `if nilai >= 55` duluan, nilai 82 akan kena "C" dan `elif` berikutnya nggak pernah dicek.

## Kondisi bersarang (nested)

```python
punya_tiket = True
umur = 15

if punya_tiket:
    if umur >= 17:
        print("Masuk bioskop")
    else:
        print("Film ini 17+")
else:
    print("Beli tiket dulu")
```

Kalau bersarangnya sudah 3 tingkat ke dalam, biasanya lebih enak digabung pakai `and`:

```python
if punya_tiket and umur >= 17:
    print("Masuk bioskop")
```

## Rantai perbandingan

Python bisa menulis rentang seperti di matematika:

```python
nilai = 75
if 70 <= nilai < 85:
    print("B")     # jalan
```

## Ternary — `if` satu baris

Kalau cuma memilih antara dua nilai:

```python
nilai = 80
status = "lulus" if nilai >= 70 else "gagal"
print(status)     # lulus
```

Bacanya: *ambil "lulus" kalau nilai >= 70, kalau nggak ambil "gagal"*. Pakai ini cuma untuk kasus sederhana; kalau kondisinya panjang, `if` biasa lebih terbaca.

## `pass` — placeholder

Blok kosong bikin error. Kalau belum mau nulis isinya:

```python
if umur < 0:
    pass   # nanti diisi validasi
```

## Ringkasan

- `if` / `elif` / `else` bikin program memilih jalur.
- Blok kode ditandai indentasi 4 spasi, dan barisnya diakhiri `:`.
- `elif` berhenti di kecocokan pertama — urutan kondisi menentukan hasil.
- Ternary `a if kondisi else b` untuk pemilihan singkat.

## Kesalahan umum

- Lupa titik dua di akhir `if`.
- Indentasi campur aduk → `IndentationError`.
- Menulis rentang nilai dengan urutan terbalik sehingga cabang tertentu nggak pernah kena.
