## Kenapa library AI penuh dengan class?

Buka kode scikit-learn mana pun, polanya selalu sama:

```python
scaler = StandardScaler()      # 1. buat objek
scaler.fit(X_train)            # 2. belajar dari data
X2 = scaler.transform(X_test)  # 3. terapkan hasil belajarnya
```

Kenapa tidak fungsi biasa saja? Karena langkah 2 menghasilkan sesuatu yang **harus diingat**: rata-rata dan standar deviasi tiap kolom. Nilai itu dipakai lagi di langkah 3, dan nanti dipakai lagi untuk data baru di produksi.

Objek adalah tempat menyimpan "hasil belajar" itu. Inilah alasan OOP jadi bahasa dasar seluruh ekosistem AI.

## Kontrak fit / transform / predict

| Method | Tugasnya | Menyimpan apa? |
|---|---|---|
| `fit(X)` | pelajari parameter dari data | ya — disimpan di `self` |
| `transform(X)` | terapkan parameter itu ke data | tidak |
| `predict(X)` | hasilkan prediksi | tidak |
| `fit_transform(X)` | jalan pintas: fit lalu transform | ya |

Konvensinya: atribut hasil belajar diberi akhiran garis bawah — `mean_`, `scale_`, `coef_`. Dengan begitu kamu langsung tahu mana yang hasil pelatihan dan mana yang pengaturan.

## Membuat scaler sendiri

```python
import numpy as np

class ScalerSederhana:
    def __init__(self):
        self.mean_ = None
        self.scale_ = None

    def fit(self, X):
        self.mean_ = X.mean(axis=0)
        std = X.std(axis=0)
        self.scale_ = np.where(std == 0, 1, std)   # hindari bagi nol
        return self                                 # biar bisa dirangkai

    def transform(self, X):
        if self.mean_ is None:
            raise ValueError("Panggil fit() dulu sebelum transform()")
        return (X - self.mean_) / self.scale_

    def fit_transform(self, X):
        return self.fit(X).transform(X)
```

Dua detail yang bikin class ini terasa "profesional":

1. **`fit` mengembalikan `self`** — supaya bisa dirangkai: `scaler.fit(X).transform(X)`
2. **`transform` menolak jalan sebelum `fit`** — error jelas lebih baik daripada hasil diam-diam salah

## Kenapa ini mencegah data leakage

Ingat aturan dari statistik: parameter penskalaan **hanya boleh dipelajari dari data latih**.

```python
scaler = ScalerSederhana()
X_train_s = scaler.fit_transform(X_train)   # belajar + terapkan
X_test_s  = scaler.transform(X_test)        # terapkan SAJA
```

Karena `mean_` dan `scale_` tersimpan di dalam objek, data uji otomatis diperlakukan dengan angka yang sama. Kalau ini ditulis sebagai fungsi lepas, kamu harus mengoper nilai-nilai itu manual — dan di situlah orang sering keliru.

## Inheritance untuk berbagi perilaku

Semua langkah preprocessing punya pola yang sama, jadi taruh bagian umumnya di induk:

```python
class BasePreprocessor:
    def fit(self, X):
        raise NotImplementedError

    def transform(self, X):
        raise NotImplementedError

    def fit_transform(self, X):
        return self.fit(X).transform(X)      # cukup ditulis sekali


class MinMaxSederhana(BasePreprocessor):
    def fit(self, X):
        self.min_ = X.min(axis=0)
        rentang = X.max(axis=0) - self.min_
        self.scale_ = np.where(rentang == 0, 1, rentang)
        return self

    def transform(self, X):
        return (X - self.min_) / self.scale_
```

`MinMaxSederhana` dapat `fit_transform` secara gratis. Persis seperti `TransformerMixin` di scikit-learn.

## Duck typing bikin pipeline mungkin

```python
class PipelineSederhana:
    def __init__(self, langkah):
        self.langkah = langkah

    def fit_transform(self, X):
        for l in self.langkah:
            X = l.fit_transform(X)
        return X
```

Pipeline ini tidak peduli class apa isinya — asal punya `fit_transform`, dia jalan. Itulah polymorphism dari lesson sebelumnya, dipakai di kode sungguhan.

## Ringkasan

- Class dipakai di library AI karena `fit` menghasilkan parameter yang harus diingat.
- Kontraknya: `fit` belajar & menyimpan, `transform`/`predict` hanya menerapkan.
- Atribut hasil belajar diberi akhiran garis bawah (`mean_`, `coef_`).
- Menyimpan parameter di objek itulah yang mencegah data leakage.

## Kesalahan umum

- Memanggil `transform` sebelum `fit`.
- Menjalankan `fit` pada data uji (data leakage).
- Menyimpan model tanpa scaler-nya sehingga data baru diproses dengan cara berbeda.
