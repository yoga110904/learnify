## Kalau jumlah putarannya belum diketahui

`for` dipakai kalau kamu tahu **apa** yang mau dilewati. `while` dipakai kalau kamu cuma tahu **kapan harus berhenti**.

```python
sisa = 3
while sisa > 0:
    print("sisa:", sisa)
    sisa -= 1
print("habis")
```

```
sisa: 3
sisa: 2
sisa: 1
habis
```

Alurnya: cek kondisi → kalau `True` jalankan blok → kembali cek → ulangi sampai kondisinya `False`.

Kalau kondisinya sudah `False` sejak awal, blok itu **tidak pernah** dijalankan:

```python
sisa = 0
while sisa > 0:
    print("tidak akan tercetak")
```

## Tiga bahan wajib `while`

Setiap `while` yang sehat punya tiga hal:

```python
i = 0                 # 1. inisialisasi
while i < 5:          # 2. kondisi berhenti
    print(i)
    i += 1            # 3. perubahan menuju berhenti
```

Lupa nomor 3 = **infinite loop**:

```python
i = 0
while i < 5:
    print(i)          # 💥 mencetak 0 selamanya
```

Kalau program terlanjur hang di terminal, tekan `Ctrl + C`. Di Learnify, eksekusi otomatis dihentikan setelah beberapa detik dengan pesan peringatan.

## Kapan `while`, kapan `for`?

| Situasi | Pilihan |
|---|---|
| Melewati isi list/string/range | `for` |
| Mengulang N kali (N diketahui) | `for` |
| Menunggu input yang valid | `while` |
| Mengulang sampai kondisi tercapai | `while` |
| Membaca data sampai habis | `while` |

Aturan praktis: **kalau bisa pakai `for`, pakai `for`** — lebih aman karena tidak mungkin infinite.

## Pola: validasi input

Ini kegunaan `while` yang paling sering:

```python
while True:
    umur = input("Umur: ")
    if umur.isdigit():
        umur = int(umur)
        break
    print("Harus angka, coba lagi.")

print(f"Umur kamu {umur}")
```

`while True` terlihat berbahaya, tapi aman selama ada `break` di dalamnya. Pola ini standar untuk "terus tanya sampai jawabannya benar".

## Pola: menu berulang

```python
while True:
    print("\n1. Tambah  2. Lihat  3. Keluar")
    pilih = input("Pilih: ")

    if pilih == "1":
        print("Menambah...")
    elif pilih == "2":
        print("Menampilkan...")
    elif pilih == "3":
        print("Sampai jumpa")
        break
    else:
        print("Pilihan tidak ada")
```

Kalau nanti kamu bikin program CLI pertama, kerangkanya hampir pasti seperti ini.

## `break` dan `continue`

- `break` = keluar dari loop sekarang juga
- `continue` = lewati sisa baris, lanjut ke putaran berikutnya

```python
for i in range(1, 8):
    if i == 5:
        break          # berhenti total
    if i % 2 == 0:
        continue       # lewati yang genap
    print(i)
# 1 3
```

Keduanya jalan di `for` maupun `while`, dan hanya mempengaruhi loop **terdalam** tempat mereka berada:

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break       # cuma keluar dari loop j
        print(i, j)
# 0 0
# 1 0
# 2 0
```

Untuk keluar dari dua loop sekaligus, pakai penanda atau bungkus dalam fungsi lalu `return`:

```python
def cari(matriks, target):
    for i, baris in enumerate(matriks):
        for j, nilai in enumerate(baris):
            if nilai == target:
                return i, j     # langsung keluar dari dua-duanya
    return None
```

## `while ... else`

Sama seperti `for ... else`: blok `else` jalan kalau loop berakhir **tanpa** `break`.

```python
percobaan = 0
while percobaan < 3:
    kode = input("Kode: ")
    if kode == "1234":
        print("Berhasil masuk")
        break
    percobaan += 1
else:
    print("Gagal 3 kali, akun dikunci")
```

Tanpa `else`, kamu butuh variabel penanda tambahan untuk membedakan "berhasil" dan "kehabisan percobaan".

n = 5

<pre>n = 10
while n > 0:
    print(n)
    n + 1</pre></div>

<details>
<summary>Lihat jawaban</summary>

Dua masalah:

1. `n + 1` menghitung hasilnya lalu **membuangnya** — nilai `n` tidak berubah. Harusnya `n -= 1` atau `n = n - 1`.
2. Bahkan kalau ditulis `n += 1`, nilainya justru membesar dan kondisinya tidak pernah `False` — tetap infinite.

Yang benar:

```python
n = 10
while n > 0:
    print(n)
    n -= 1
```

## Ringkasan

- `while` dipakai kalau jumlah putarannya belum diketahui, hanya kondisi berhentinya.
- Tiga bahan wajib: inisialisasi, kondisi, dan perubahan menuju berhenti.
- `while True` + `break` adalah pola baku untuk validasi input dan menu.
- `break` keluar dari loop, `continue` lompat ke putaran berikutnya — keduanya hanya mempengaruhi loop terdalam.
- `while ... else` berjalan kalau loop selesai tanpa `break`.

## Kesalahan umum

- Lupa mengubah variabel kondisi → infinite loop.
- Menulis `n + 1` alih-alih `n -= 1` (hasilnya dibuang).
- Menaruh `continue` sebelum baris yang menambah counter, sehingga loop macet.
- Mengira `break` bisa keluar dari semua loop bersarang sekaligus.
