## Di mana sebuah variabel "hidup"?

Variabel yang dibuat di dalam fungsi hanya ada di dalam fungsi itu. Begitu fungsinya selesai, variabelnya hilang. Itu namanya **scope**.

```python
def f():
    pesan = "halo"      # variabel LOKAL
    print(pesan)

f()               # halo
print(pesan)      # 💥 NameError: name 'pesan' is not defined
```

Sebaliknya, variabel di luar fungsi (**global**) bisa dibaca dari dalam:

```python
pajak = 0.1

def total(harga):
    return harga + harga * pajak    # boleh membaca pajak

print(total(1000))    # 1100.0
```

## Membaca boleh, menimpa bikin variabel baru

```python
x = 1

def f():
    x = 2        # ini variabel LOKAL baru, bukan x yang di luar
    print(x)     # 2

f()
print(x)         # 1  <- yang di luar tidak berubah
```

Kalau benar-benar perlu mengubah yang global:

```python
x = 1

def f():
    global x
    x = 2

f()
print(x)    # 2
```

Tapi hindari `global`. Fungsi yang diam-diam mengubah keadaan di luar bikin bug yang susah dilacak. Lebih baik: terima lewat parameter, kembalikan lewat `return`.

## Aturan LEGB

Python mencari nama variabel secara berurutan:

1. **L**ocal — di dalam fungsi sekarang
2. **E**nclosing — fungsi pembungkusnya
3. **G**lobal — level file
4. **B**uilt-in — bawaan Python (`len`, `print`, ...)

Karena itu jangan menamai variabel `list`, `str`, atau `sum` — kamu menutupi fungsi bawaan:

```python
sum = 10
print(sum([1, 2]))   # 💥 TypeError: 'int' object is not callable
```

## Lambda: fungsi satu baris tanpa nama

```python
kuadrat = lambda x: x * x
print(kuadrat(4))     # 16
```

Bentuknya `lambda parameter: ekspresi`. Isinya cuma boleh **satu ekspresi**, dan hasilnya otomatis dikembalikan (tidak ada `return`).

Lambda bukan buat disimpan ke variabel (kalau begitu, pakai `def` saja). Kegunaan aslinya: dikirim sebagai argumen ke fungsi lain.

## `sorted(key=...)` — tempat lambda bersinar

```python
orang = [
    {"nama": "Ani", "umur": 30},
    {"nama": "Budi", "umur": 20},
]

urut = sorted(orang, key=lambda o: o["umur"])
print(urut[0]["nama"])    # Budi
```

`key` menerima sebuah fungsi yang menentukan "dinilai dari apa" tiap elemen.

```python
kata = ["banana", "kiwi", "apple"]

sorted(kata, key=len)                 # ['kiwi', 'apple', 'banana']
sorted(kata, key=lambda s: s[-1])     # urut berdasarkan huruf terakhir
sorted(orang, key=lambda o: -o["umur"])   # urut menurun
sorted(orang, key=lambda o: o["umur"], reverse=True)   # cara yang lebih jelas
```

Urut berdasarkan dua kriteria sekaligus — kembalikan tuple:

```python
sorted(orang, key=lambda o: (o["umur"], o["nama"]))
```

## Ringkasan

- Variabel lokal hidup hanya selama fungsinya berjalan.
- Fungsi boleh membaca variabel global, tapi menimpanya butuh `global` (hindari).
- Urutan pencarian nama: Local → Enclosing → Global → Built-in.
- `lambda x: ...` adalah fungsi singkat, paling berguna sebagai argumen `key=`.

## Kesalahan umum

- Mengira variabel di dalam fungsi bisa dibaca dari luar.
- Menimpa nama bawaan seperti `list`, `sum`, `id`.
- Menulis lambda panjang berisi banyak logika — pakai `def`.
