## Kenapa `"5" + 3` error?

Python sengaja galak soal tipe data. Coba tebak apa yang terjadi:

```python
print("5" + 3)
```

```
TypeError: can only concatenate str (not "int") to str
```

Python bingung: `+` buat string artinya *menyambung*, buat angka artinya *menjumlah*. Karena kedua sisinya beda tipe, dia nggak mau nebak-nebak. Bandingkan:

```python
print("5" + "3")   # 53   -> disambung
print(5 + 3)       # 8    -> dijumlah
```

Solusinya: **konversi tipe** (type casting) supaya kedua sisi sejenis.

## Empat fungsi konversi

```python
int("7")        # 7
int(3.9)        # 3      -> dipotong, BUKAN dibulatkan
float("3.5")    # 3.5
float(7)        # 7.0
str(20)         # "20"
bool(0)         # False
```

### Yang sering bikin kaget

```python
int("3.5")      # 💥 ValueError
```

`int()` cuma mau string yang isinya **bilangan bulat murni**. Kalau stringnya desimal, konversi dua langkah:

```python
int(float("3.5"))   # 3
```

Dan `int()` selalu **memotong** ke bawah, nggak membulatkan:

```python
int(3.99)       # 3
round(3.99)     # 4   <- ini baru membulatkan
```

## Nilai "truthy" dan "falsy"

Setiap nilai di Python punya "rasa" benar atau salah waktu dipakai sebagai kondisi. Yang dianggap **falsy** (rasa `False`) cuma sedikit, sisanya truthy:

```python
bool(0)         # False
bool(0.0)       # False
bool("")        # False   string kosong
bool([])        # False   list kosong
bool({})        # False   dict kosong
bool(None)      # False

bool(1)         # True
bool(-5)        # True    angka negatif tetap True!
bool("0")       # True    string berisi "0" tetap True!
bool(" ")       # True    spasi juga isi
```

Ini kepakai buat ngecek data kosong dengan singkat:

```python
nama = input("Nama: ")
if not nama:
    print("Nama tidak boleh kosong")
```

## Konversi yang aman

Data dari user atau file sering nggak bisa dipercaya. Pola aman (dibahas penuh di Modul 3):

```python
teks = "abc"
if teks.isdigit():
    angka = int(teks)
else:
    angka = 0
print(angka)    # 0
```

## Ringkasan

- Python nggak otomatis nyampur tipe — kita yang harus konversi.
- `int()`, `float()`, `str()`, `bool()` adalah alat konversinya.
- `int("3.5")` error; `int(3.5)` menghasilkan 3 (dipotong).
- Falsy: `0`, `0.0`, `""`, `[]`, `{}`, `None`. Selain itu truthy.

## Kesalahan umum

- Mengira `int()` membulatkan (padahal memotong) — pakai `round()` kalau mau membulatkan.
- Lupa `int()` di hasil `input()`.
- Mengira `"0"` bernilai `False`.
