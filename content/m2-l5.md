## Fungsi = kode yang dibungkus dan diberi nama

Kalau kamu menulis logika yang sama di tiga tempat, dan besok logikanya berubah, kamu harus memperbaikinya di tiga tempat. Fungsi menyelesaikan masalah itu.

```python
def sapa(nama):
    return f"Halo {nama}"

print(sapa("Salsa"))    # Halo Salsa
print(sapa("Budi"))     # Halo Budi
```

Bagian-bagiannya:

- `def` — kata kunci pembuat fungsi
- `sapa` — nama fungsi (snake_case, sebaiknya kata kerja)
- `(nama)` — **parameter**, variabel lokal yang diisi saat dipanggil
- `return` — nilai yang dikirim balik ke pemanggil

## `return` vs `print` — beda besar!

```python
def tambah_print(a, b):
    print(a + b)

def tambah_return(a, b):
    return a + b

x = tambah_print(2, 3)     # tercetak 5, tapi x = None
y = tambah_return(2, 3)    # tidak tercetak, tapi y = 5
print(y * 2)               # 10 — bisa dipakai lagi
```

`print` hanya menampilkan ke layar. `return` memberi **nilai** yang bisa disimpan, dihitung, atau diuji. Karena itu semua latihan di sini memakai `return`.

Fungsi tanpa `return` otomatis mengembalikan `None`. Dan `return` langsung menghentikan fungsi:

```python
def cek(n):
    if n < 0:
        return "negatif"
    return "positif"      # baris ini tidak jalan kalau sudah return di atas
```

## Default argument

```python
def sapa(nama, salam="Halo"):
    return f"{salam} {nama}"

sapa("Budi")               # Halo Budi
sapa("Budi", "Selamat pagi")  # Selamat pagi Budi
```

Parameter berdefault harus ditaruh **setelah** yang tanpa default.

> ⚠️ Jangan pakai list/dict sebagai nilai default (`def f(x=[])`) — objeknya dibuat sekali dan dipakai ulang antar pemanggilan. Pakai `None` lalu isi di dalam fungsi.

## Keyword argument

Memanggil dengan menyebut nama parameternya bikin kode jauh lebih jelas:

```python
def buat_user(nama, admin=False, aktif=True):
    return (nama, admin, aktif)

buat_user("Salsa", admin=True)         # jelas
buat_user("Salsa", True, False)        # True-nya yang mana?
```

## `*args` dan `**kwargs`

Untuk jumlah argumen yang tidak ditentukan:

```python
def total(*angka):          # angka menjadi TUPLE
    return sum(angka)

total(1, 2)          # 3
total(1, 2, 3, 4)    # 10
total()              # 0

def info(**data):           # data menjadi DICT
    return data

info(nama="Salsa", umur=21)   # {'nama': 'Salsa', 'umur': 21}
```

Gabungan keduanya:

```python
def belanja(*harga, diskon=0):
    subtotal = sum(harga)
    return subtotal - subtotal * diskon / 100

belanja(100, 200)              # 300
belanja(100, 100, diskon=10)   # 180
```

## Docstring

Penjelasan singkat di baris pertama fungsi, dibaca lewat `help()` dan editor:

```python
def luas_lingkaran(r):
    """Mengembalikan luas lingkaran dengan jari-jari r."""
    return 3.14159 * r ** 2
```

## Ringkasan

- Fungsi membungkus logika supaya bisa dipakai ulang.
- `return` mengirim nilai; `print` hanya menampilkan.
- Default dan keyword argument bikin pemanggilan lebih jelas.
- `*args` → tuple, `**kwargs` → dict.

## Kesalahan umum

- Memakai `print` padahal dibutuhkan `return`.
- Lupa memanggil fungsinya (`sapa` vs `sapa()`).
- Memakai list sebagai nilai default parameter.
