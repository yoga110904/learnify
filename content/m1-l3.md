## Program yang bisa diajak ngobrol

Sejauh ini program kita cuma "ngomong sendiri" pakai `print()`. Sekarang kita bikin dia bisa "dengar" pakai `input()`.

```python
nama = input("Siapa namamu? ")
print("Halo", nama)
```

Waktu dijalankan:

```
Siapa namamu? Salsa
Halo Salsa
```

### `input()` selalu menghasilkan teks

Ini jebakan nomor satu buat pemula:

```python
umur = input("Umur: ")   # user ketik 20
print(umur + 5)          # 💥 TypeError!
```

Karena `umur` isinya string `"20"`, bukan angka `20`. Solusinya dibungkus `int()`:

```python
umur = int(input("Umur: "))
print(umur + 5)   # 25
```

## `print()` lebih dalam

```python
print("a", "b", "c")                 # a b c   (dipisah spasi)
print("a", "b", sep="-")             # a-b
print("loading", end="...")          # nggak pindah baris
print("selesai")                     # loading...selesai
```

Default-nya `sep=" "` dan `end="\n"` (pindah baris).

Karakter khusus di dalam string:

```python
print("baris 1\nbaris 2")   # \n  = enter
print("Nama:\tBudi")        # \t  = tab
print("Dia bilang \"hai\"") # \"  = tanda kutip literal
```

## f-string: cara modern merangkai teks

Sebelum f-string, orang nyambung teks pakai `+` dan itu berantakan:

```python
nama = "Budi"; umur = 20
print("Halo " + nama + ", umurmu " + str(umur) + " tahun")   # 😩
```

Dengan **f-string** (tambahkan `f` sebelum kutip, variabel ditaruh di `{}`):

```python
print(f"Halo {nama}, umurmu {umur} tahun")
# Halo Budi, umurmu 20 tahun
```

Di dalam `{}` boleh ada ekspresi:

```python
x = 5
print(f"Dua kali {x} adalah {x * 2}")   # Dua kali 5 adalah 10
print(f"Dewasa? {umur >= 17}")          # Dewasa? True
```

### Format angka

```python
harga = 1234567.891
print(f"{harga:,.2f}")    # 1,234,567.89   (pakai koma, 2 desimal)
print(f"{0.25:.1%}")      # 25.0%
print(f"{7:03d}")         # 007            (3 digit, isi nol)
```

Aturannya: `{nilai:format}`.

| Format | Arti |
|---|---|
| `.2f` | 2 angka di belakang koma |
| `,` | pemisah ribuan |
| `:>10` | rata kanan selebar 10 karakter |
| `:<10` | rata kiri |
| `:^10` | rata tengah |

## Ringkasan

- `input()` membaca ketikan user dan **selalu** mengembalikan `str`.
- Bungkus dengan `int()` / `float()` kalau butuh angka.
- `print()` punya `sep` dan `end` yang bisa diatur.
- f-string (`f"... {variabel} ..."`) adalah cara paling rapi merangkai teks.

## Kesalahan umum

- Menghitung langsung dari hasil `input()` tanpa konversi.
- Lupa huruf `f` di depan string, jadi `{nama}` ikut tercetak apa adanya.
- Nyampur kutip yang sama di dalam f-string: `f"{d["k"]}"` → error.
