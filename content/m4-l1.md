## Cetakan kue dan kuenya

Kamu punya satu **cetakan** kue. Dari cetakan itu kamu bisa bikin puluhan kue: bentuknya sama, tapi rasanya bisa beda-beda.

- **Class** = cetakannya (rancangan).
- **Object** = kue hasil cetakan (wujud nyatanya).

Sebelum OOP, data dan fungsi terpisah:

```python
nama_kucing = "Oyen"
def bersuara(nama):
    return f"Meong, aku {nama}"
```

Begitu kucingnya ada 50 dengan 6 atribut masing-masing, kode seperti itu berantakan. OOP menyatukan **data** dan **perilaku** dalam satu bungkus.

## Class pertama

```python
class Kucing:
    def __init__(self, nama):
        self.nama = nama

    def bersuara(self):
        return f"Meong, aku {self.nama}"

oyen = Kucing("Oyen")
mimi = Kucing("Mimi")

print(oyen.bersuara())    # Meong, aku Oyen
print(mimi.nama)          # Mimi
```

## Membedah bagian-bagiannya

### `class Kucing:`
Nama class pakai **PascalCase** (huruf besar tiap kata): `Kucing`, `LoginPage`, `RekeningBank`.

### `__init__`
Disebut *constructor*. Dijalankan **otomatis** saat objek dibuat. Tugasnya menyiapkan atribut awal.

```python
oyen = Kucing("Oyen")
#      ^ __init__ jalan di sini, nama="Oyen"
```

### `self`
`self` adalah **objek itu sendiri**. Waktu kamu panggil `oyen.bersuara()`, Python diam-diam mengirim `oyen` sebagai argumen pertama.

```python
oyen.bersuara()          # yang kamu tulis
Kucing.bersuara(oyen)    # yang sebenarnya terjadi
```

Karena itu `self` **wajib** jadi parameter pertama setiap method. Lupa menulisnya = `TypeError`.

Bedakan dengan jelas:

```python
class Kucing:
    def __init__(self, nama):
        self.nama = nama    # kiri: atribut milik objek
        #                     kanan: parameter lokal
```

## Atribut instance vs atribut class

```python
class Kucing:
    spesies = "Felis catus"      # atribut CLASS — dibagi semua objek

    def __init__(self, nama):
        self.nama = nama         # atribut INSTANCE — beda tiap objek

print(Kucing.spesies)     # Felis catus
print(Kucing("A").nama)   # A
```

## Method bisa mengubah keadaan objek

```python
class Kucing:
    def __init__(self, nama):
        self.nama = nama
        self.kenyang = 0

    def makan(self, porsi):
        self.kenyang += porsi
        return self.kenyang

oyen = Kucing("Oyen")
oyen.makan(2)
print(oyen.kenyang)    # 2
```

Objek "mengingat" keadaannya — itulah kelebihan utama OOP dibanding fungsi lepas.

## Ringkasan

- Class adalah rancangan; object adalah wujud nyatanya.
- `__init__` dijalankan otomatis saat objek dibuat.
- `self` merujuk objek itu sendiri dan wajib jadi parameter pertama method.
- Atribut instance (`self.x`) berbeda tiap objek; atribut class dibagi bersama.

## Kesalahan umum

- Lupa menulis `self` di parameter method.
- Menulis `nama = nama` alih-alih `self.nama = nama` di `__init__`.
- Menamai class dengan huruf kecil (bikin kode sulit dibedakan dari fungsi).
