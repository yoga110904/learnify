## String itu deretan karakter

Anggap string sebagai gerbong kereta: tiap karakter punya nomor kursi, dimulai dari **0**.

```
 P  y  t  h  o  n
 0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

```python
teks = "Python"
print(teks[0])    # P
print(teks[5])    # n
print(teks[-1])   # n   (dari belakang)
print(teks[-2])   # o
```

## Slicing: `teks[start:stop:step]`

```python
teks = "Python"
print(teks[1:4])    # yth   (index 1,2,3 — 4 tidak ikut)
print(teks[:3])     # Pyt   (dari awal)
print(teks[3:])     # hon   (sampai akhir)
print(teks[::2])    # Pto   (loncat 2)
print(teks[::-1])   # nohtyP (dibalik!)
```

`[::-1]` adalah trik klasik buat membalik string.

## Method penting

```python
t = "  Halo Dunia  "

t.strip()          # "Halo Dunia"   buang spasi di ujung
t.upper()          # "  HALO DUNIA  "
t.lower()          # "  halo dunia  "
t.replace("a", "@")# "  H@lo Duni@  "
```

```python
"a,b,c".split(",")        # ['a', 'b', 'c']
"a b c".split()           # ['a', 'b', 'c']   (default: spasi)
"-".join(["a", "b", "c"]) # "a-b-c"
```

`split` memecah string jadi list, `join` menyatukan list jadi string. Dua-duanya wajib hafal — kepakai terus waktu ngolah CSV dan log.

```python
"python".find("th")       # 2   (-1 kalau tidak ketemu)
"python".startswith("py") # True
"python".endswith("on")   # True
"Python3".isdigit()       # False
"123".isdigit()           # True
```

## `len()` dan operator `in`

```python
print(len("Python"))          # 6
print("th" in "Python")       # True
print("z" not in "Python")    # True
```

## String itu immutable

Artinya isinya **nggak bisa diubah di tempat**:

```python
teks = "Python"
teks[0] = "J"     # 💥 TypeError
```

Yang bisa kita lakukan adalah **bikin string baru**:

```python
teks = "J" + teks[1:]
print(teks)       # Jython
```

Makanya semua method di atas **mengembalikan string baru**, bukan mengubah aslinya:

```python
t = "halo"
t.upper()
print(t)          # halo  <- nggak berubah!
t = t.upper()
print(t)          # HALO  <- baru berubah
```

## Contoh nyata: normalisasi teks

Sebelum membandingkan input user, biasanya teks "dibersihkan" dulu:

```python
def bersihkan(s):
    return s.strip().lower().replace(" ", "")

print(bersihkan("  Kasur Ini Rusak "))   # kasurinirusak
```

Pola ini persis yang kamu butuhkan buat latihan palindrom.

## Ringkasan

- Index dimulai dari 0; index negatif menghitung dari belakang.
- Slicing `[a:b]` mengambil a sampai b-1; `[::-1]` membalik.
- `split`/`join` untuk memecah dan menyatukan teks.
- String immutable — method selalu mengembalikan string baru.

## Kesalahan umum

- Menulis `t.upper()` tanpa menyimpan hasilnya.
- Mengira `teks[1:4]` ikut mengambil index 4.
- Lupa `.strip()` waktu membandingkan input yang mungkin ada spasinya.
