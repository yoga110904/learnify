## Kenapa `"5" + 3` error?

Python sengaja galak soal tipe data. Coba tebak apa yang terjadi:

```python
print("5" + 3)
```

```
TypeError: can only concatenate str (not "int") to str
```

Python bingung: `+` buat string artinya *menyambung*, buat angka artinya *menjumlah*. Karena kedua sisinya beda tipe, dia nggak mau nebak-nebak. Bandingkan:

```python
print("5" + "3")   # 53   -> disambung
print(5 + 3)       # 8    -> dijumlah
print("5" * 3)     # 555  -> diulang 3 kali!
print(5 * 3)       # 15
```

Baris ketiga menunjukkan kenapa menebak itu berbahaya: `*` antara string dan angka **sah** tapi artinya sangat berbeda.

Bahasa lain seperti JavaScript memilih menebak, dan hasilnya terkenal membingungkan (`"5" + 3` jadi `"53"`, tapi `"5" - 3` jadi `2`). Python memilih berteriak lebih awal — itu fitur, bukan kekurangan.

## Empat fungsi konversi

```python
int("7")        # 7
int(3.9)        # 3      -> dipotong, BUKAN dibulatkan
int(True)       # 1
float("3.5")    # 3.5
float(7)        # 7.0
str(20)         # "20"
str([1, 2])     # "[1, 2]"
bool(0)         # False
```

### Yang sering bikin kaget

```python
int("3.5")      # 💥 ValueError: invalid literal for int()
```

`int()` cuma mau string yang isinya **bilangan bulat murni**. Kalau stringnya desimal, konversi dua langkah:

```python
int(float("3.5"))   # 3
```

Spasi di ujung dimaafkan, tapi karakter lain tidak:

```python
int("  7  ")    # 7    ✅ spasi diabaikan
int("7 kg")     # 💥 ValueError
int("")         # 💥 ValueError
int("1,5")      # 💥 ValueError  (koma bukan desimal Python)
```

Dan `int()` selalu **memotong** ke arah nol, nggak membulatkan:

```python
int(3.99)       # 3
int(-3.99)      # -3      memotong, bukan ke bawah
round(3.99)     # 4       <- ini baru membulatkan
```

### Konversi antar koleksi

```python
list("abc")            # ['a', 'b', 'c']
list((1, 2))           # [1, 2]
tuple([1, 2])          # (1, 2)
set([1, 1, 2])         # {1, 2}       duplikat hilang
"".join(["a", "b"])    # "ab"
```

`"".join(...)` adalah cara mengubah list of string jadi satu string — perhatikan, bukan `str(list)`:

```python
str(["a", "b"])        # "['a', 'b']"   ❌ ikut kurung dan kutipnya
"".join(["a", "b"])    # "ab"            ✅
```

## Nilai "truthy" dan "falsy"

Setiap nilai punya "rasa" benar atau salah waktu dipakai sebagai kondisi. Yang dianggap **falsy** cuma sedikit, sisanya truthy:

```python
bool(0)         # False
bool(0.0)       # False
bool("")        # False   string kosong
bool([])        # False   list kosong
bool({})        # False   dict kosong
bool(None)      # False

bool(1)         # True
bool(-5)        # True    angka negatif tetap True!
bool("0")       # True    string berisi "0" tetap True!
bool("False")   # True    string apa pun yang tidak kosong itu True
bool(" ")       # True    spasi juga isi
```

Baris `bool("False")` itu jebakan nyata: kalau kamu membaca `"False"` dari file konfigurasi lalu langsung `bool()`, hasilnya `True`. Konversi teks ke boolean harus dilakukan manual:

```python
def ke_bool(teks):
    return teks.strip().lower() in ("true", "1", "ya", "y")
```

## Konversi yang aman

Data dari user, file, atau API sering nggak bisa dipercaya. Tiga pola yang akan sering kamu pakai:

### 1. Cek dulu

```python
teks = "abc"
if teks.isdigit():
    angka = int(teks)
else:
    angka = 0
```

⚠️ `.isdigit()` hanya `True` untuk digit murni — `"-5"` dan `"3.5"` menghasilkan `False`.

### 2. Coba dan tangani (dibahas penuh di Modul 3)

```python
try:
    angka = int(teks)
except ValueError:
    angka = 0
```

Ini cara paling andal dan paling Pythonic.

### 3. Fungsi bantu sendiri

```python
def ke_int(teks, default=0):
    try:
        return int(str(teks).strip())
    except (ValueError, TypeError):
        return default

print(ke_int("42"))       # 42
print(ke_int("abc"))      # 0
print(ke_int(None, -1))   # -1
```

Fungsi seperti ini akan kamu tulis berkali-kali dalam karier ngodingmu.

## Konversi implisit yang tetap terjadi

Python tidak mencampur str dan int, tapi **tetap** menaikkan int ke float secara otomatis:

```python
print(5 + 2.0)          # 7.0
print(type(5 + 2.0))    # <class 'float'>
print(True + 1)         # 2       bool dinaikkan ke int
```

Urutan promosinya: `bool` → `int` → `float` → `complex`. Tipe yang "lebih luas" menang.

## Ringkasan

- Python nggak otomatis nyampur str dan angka — kita yang harus konversi.
- `int()`, `float()`, `str()`, `bool()` adalah alat konversinya.
- `int("3.5")` error; `int(3.5)` menghasilkan 3 (memotong ke arah nol).
- Falsy: `0`, `0.0`, `""`, `[]`, `{}`, `None`. Selain itu truthy — termasuk `"False"`.
- Untuk data dari luar, konversi dengan `try/except` atau fungsi bantu berdefault.

## Kesalahan umum

- Mengira `int()` membulatkan (padahal memotong) — pakai `round()` kalau mau membulatkan.
- Lupa `int()` di hasil `input()`.
- Mengira `"0"` atau `"False"` bernilai `False`.
- Memakai `str(list)` padahal maksudnya `"".join(list)`.
