## Loop yang muat dalam satu baris

Pola ini muncul terus-terusan:

```python
hasil = []
for x in data:
    hasil.append(x * 2)
```

Python punya cara ringkas untuk itu — **list comprehension**:

```python
hasil = [x * 2 for x in data]
```

Bacanya dari tengah: *untuk setiap `x` di `data`, ambil `x * 2`.*

Selain lebih pendek, comprehension juga **lebih cepat** karena loop-nya dijalankan di level C, bukan bytecode Python.

## Pola dasar

```
[ ekspresi  for item in iterable  if kondisi ]
```

```python
angka = [1, 2, 3, 4, 5, 6]

[x * x for x in angka]                  # [1, 4, 9, 16, 25, 36]
[x for x in angka if x % 2 == 0]        # [2, 4, 6]
[x * x for x in angka if x % 2 == 0]    # [4, 16, 36]
[x for x in range(6) if x % 2 == 0]     # [0, 2, 4]
```

Contoh nyata membersihkan data:

```python
nama = ["  budi ", "ANI", " citra"]
rapi = [n.strip().title() for n in nama]
print(rapi)   # ['Budi', 'Ani', 'Citra']

nilai_teks = ["80", "92", "75"]
nilai = [int(n) for n in nilai_teks]
```

Konversi tipe massal seperti baris terakhir itu mungkin penggunaan comprehension yang paling sering kamu tulis.

## `if ... else` di dalam comprehension

Kalau butuh dua kemungkinan nilai, `if/else` ditaruh **di depan** (bentuk ternary):

```python
angka = [1, 2, 3, 4]
[("genap" if x % 2 == 0 else "ganjil") for x in angka]
# ['ganjil', 'genap', 'ganjil', 'genap']
```

Ingat bedanya:

| Posisi | Fungsi | Jumlah elemen |
|---|---|---|
| `if` **di belakang** | menyaring | bisa berkurang |
| `if/else` **di depan** | memilih nilai | tetap |

Bisa juga digabung — filter dan pilih nilai sekaligus:

```python
[("lulus" if n >= 70 else "gagal") for n in nilai if n > 0]
```

## Dict & set comprehension

```python
angka = [1, 2, 3]

{x: x * x for x in angka}          # {1: 1, 2: 4, 3: 9}
{x % 3 for x in range(10)}         # {0, 1, 2}   (set, otomatis unik)
```

Membalik dictionary:

```python
d = {"a": 1, "b": 2}
{v: k for k, v in d.items()}       # {1: 'a', 2: 'b'}
```

Menyaring dictionary:

```python
nilai = {"Budi": 80, "Ani": 60, "Citra": 92}
lulus = {k: v for k, v in nilai.items() if v >= 70}
print(lulus)     # {'Budi': 80, 'Citra': 92}
```

Mengubah list of dict jadi index:

```python
user = [{"id": 1, "nama": "A"}, {"id": 2, "nama": "B"}]
per_id = {u["id"]: u for u in user}
```

## Generator expression — kurung biasa

Ganti kurung siku dengan kurung biasa, dan hasilnya **tidak dibuat sekaligus** di memori:

```python
kuadrat_list = [x * x for x in range(1_000_000)]   # ±40 MB
kuadrat_gen = (x * x for x in range(1_000_000))    # beberapa byte
```

Generator menghasilkan nilai satu per satu saat diminta. Untuk fungsi agregat, ini pilihan terbaik:

```python
print(sum(x * x for x in range(1000)))      # tidak perlu kurung ganda
print(any(n < 0 for n in nilai))
print(max(len(k) for k in kata))
```

Bedanya: generator **habis sekali pakai** dan tidak punya `len()` atau index. Kalau butuh itu, pakai list.

Generator dibahas tuntas di Modul 5.

## Comprehension bersarang

```python
matriks = [[1, 2], [3, 4]]
datar = [x for baris in matriks for x in baris]
print(datar)    # [1, 2, 3, 4]
```

Urutan `for`-nya **sama seperti kalau ditulis nested loop biasa**, dari luar ke dalam:

```python
# setara dengan:
datar = []
for baris in matriks:
    for x in baris:
        datar.append(x)
```

Ini sering ditulis terbalik dan hasilnya error. Kalau ragu, tulis loop biasanya dulu lalu ubah.

Membuat matriks:

```python
grid = [[0 for _ in range(3)] for _ in range(2)]
# [[0, 0, 0], [0, 0, 0]]
```

Perhatikan ini **aman**, berbeda dengan `[[0]*3]*2` yang berbagi referensi.

## Kapan JANGAN pakai comprehension

Comprehension bagus kalau **muat dibaca sekali lihat**. Kalau sudah begini:

```python
hasil = [transform(x) if cek(x) else fallback(x) for y in data for x in y if x and x.aktif]
```

...tulis saja loop biasa. Kode dibaca jauh lebih sering daripada ditulis.

Juga jangan pakai comprehension hanya untuk efek samping:

```python
[print(x) for x in data]      # ❌ membuat list sampah berisi None
for x in data: print(x)       # ✅
```

## Ringkasan

- `[ekspresi for item in data if kondisi]` menggantikan pola loop + append, dan lebih cepat.
- `if` di belakang menyaring; `if/else` di depan memilih nilai.
- Ada juga dict comprehension `{k: v for ...}` dan set comprehension.
- Kurung biasa membuat generator expression — hemat memori untuk data besar.
- Comprehension bersarang memakai urutan `for` dari luar ke dalam.

## Kesalahan umum

- Menaruh `if` tanpa `else` di posisi depan → `SyntaxError`.
- Membalik urutan `for` pada comprehension bersarang.
- Memakai comprehension hanya untuk efek samping seperti `print`.
- Membuat comprehension tiga tingkat yang tidak terbaca.
