## Fungsi yang memanggil dirinya sendiri

Pernah lihat boneka matryoshka? Buka satu, di dalamnya ada yang lebih kecil, buka lagi, lebih kecil lagi — sampai ketemu yang paling kecil dan nggak bisa dibuka. Itulah **rekursi**.

```python
def hitung_mundur(n):
    if n == 0:            # base case — boneka terkecil
        print("Selesai!")
        return
    print(n)
    hitung_mundur(n - 1)  # recursive case — buka boneka berikutnya

hitung_mundur(3)
```

```
3
2
1
Selesai!
```

## Dua bagian wajib

Setiap fungsi rekursif harus punya:

1. **Base case** — kondisi berhenti. Tanpa ini, rekursinya nggak pernah selesai.
2. **Recursive case** — memanggil diri sendiri dengan input yang **makin mendekati base case**.

```python
def faktorial(n):
    if n <= 1:                 # base case
        return 1
    return n * faktorial(n - 1)  # recursive case

print(faktorial(5))    # 120
```

Kalau dibongkar:

```
faktorial(5)
= 5 * faktorial(4)
= 5 * 4 * faktorial(3)
= 5 * 4 * 3 * faktorial(2)
= 5 * 4 * 3 * 2 * faktorial(1)
= 5 * 4 * 3 * 2 * 1
= 120
```

## Fibonacci

```python
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(8)])   # [0, 1, 1, 2, 3, 5, 8, 13]
```

Versi ini benar tapi **lambat**: `fib(30)` menghitung nilai yang sama berkali-kali. Perbaikannya dengan cache:

```python
from functools import lru_cache

@lru_cache
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)
```

Sekarang `fib(100)` selesai seketika. (Decorator `@` dibahas di Modul 5.)

## Batas rekursi

Tiap pemanggilan menumpuk memori di "call stack". Python membatasi sekitar 1000 tingkat:

```python
import sys
print(sys.getrecursionlimit())   # 1000

def f(n):
    return f(n + 1)

f(1)    # 💥 RecursionError: maximum recursion depth exceeded
```

Lupa base case = error yang sama.

## Kapan rekursi layak dipakai?

Bagus untuk data yang bentuknya **bersarang**: struktur folder, pohon kategori, JSON bertingkat, menu bertingkat.

```python
def flatten(data):
    hasil = []
    for item in data:
        if isinstance(item, list):
            hasil.extend(flatten(item))   # item ini list -> gali lagi
        else:
            hasil.append(item)
    return hasil

print(flatten([1, [2, [3, [4]]]]))   # [1, 2, 3, 4]
```

Untuk perulangan biasa (menjumlah list, mencetak angka), `for` lebih sederhana dan lebih cepat.

## Ringkasan

- Rekursi = fungsi memanggil dirinya sendiri.
- Wajib punya base case, dan tiap panggilan harus mendekat ke base case.
- Cocok untuk data bersarang; untuk kasus sederhana pakai loop.
- Rekursi terlalu dalam menghasilkan `RecursionError`.

## Kesalahan umum

- Lupa base case → `RecursionError`.
- Base case ada, tapi argumennya tidak pernah berubah mendekatinya.
- Memakai rekursi untuk kasus yang jelas lebih cocok pakai `for`.
