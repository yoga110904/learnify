## String itu deretan karakter

Anggap string sebagai gerbong kereta: tiap karakter punya nomor kursi, dimulai dari **0**.

```
 P  y  t  h  o  n
 0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

```python
teks = "Python"
print(teks[0])    # P
print(teks[5])    # n
print(teks[-1])   # n   (dari belakang)
print(teks[-2])   # o
print(teks[10])   # 💥 IndexError: string index out of range
```

Index negatif sangat berguna karena kamu tidak perlu tahu panjangnya:

```python
print(teks[-1])         # karakter terakhir
print(teks[len(teks)-1])  # sama, tapi bertele-tele
```

## Slicing: `teks[start:stop:step]`

```python
teks = "Python"
print(teks[1:4])    # yth   (index 1,2,3 — 4 tidak ikut)
print(teks[:3])     # Pyt   (dari awal)
print(teks[3:])     # hon   (sampai akhir)
print(teks[:])      # Python (salinan penuh)
print(teks[::2])    # Pto   (loncat 2)
print(teks[::-1])   # nohtyP (dibalik!)
print(teks[-3:])    # hon   (3 karakter terakhir)
```

Slicing **tidak pernah error** walaupun index-nya kelewat:

```python
print(teks[2:100])    # thon   -> aman
print(teks[100:])     # ""     -> string kosong
```

Ini beda dengan `teks[100]` yang langsung `IndexError`. Sifat itu sering dimanfaatkan untuk memotong teks dengan aman:

```python
judul = teks[:50]     # ambil maksimal 50 karakter, tanpa perlu cek panjang
```

## Method penting

### Membersihkan

```python
t = "  Halo Dunia  "
t.strip()          # "Halo Dunia"   buang spasi kiri & kanan
t.lstrip()         # "Halo Dunia  "
t.rstrip()         # "  Halo Dunia"
"xxhaloxx".strip("x")   # "halo"    buang karakter tertentu
```

### Mengubah huruf

```python
"halo dunia".upper()       # "HALO DUNIA"
"HALO".lower()             # "halo"
"halo dunia".title()       # "Halo Dunia"
"halo dunia".capitalize()  # "Halo dunia"
"Halo".swapcase()          # "hALO"
```

### Mencari & mengganti

```python
"python".find("th")        # 2    -> -1 kalau tidak ketemu
"python".index("th")       # 2    -> ERROR kalau tidak ketemu
"python".count("o")        # 1
"python".replace("o", "0") # "pyth0n"
"aaa".replace("a", "b", 2) # "bba"  -> ganti 2 kali saja
```

Pakai `find` kalau ketidakhadiran itu wajar, `index` kalau seharusnya selalu ada.

### Mengecek

```python
"python".startswith("py")   # True
"data.csv".endswith(".csv") # True
"123".isdigit()             # True
"abc".isalpha()             # True
"abc123".isalnum()          # True
"  ".isspace()              # True
"Halo".istitle()            # True
```

`startswith` dan `endswith` juga menerima tuple:

```python
nama_file = "foto.png"
if nama_file.endswith((".png", ".jpg", ".gif")):
    print("ini gambar")
```

### Memecah & menyatukan

```python
"a,b,c".split(",")          # ['a', 'b', 'c']
"a b  c".split()            # ['a', 'b', 'c']   default: spasi, dan rapat
"a,b,c".split(",", 1)       # ['a', 'b,c']      pecah sekali saja
"baris1\nbaris2".splitlines()  # ['baris1', 'baris2']

"-".join(["a", "b", "c"])   # "a-b-c"
```

`split` dan `join` adalah pasangan yang akan kamu pakai terus waktu mengolah CSV, log, dan teks apa pun.

⚠️ Perhatikan siapa yang punya method-nya: **pemisah**-lah yang punya `.join()`, bukan list-nya.

```python
["a", "b"].join("-")    # 💥 AttributeError
"-".join(["a", "b"])    # ✅
```

### Memisah jadi tiga bagian

```python
"nama@email.com".partition("@")    # ('nama', '@', 'email.com')
```

Berguna kalau kamu mau memisahkan sekali tepat di pemisah pertama dan yakin bagian kirinya utuh.

## `len()` dan operator `in`

```python
print(len("Python"))          # 6
print("th" in "Python")       # True
print("z" not in "Python")    # True
print("Th" in "Python")       # False  -> peka huruf besar/kecil
```

Untuk pencarian yang mengabaikan huruf besar/kecil, samakan dulu:

```python
if "th" in teks.lower():
    ...
```

## String itu immutable

Artinya isinya **nggak bisa diubah di tempat**:

```python
teks = "Python"
teks[0] = "J"     # 💥 TypeError: 'str' object does not support item assignment
```

Yang bisa kita lakukan adalah **bikin string baru**:

```python
teks = "J" + teks[1:]
print(teks)       # Jython
```

Makanya semua method di atas **mengembalikan string baru**, bukan mengubah aslinya:

```python
t = "halo"
t.upper()
print(t)          # halo   <- nggak berubah!
t = t.upper()
print(t)          # HALO   <- baru berubah
```

Ini kesalahan nomor satu saat belajar string. Kalau hasil method-mu "tidak berpengaruh", pasti lupa menyimpannya.

### Konsekuensi performa

Karena immutable, menyambung string di dalam loop itu boros — tiap `+=` membuat string baru:

```python
# ❌ lambat untuk data besar
hasil = ""
for kata in daftar:
    hasil += kata + " "

# ✅ cepat
hasil = " ".join(daftar)
```

Untuk 10 kata bedanya tidak terasa; untuk 100.000 kata bedanya bisa detik vs milidetik.

## Merangkai method

Karena tiap method mengembalikan string baru, kamu bisa menyambungnya:

```python
teks = "  Halo Dunia  "
print(teks.strip().lower().replace(" ", "_"))    # halo_dunia
```

Dibaca dari kiri ke kanan: bersihkan → kecilkan → ganti spasi. Ini pola yang sangat umum untuk normalisasi teks.

## Contoh nyata: normalisasi teks

Sebelum membandingkan input user, biasanya teks "dibersihkan" dulu:

```python
def bersihkan(s):
    return s.strip().lower().replace(" ", "")

print(bersihkan("  Kasur Ini Rusak "))   # kasurinirusak
```

Pola ini persis yang kamu butuhkan buat latihan palindrom.

<div class="latihan"><b>Latihan 5.</b> Tulis fungsi yang menyamarkan email jadi <code>s***a@treetan.com</code> (huruf pertama dan terakhir nama tetap terlihat).</div>

<summary>Lihat jawaban</summary>

```python
def samarkan(email):
    nama, _, domain = email.partition("@")
    if len(nama) <= 2:
        return email
    tengah = "*" * (len(nama) - 2)
    return f"{nama[0]}{tengah}{nama[-1]}@{domain}"

print(samarkan("salsa@treetan.com"))    # s***a@treetan.com
```
</details>

## Ringkasan

- Index dimulai dari 0; index negatif menghitung dari belakang.
- Slicing `[a:b]` mengambil a sampai b-1, aman walaupun index kelewat; `[::-1]` membalik.
- `split`/`join` untuk memecah dan menyatukan teks — pemisah yang punya `.join()`.
- String immutable: method selalu mengembalikan string baru, harus disimpan.
- Menyambung string di loop itu boros; pakai `"".join(...)`.

## Kesalahan umum

- Menulis `t.upper()` tanpa menyimpan hasilnya.
- Mengira `teks[1:4]` ikut mengambil index 4.
- Menulis `list.join("-")` alih-alih `"-".join(list)`.
- Lupa `.strip()` waktu membandingkan input yang mungkin ada spasinya.
