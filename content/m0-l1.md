## Ngoding itu kayak nulis resep masakan

Bayangin kamu nyuruh adik kamu bikin mie instan. Kamu nggak bisa cuma bilang "bikinin mie". Kamu harus ngasih langkah: *rebus air → masukin mie → tunggu 3 menit → tiriskan → campur bumbu*. Urutannya penting, dan satu langkah kelewat bisa bikin hasilnya aneh.

**Bahasa pemrograman** itu cara kita ngasih resep ke komputer. Komputer super patuh tapi super bodoh: dia cuma ngerjain persis apa yang kita tulis, nggak lebih.

Coba bandingkan tiga instruksi ini:

| Instruksi | Yang dipahami komputer |
|---|---|
| "Rapikan datanya" | ❌ tidak ada artinya |
| "Urutkan dari kecil ke besar" | 🤔 masih ambigu — data yang mana? |
| `nilai.sort()` | ✅ jelas dan pasti |

Semakin spesifik, semakin bisa dijalankan. Belajar ngoding sebagian besar adalah belajar **berpikir sespesifik itu**.

## Kenapa Python?

Python dipilih jutaan orang sebagai bahasa pertama karena sintaksnya mirip bahasa Inggris sehari-hari. Bandingin nyetak tulisan di layar:

```python
# Python
print("Halo Dunia")
```

```java
// Java
public class Main {
    public static void main(String[] args) {
        System.out.println("Halo Dunia");
    }
}
```

```c
// C
#include <stdio.h>
int main() {
    printf("Halo Dunia\n");
    return 0;
}
```

Hasilnya sama, tapi Python jauh lebih pendek. Lebih sedikit yang diketik = lebih sedikit yang bisa salah, dan lebih banyak energi tersisa buat memikirkan **masalahnya**, bukan sintaksnya.

Tiga alasan teknis kenapa Python jadi favorit:

1. **Tidak perlu deklarasi tipe.** `umur = 20` sudah cukup, nggak perlu bilang "ini bilangan bulat".
2. **Tidak perlu titik koma dan kurung kurawal.** Struktur ditandai indentasi, yang memang sudah kamu tulis biar rapi.
3. **Library-nya lengkap banget.** Mau baca Excel, kirim email, latih model AI — hampir selalu sudah ada yang bikin.

## Python dipakai buat apa aja?

| Bidang | Contoh nyata | Library populer |
|---|---|---|
| Web | Instagram & Spotify backend | Django, FastAPI |
| Data science | Analisis penjualan, dashboard | pandas, matplotlib |
| **AI / Machine Learning** | Rekomendasi, prediksi, chatbot | scikit-learn, PyTorch |
| Otomasi | Rename 1000 file, scraping harga | os, requests |
| Keuangan | Analisis risiko, backtesting | NumPy, statsmodels |

Yang ketiga itu tujuan akhir kurikulum ini — dan Python praktis jadi bahasa wajib di sana, karena hampir semua library AI ditulis untuknya.

Kenapa AI "milih" Python? Karena bagian beratnya (perkalian matriks raksasa) sebenarnya dijalankan oleh kode C/C++ dan GPU. Python cuma jadi **remote control** yang gampang dipakai manusia. Jadi kamu dapat kenyamanan Python dengan kecepatan C.

## Interpreted vs compiled

Python adalah bahasa **interpreted** (diterjemahkan). Kodenya dibaca dan dijalankan **baris per baris** oleh program bernama *interpreter*.

Analogi: interpreter itu kayak penerjemah lisan yang nerjemahin kalimat demi kalimat saat kamu ngomong. Sedangkan bahasa *compiled* (C, Java, Go) kayak nerjemahin seluruh buku dulu sampai selesai, baru bukunya dibaca.

Konsekuensinya:

- ✅ Kamu bisa langsung jalanin kode tanpa nunggu proses build.
- ✅ Error langsung kelihatan pas baris itu dieksekusi.
- ✅ Bisa coba-coba satu baris di REPL (dibahas lesson berikutnya).
- ⚠️ Jalannya lebih lambat dibanding C — tapi buat 95% kebutuhan, nggak kerasa.
- ⚠️ Typo di baris 100 baru ketahuan waktu baris 100 dijalankan.

```python
print("baris 1")
print("baris 2")
prin("baris 3")   # typo di sini
```

Output:

```
baris 1
baris 2
NameError: name 'prin' is not defined
```

Lihat? Baris 1 dan 2 tetap jalan duluan, baru error muncul di baris 3. Kalau ini bahasa compiled, typo itu ketahuan sebelum apa pun sempat jalan.

## Versi Python

Yang dipakai sekarang adalah **Python 3**. Python 2 sudah resmi pensiun sejak 2020 — kalau kamu ketemu tutorial dengan `print "halo"` (tanpa kurung), itu Python 2 dan sudah usang.

```python
print "halo"      # ❌ Python 2, sekarang error
print("halo")     # ✅ Python 3
```

Kurikulum ini memakai Python 3.10 ke atas.

<details>
<summary>Lihat jawaban</summary>

Konsekuensi praktisnya: di Python, kode yang jarang dijalankan (misalnya di dalam `if` yang hampir tidak pernah benar) bisa menyimpan bug bertahun-tahun tanpa ketahuan. Itu salah satu alasan orang menulis test.

## Ringkasan

- Bahasa pemrograman = cara ngasih instruksi berurutan yang sangat spesifik ke komputer.
- Python populer karena sintaksnya singkat, tidak butuh deklarasi tipe, dan library-nya lengkap.
- Python jadi bahasa utama AI karena berperan sebagai "remote control" untuk kode C/GPU yang cepat.
- Python bersifat *interpreted*: dijalankan baris per baris, error muncul saat baris itu dieksekusi.
- Yang dipakai sekarang adalah Python 3; Python 2 sudah pensiun.

## Kesalahan umum

- Mengira Python cuma buat data science. Padahal serba bisa.
- Mengikuti tutorial Python 2 tanpa sadar (ciri khas: `print` tanpa kurung).
- Lupa bahwa komputer nggak bisa nebak maksud kita — urutan langkah harus jelas.
- Mengira "lambat"-nya Python jadi masalah di semua kasus; untuk mayoritas program, bottleneck-nya justru jaringan atau disk.
