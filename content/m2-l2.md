## Tuple: list yang dikunci

**Tuple** mirip list, tapi setelah dibuat isinya **tidak bisa diubah** (immutable). Ditulis dengan kurung biasa:

```python
titik = (10, 20)
warna = ("merah", "hijau", "biru")
satu = (5,)        # perhatikan koma! tanpa koma itu cuma angka 5
kosong = ()
```

```python
titik[0] = 99     # 💥 TypeError: 'tuple' object does not support item assignment
```

Bahkan kurungnya opsional — yang membuat tuple sebenarnya **komanya**:

```python
t = 1, 2, 3
print(type(t))     # <class 'tuple'>
```

Itu sebabnya `return a, b` dari sebuah fungsi sebenarnya mengembalikan satu tuple.

## Kapan pakai tuple?

| Alasan | Contoh |
|---|---|
| Data yang memang tidak boleh berubah | koordinat, tanggal, konfigurasi |
| Menandakan "ini satu kesatuan" | `(lintang, bujur)` |
| Sedikit lebih cepat & hemat memori | data besar yang cuma dibaca |
| Bisa jadi **kunci dictionary** | `{(0, 0): "asal"}` |

Poin terakhir itu kemampuan yang list tidak punya:

```python
peta = {(0, 0): "rumah", (1, 2): "sekolah"}
print(peta[(1, 2)])     # sekolah

peta = {[0, 0]: "rumah"}    # 💥 TypeError: unhashable type: 'list'
```

Alasannya: kunci dict harus punya nilai hash yang stabil. Kalau isinya bisa berubah, hash-nya ikut berubah dan datanya jadi tidak bisa ditemukan lagi.

⚠️ Immutable-nya tuple cuma **satu lapis**. Kalau isinya list, list itu tetap bisa diubah:

```python
t = (1, [2, 3])
t[1].append(4)
print(t)     # (1, [2, 3, 4])   isinya berubah!
```

## Unpacking

Membongkar isi tuple ke beberapa variabel sekaligus:

```python
titik = (10, 20)
x, y = titik
print(x, y)     # 10 20
```

Ini yang bikin trik tukar nilai jalan:

```python
a, b = b, a       # sisi kanan otomatis jadi tuple
```

Fungsi yang "mengembalikan dua nilai" sebenarnya mengembalikan tuple:

```python
def bagi(a, b):
    return a // b, a % b

hasil, sisa = bagi(7, 2)
print(hasil, sisa)     # 3 1
```

### Unpacking dengan `*`

Kalau jumlahnya tidak pasti, `*` menampung sisanya sebagai **list**:

```python
angka = [1, 2, 3, 4, 5]

pertama, *sisa = angka
print(pertama, sisa)        # 1 [2, 3, 4, 5]

*awal, terakhir = angka
print(awal, terakhir)       # [1, 2, 3, 4] 5

pertama, *tengah, terakhir = angka
print(tengah)               # [2, 3, 4]
```

Pola ini sangat berguna saat mengurai baris data yang kolomnya banyak:

```python
baris = "Budi,80,90,75,60"
nama, *nilai = baris.split(",")
print(nama, nilai)     # Budi ['80', '90', '75', '60']
```

### Mengabaikan nilai

Konvensi: pakai `_` untuk nilai yang tidak dipakai.

```python
_, umur, _ = ("Budi", 20, "Bandung")
print(umur)     # 20
```

## Set: koleksi unik tanpa urutan

**Set** otomatis membuang duplikat. Ditulis dengan kurung kurawal:

```python
angka = {1, 2, 2, 3, 3, 3}
print(angka)               # {1, 2, 3}
print(len({1, 1, 2, 3}))   # 3
```

⚠️ Set **tidak punya urutan** dan **tidak bisa diakses pakai index**:

```python
angka[0]     # 💥 TypeError: 'set' object is not subscriptable
```

Set kosong harus ditulis `set()`, karena `{}` itu dictionary kosong:

```python
print(type({}))       # <class 'dict'>
print(type(set()))    # <class 'set'>
```

Isi set harus immutable — jadi boleh angka, string, dan tuple, tapi tidak boleh list.

### Menambah & menghapus

```python
s = {1, 2}
s.add(3)            # tambah satu
s.update([4, 5])    # tambah banyak
s.discard(9)        # hapus, aman kalau tidak ada
s.remove(9)         # 💥 KeyError kalau tidak ada
```

### Operasi himpunan

Ini persis pelajaran himpunan di sekolah:

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)   # {1,2,3,4,5}   union (gabungan)
print(a & b)   # {3}           intersection (irisan)
print(a - b)   # {1,2}         difference (ada di a, tidak di b)
print(a ^ b)   # {1,2,4,5}     symmetric difference (tidak di keduanya)
```

Bentuk method-nya: `a.union(b)`, `a.intersection(b)`, `a.difference(b)`.

Contoh nyata:

```python
kemarin = {"budi", "ani", "citra"}
hari_ini = {"ani", "dedi"}

print(hari_ini - kemarin)   # {'dedi'}        user baru
print(kemarin - hari_ini)   # {'budi','citra'} user yang hilang
print(kemarin & hari_ini)   # {'ani'}          user setia
```

Tiga baris untuk analisis yang biasanya butuh puluhan baris loop.

### Set sangat cepat untuk mengecek keanggotaan

```python
data_list = list(range(1_000_000))
data_set = set(data_list)

999999 in data_list    # lambat — diperiksa satu per satu
999999 in data_set     # instan — lewat hash
```

Kalau kamu harus mengecek `x in ...` ribuan kali pada data besar, ubah dulu jadi set. Ini salah satu optimasi paling mudah dan paling berdampak di Python.

## Menghapus duplikat

```python
data = [3, 1, 3, 2, 1]
print(list(set(data)))    # [1, 2, 3]  -> urutannya BISA berubah!
```

Kalau urutan kemunculan pertama harus dipertahankan, jangan pakai `set()` langsung — pakai set hanya sebagai catatan "sudah pernah dilihat":

```python
def hapus_duplikat(data):
    seen = set()
    hasil = []
    for x in data:
        if x not in seen:
            seen.add(x)
            hasil.append(x)
    return hasil
```

Sejak Python 3.7 ada trik satu baris memakai dict (yang mempertahankan urutan):

```python
print(list(dict.fromkeys(data)))    # [3, 1, 2]
```

## Perbandingan cepat

| | list | tuple | set |
|---|---|---|---|
| Ditulis | `[1, 2]` | `(1, 2)` | `{1, 2}` |
| Berurutan | ya | ya | tidak |
| Bisa diubah | ya | tidak | ya (isinya) |
| Boleh duplikat | ya | ya | tidak |
| Bisa jadi kunci dict | tidak | ya | tidak |
| Cek `in` | lambat | lambat | sangat cepat |

## Ringkasan

- Tuple = urutan yang tidak bisa diubah; yang membuatnya tuple adalah koma, bukan kurung.
- Tuple bisa jadi kunci dictionary; list tidak bisa karena tidak hashable.
- Unpacking dengan `*` menampung sisa elemen sebagai list.
- Set = koleksi unik tanpa urutan, mendukung `|`, `&`, `-`, `^`.
- Set sangat cepat untuk pengecekan `in` — optimasi mudah pada data besar.

## Kesalahan umum

- Menulis tuple satu elemen tanpa koma: `(5)` bukan tuple.
- Mengira `list(set(x))` mempertahankan urutan asli.
- Membuat set kosong dengan `{}` (itu dict).
- Mengira tuple berisi list jadi benar-benar tidak bisa diubah.
