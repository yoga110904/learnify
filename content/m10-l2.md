## Tanpa aktivasi, kedalaman tidak ada artinya

Misal dua lapisan tanpa aktivasi:

$$y = W_2(W_1x + b_1) + b_2 = (W_2W_1)x + (W_2b_1 + b_2)$$

Hasilnya tetap berbentuk $Wx + b$ — **satu lapisan linear**. Seratus lapisan pun sama saja.

Fungsi aktivasi menambahkan kelengkungan, dan itulah yang membuat jaringan bisa mempelajari pola rumit.

## Sigmoid

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

sigmoid(np.array([-2., 0., 2.]))    # [0.12 0.5  0.88]
```

Memeras nilai apa pun ke 0–1, jadi cocok sebagai **keluaran** klasifikasi biner.

Kelemahannya: saat `z` sangat besar atau sangat kecil, kurvanya hampir datar sehingga turunannya mendekati nol. Gradien pun ikut mengecil dan lapisan awal berhenti belajar — masalah klasik bernama **vanishing gradient**. Karena itu sigmoid sudah jarang dipakai di lapisan tersembunyi.

⚠️ `np.exp(-z)` bisa meledak untuk `z` yang sangat negatif. Versi amannya:

```python
def sigmoid(z):
    return np.where(z >= 0,
                    1 / (1 + np.exp(-np.clip(z, -500, 500))),
                    np.exp(np.clip(z, -500, 500)) / (1 + np.exp(np.clip(z, -500, 500))))
```

Untuk latihan, `np.clip(z, -500, 500)` saja sudah cukup.

## ReLU — standar modern

$$\text{ReLU}(z) = \max(0, z)$$

```python
def relu(z):
    return np.maximum(0, z)

relu(np.array([-2., 0., 3.]))   # [0. 0. 3.]
```

Sederhana tapi sangat efektif:

- ✅ Cepat dihitung
- ✅ Tidak mengalami vanishing gradient di sisi positif
- ✅ Menghasilkan jaringan yang jarang aktif (*sparse*), yang ternyata membantu
- ⚠️ *Dying ReLU* — neuron yang selalu menghasilkan negatif akan mati selamanya karena gradiennya nol

Solusi untuk yang terakhir, **Leaky ReLU**:

```python
def leaky_relu(z, alpha=0.01):
    return np.where(z > 0, z, alpha * z)
```

ReLU adalah pilihan default untuk lapisan tersembunyi. Kalau ragu, pakai ini.

## Tanh

$$\tanh(z) \in (-1, 1)$$

```python
np.tanh(np.array([-2., 0., 2.]))    # [-0.96 0. 0.96]
```

Mirip sigmoid tapi berpusat di nol, jadi biasanya melatih lebih cepat. Tetap punya masalah vanishing gradient.

## Softmax — untuk banyak kelas

Mengubah sekumpulan angka jadi peluang yang totalnya 1:

$$\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

```python
def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)    # jaga kestabilan angka
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)

softmax(np.array([2.0, 1.0, 0.1]))   # [0.66 0.24 0.10]  jumlahnya 1
```

Dua hal penting:

1. **Kurangi nilai maksimum dulu.** `np.exp(1000)` menghasilkan `inf`. Mengurangi maksimum tidak mengubah hasil tapi mencegah overflow.
2. **`keepdims=True` wajib** supaya pembagiannya bisa di-broadcast per baris.

## Memilih aktivasi

| Posisi | Pilihan |
|---|---|
| Lapisan tersembunyi | **ReLU** (default) |
| Keluaran biner | **Sigmoid** |
| Keluaran banyak kelas | **Softmax** |
| Keluaran regresi | **tanpa aktivasi** |

Keluaran regresi tidak boleh dibatasi — kalau dipaksa sigmoid, model tidak akan pernah bisa memprediksi nilai di luar 0–1.

## Ringkasan

- Tanpa aktivasi non-linear, kedalaman jaringan tidak ada gunanya.
- ReLU adalah default untuk lapisan tersembunyi.
- Sigmoid untuk keluaran biner, softmax untuk banyak kelas, tanpa aktivasi untuk regresi.
- Softmax harus dikurangi nilai maksimumnya dulu agar tidak overflow.

## Kesalahan umum

- Memakai sigmoid di semua lapisan sehingga gradien menghilang.
- Lupa mengurangi maksimum di softmax sehingga muncul `inf` atau `NaN`.
- Memasang sigmoid di keluaran model regresi.
