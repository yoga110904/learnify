## Menyatukan semuanya

Melatih jaringan adalah pengulangan empat langkah:

```
1. Forward   — hitung prediksi
2. Loss      — ukur kesalahan
3. Backward  — hitung gradien
4. Update    — geser bobot berlawanan arah gradien
```

Ulangi ribuan kali. Itu saja isi seluruh deep learning.

## Training loop lengkap

```python
import numpy as np

def latih(X, y, n_hidden=4, lr=0.5, epoch=2000, seed=42):
    rng = np.random.default_rng(seed)
    n_fitur = X.shape[1]
    y = y.reshape(-1, 1)

    params = {
        'W1': rng.normal(0, np.sqrt(2 / n_fitur), (n_fitur, n_hidden)),
        'b1': np.zeros(n_hidden),
        'W2': rng.normal(0, np.sqrt(2 / n_hidden), (n_hidden, 1)),
        'b2': np.zeros(1)
    }

    for i in range(epoch):
        # forward
        Z1 = X @ params['W1'] + params['b1']
        A1 = np.maximum(0, Z1)
        Z2 = A1 @ params['W2'] + params['b2']
        A2 = 1 / (1 + np.exp(-np.clip(Z2, -500, 500)))

        # backward
        n = X.shape[0]
        dZ2 = (A2 - y) / n
        dW2 = A1.T @ dZ2
        db2 = dZ2.sum(axis=0)
        dZ1 = (dZ2 @ params['W2'].T) * (Z1 > 0)
        dW1 = X.T @ dZ1
        db1 = dZ1.sum(axis=0)

        # update
        params['W1'] -= lr * dW1
        params['b1'] -= lr * db1
        params['W2'] -= lr * dW2
        params['b2'] -= lr * db2

    return params
```

Uji dengan XOR — masalah yang tidak bisa diselesaikan satu perceptron:

```python
X = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = np.array([0., 1., 1., 0.])

params = latih(X, y)
# prediksi mendekati [0, 1, 1, 0]  ✅
```

Jaringan dengan satu lapisan tersembunyi berhasil.

## Epoch, batch, iterasi

| Istilah | Artinya |
|---|---|
| **Epoch** | satu putaran penuh melihat seluruh data latih |
| **Batch** | potongan data yang diproses sekali update |
| **Iterasi** | satu kali update bobot |

Tiga gaya pelatihan:

```python
# Batch GD — semua data sekaligus. Stabil tapi lambat & boros memori
# SGD — satu sampel per update. Cepat tapi sangat berisik
# Mini-batch — 32/64/128 sampel. Standar industri ✅
```

Mini-batch mendapat yang terbaik dari keduanya, dan ukurannya pas untuk paralelisasi GPU.

```python
for e in range(epoch):
    idx = rng.permutation(len(X))        # acak tiap epoch
    for i in range(0, len(X), batch_size):

    ...
```

Pengacakan tiap epoch itu penting — tanpa itu, model bisa belajar urutan datanya, bukan polanya.

## Memantau pelatihan

Selalu catat loss dan lihat grafiknya:

```python
riwayat = []
# di dalam loop:
riwayat.append(float(loss))
```

| Gejala | Penyebab |
|---|---|
| Loss turun lalu datar | normal, sudah konvergen |
| Loss naik atau `NaN` | learning rate kebesaran |
| Loss hampir tidak bergerak | learning rate kekecilan, atau data belum distandardisasi |
| Loss latih turun, loss validasi naik | overfitting |

Kalau loss-mu `NaN` di epoch pertama, curigai learning rate atau `log(0)` lebih dulu.

## Optimizer yang lebih pintar

Gradient descent biasa memakai langkah tetap. Optimizer modern mengatur langkahnya sendiri:

- **Momentum** — menyimpan arah sebelumnya, seperti bola menggelinding melewati cekungan kecil
- **RMSProp** — langkah kecil untuk parameter yang gradiennya besar
- **Adam** — gabungan keduanya, dan jadi **pilihan default** di hampir semua proyek

## Dari sini ke framework asli

Yang kamu tulis manual di atas, di PyTorch jadi:

```python
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 4), nn.ReLU(),
    nn.Linear(4, 1), nn.Sigmoid()
)
loss_fn = nn.BCELoss()
opt = torch.optim.Adam(model.parameters(), lr=0.01)

for epoch in range(2000):
    pred = model(X)
    loss = loss_fn(pred, y)
    opt.zero_grad()
    loss.backward()      # backprop otomatis
    opt.step()
```

Backpropagation dihitung otomatis lewat *autograd*. Tapi karena kamu sudah menulisnya sendiri, kamu tahu persis apa yang terjadi di balik `loss.backward()` — dan itu yang membedakan orang yang bisa men-debug model dari yang cuma menyalin kode.

## Ringkasan

- Training = forward → loss → backward → update, diulang ribuan kali.
- Mini-batch (32–128) adalah standar industri.
- Acak urutan data tiap epoch.
- Grafik loss adalah alat diagnosis utama; Adam adalah optimizer default.

## Kesalahan umum

- Lupa mengacak data tiap epoch.
- Menyerah saat loss `NaN` padahal cuma perlu menurunkan learning rate.
- Melatih tanpa memantau loss sama sekali.
