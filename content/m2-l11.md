## Kenapa list "berubah sendiri"?

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)     # [1, 2, 3, 4]   😱 padahal yang diubah b
```

Ini bukan bug. Ini konsekuensi dari cara Python menyimpan data, dan memahaminya menghilangkan seluruh kelas bug yang sangat sulit dilacak.

## Variabel itu label, bukan kotak

Sepanjang Modul 1 kita membayangkan variabel sebagai kotak berisi nilai. Sekarang saatnya menyempurnakan gambarannya:

> **Variabel adalah label yang ditempelkan ke sebuah objek di memori.**

```python
a = [1, 2, 3]     # objek list dibuat, label 'a' ditempel padanya
b = a             # label 'b' ditempel ke objek YANG SAMA
```

Tidak ada penyalinan. Sekarang ada satu list dengan dua label. Mengubahnya lewat label mana pun akan terlihat dari keduanya.

Buktikan dengan `id()` yang menunjukkan alamat objek:

```python
a = [1, 2, 3]
b = a
print(id(a) == id(b))    # True   -> objek yang sama
print(a is b)            # True
```

## Mutable vs immutable

Inilah yang menentukan apakah kamu akan kena masalah ini:

| Immutable (aman) | Mutable (hati-hati) |
|---|---|
| `int`, `float`, `bool` | `list` |
| `str` | `dict` |
| `tuple` | `set` |
| `frozenset` | objek buatan sendiri |

Objek immutable **tidak bisa diubah**, jadi "mengubahnya" sebenarnya membuat objek baru:

```python
x = 5
y = x
y += 1        # membuat objek 6 baru, label y pindah ke sana
print(x)      # 5   -> tidak terpengaruh

s = "halo"
t = s
t += " dunia" # string baru dibuat
print(s)      # halo
```

Itu sebabnya angka dan string tidak pernah menimbulkan masalah ini — sedangkan list dan dict bisa.

## Menyalin dengan benar

### Shallow copy — menyalin satu lapis

```python
a = [1, 2, 3]

b = a.copy()      # cara paling jelas
b = list(a)
b = a[:]

b.append(4)
print(a)          # [1, 2, 3]   ✅ aman
```

Untuk dict:

```python
d2 = d.copy()
d2 = dict(d)
d2 = {**d}
```

### Masalahnya: shallow cuma satu lapis

```python
a = [[1, 2], [3, 4]]
b = a.copy()
b[0].append(99)
print(a)     # [[1, 2, 99], [3, 4]]   😱 masih ikut berubah
```

`copy()` menyalin list luarnya, tapi isinya tetap **referensi ke list dalam yang sama**.

### Deep copy — menyalin sampai ke dalam

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
b[0].append(99)
print(a)     # [[1, 2], [3, 4]]   ✅ aman
```

`deepcopy` lebih lambat dan boros memori, jadi pakai hanya kalau datanya memang bersarang dan kamu benar-benar perlu memisahkannya.

| Cara | Menyalin | Kapan dipakai |
|---|---|---|
| `b = a` | tidak menyalin | kalau memang mau berbagi |
| `a.copy()` | satu lapis | data datar |
| `copy.deepcopy(a)` | semua lapis | data bersarang |

## Jebakan: default argument yang mutable

Ini salah satu jebakan Python paling terkenal:

```python
def tambah(item, daftar=[]):
    daftar.append(item)
    return daftar

print(tambah("a"))    # ['a']
print(tambah("b"))    # ['a', 'b']   😱 harusnya ['b']
```

Penyebabnya: **nilai default dievaluasi sekali saja**, saat fungsi didefinisikan. List yang sama dipakai ulang di semua pemanggilan.

Cara benar:

```python
def tambah(item, daftar=None):
    if daftar is None:
        daftar = []
    daftar.append(item)
    return daftar

print(tambah("a"))    # ['a']
print(tambah("b"))    # ['b']   ✅
```

Aturannya: **jangan pernah memakai list, dict, atau set sebagai nilai default parameter.** Pakai `None` lalu buat di dalam fungsi.

## Fungsi bisa mengubah argumennya

```python
def tambah_nol(data):
    data.append(0)        # mengubah list milik pemanggil!

angka = [1, 2]
tambah_nol(angka)
print(angka)     # [1, 2, 0]
```

Ini sah, tapi bisa mengejutkan. Dua pendekatan:

```python
# 1. sengaja mengubah — beri nama yang jelas dan kembalikan None
def urutkan_di_tempat(data):
    data.sort()

# 2. tidak mengubah — kembalikan objek baru
def urutkan(data):
    return sorted(data)
```

Pilih satu gaya dan konsisten. Fungsi yang diam-diam mengubah argumennya adalah sumber bug yang sulit dilacak.

Kalau ragu, salin dulu di dalam fungsi:

```python
def proses(data):
    data = data.copy()     # mulai dari salinan
    data.append(0)
    return data
```

## `is` vs `==` sekali lagi

Sekarang perbedaannya jadi jelas:

```python
a = [1, 2]
b = [1, 2]
c = a

a == b    # True   isinya sama
a is b    # False  dua objek berbeda
a is c    # True   objek yang sama
```

`==` menanyakan **nilai**, `is` menanyakan **identitas**. Tetap: pakai `is` hanya untuk `None`, `True`, `False`.

## Ringkasan

- Variabel adalah label yang menempel ke objek, bukan kotak berisi nilai.
- `b = a` pada list/dict berarti **berbagi**, bukan menyalin.
- `.copy()` menyalin satu lapis; `copy.deepcopy()` menyalin sampai ke dalam.
- Jangan pernah memakai list/dict sebagai nilai default parameter — pakai `None`.
- Fungsi bisa mengubah argumen mutable milik pemanggil; pilih gaya dan konsisten.

## Kesalahan umum

- Mengira `b = a` membuat salinan.
- Memakai `.copy()` pada data bersarang lalu heran aslinya ikut berubah.
- Menulis `def f(x, daftar=[])`.
- Menulis fungsi yang diam-diam mengubah argumennya tanpa memberi tahu lewat namanya.
