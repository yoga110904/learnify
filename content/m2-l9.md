## Bentuk data yang sesungguhnya

Data dari API, file JSON, atau database jarang datar. Bentuknya hampir selalu **dict berisi list berisi dict**:

```python
response = {
    "status": 200,
    "data": {
        "user": {"id": 7, "nama": "Salsa"},
        "pesanan": [
            {"id": 1, "total": 50000, "item": ["kopi", "roti"]},
            {"id": 2, "total": 75000, "item": ["teh"]},
        ]
    }
}
```

Membaca struktur seperti ini adalah keterampilan harian seorang programmer.

## Membaca lapis demi lapis

Baca dari luar ke dalam, satu lapis per satu lapis:

```python
print(response["data"]["user"]["nama"])          # Salsa
print(response["data"]["pesanan"][0]["total"])   # 50000
print(response["data"]["pesanan"][0]["item"][1]) # roti
```

Kalau bingung, telusuri bertahap:

```python
d = response["data"]
print(type(d), list(d.keys()))      # dict, ['user', 'pesanan']

p = d["pesanan"]
print(type(p), len(p))              # list, 2

print(p[0].keys())                  # dict_keys(['id','total','item'])
```

Ini teknik debugging yang paling sering menyelamatkan: **cetak `type()` dan `keys()` di tiap lapis** sampai ketemu bentuk yang kamu kira.

## Akses aman untuk data bersarang

`.get()` berantai mencegah crash kalau strukturnya tidak lengkap:

```python
nama = response.get("data", {}).get("user", {}).get("nama", "tidak ada")
```

Kuncinya `{}` sebagai default — supaya `.get()` berikutnya tetap punya dict untuk dipanggil.

Untuk struktur yang sangat dalam, tulis fungsi bantu:

```python
def ambil(data, *kunci, default=None):
    for k in kunci:
        if isinstance(data, dict):
            data = data.get(k)
        elif isinstance(data, list) and isinstance(k, int) and -len(data) <= k < len(data):
            data = data[k]
        else:
            return default
        if data is None:
            return default
    return data

print(ambil(response, "data", "user", "nama"))        # Salsa
print(ambil(response, "data", "alamat", "kota", default="-"))   # -
```

## Looping data bersarang

```python
for pesanan in response["data"]["pesanan"]:
    print(f"Pesanan #{pesanan['id']}: Rp{pesanan['total']:,}")
    for item in pesanan["item"]:
        print("  -", item)
```

⚠️ Perhatikan kutipnya: di dalam f-string yang memakai kutip ganda, kunci dict ditulis dengan kutip **tunggal** — `f"{pesanan['id']}"`. Kutip yang sama akan menutup string lebih awal dan menyebabkan error.

## Membentuk ulang data

Tugas paling sering: mengubah bentuk data agar mudah dipakai.

### List of dict → dict (index by id)

```python
pesanan = response["data"]["pesanan"]
per_id = {p["id"]: p for p in pesanan}
print(per_id[2]["total"])     # 75000
```

Sekarang pencarian berdasarkan id jadi instan, bukan melewati list satu per satu.

### Mengelompokkan

```python
data = [
    {"kota": "Bandung", "total": 50},
    {"kota": "Jakarta", "total": 70},
    {"kota": "Bandung", "total": 30},
]

grup = {}
for d in data:
    grup.setdefault(d["kota"], []).append(d["total"])
print(grup)     # {'Bandung': [50, 30], 'Jakarta': [70]}
```

`setdefault` menghindari pengecekan "kalau kunci belum ada, buat dulu". Versi yang lebih bersih memakai `defaultdict`:

```python
from collections import defaultdict

grup = defaultdict(list)
for d in data:
    grup[d["kota"]].append(d["total"])
```

Dengan `defaultdict(list)`, kunci yang belum ada otomatis dibuat berisi list kosong.

### Meringkas per kelompok

```python
ringkas = {kota: sum(nilai) for kota, nilai in grup.items()}
print(ringkas)     # {'Bandung': 80, 'Jakarta': 70}
```

Pola **kelompokkan lalu ringkas** ini persis yang nanti dilakukan `groupby` di pandas — cuma di sana satu baris.

## JSON dan dict

JSON adalah format teks; dict adalah objek Python. Keduanya berpasangan:

```python
import json

teks = '{"nama": "Salsa", "umur": 21}'
data = json.loads(teks)        # teks  -> dict
print(data["nama"])

kembali = json.dumps(data, indent=2)   # dict -> teks
print(kembali)
```

Perbedaan penulisan yang perlu diingat:

| JSON | Python |
|---|---|
| `true` / `false` | `True` / `False` |
| `null` | `None` |
| kunci **harus** kutip ganda | boleh kutip tunggal |

Karena itu kamu tidak bisa menempel JSON mentah ke kode Python begitu saja — pakai `json.loads()`.

## Meratakan data bersarang

Kadang kamu butuh bentuk datar untuk disimpan ke CSV:

```python
baris = []
for p in response["data"]["pesanan"]:
    baris.append({
        "user": response["data"]["user"]["nama"],
        "pesanan_id": p["id"],
        "total": p["total"],
        "jumlah_item": len(p["item"]),
    })

for b in baris:
    print(b)
# {'user': 'Salsa', 'pesanan_id': 1, 'total': 50000, 'jumlah_item': 2}
# {'user': 'Salsa', 'pesanan_id': 2, 'total': 75000, 'jumlah_item': 1}
```

Bentuk seperti ini yang nanti langsung bisa diberikan ke pandas.

## Ringkasan

- Data nyata berbentuk dict berisi list berisi dict; baca dari luar ke dalam.
- Saat bingung, cetak `type()` dan `.keys()` di tiap lapis.
- `.get()` berantai dengan default `{}` mencegah crash pada struktur tidak lengkap.
- `setdefault` dan `defaultdict` menyederhanakan pengelompokan data.
- JSON ↔ dict lewat `json.loads()` dan `json.dumps()`; perhatikan `true`/`True` dan `null`/`None`.

## Kesalahan umum

- Memakai kutip ganda di dalam f-string berkutip ganda.
- Memakai default `None` pada `.get()` berantai sehingga lapis berikutnya error.
- Menempel JSON mentah ke kode Python tanpa `json.loads()`.
- Mencari berulang kali di list padahal bisa di-index jadi dict sekali di awal.
