## Program biasa vs machine learning

Program biasa: kamu menulis aturannya.

```python
def spam(email):
    if "menang undian" in email:
        return True
    if "transfer sekarang" in email:
        return True
    return False
```

Masalahnya, spammer terus mengubah kalimat. Kamu akan menulis aturan selamanya.

**Machine learning membalik arahnya:** kamu memberi contoh, mesin yang menemukan aturannya.

```
Program biasa:      data + aturan   → jawaban
Machine learning:   data + jawaban  → aturan
```

Kamu kasih 10.000 email berlabel spam/bukan, model menemukan sendiri pola yang membedakannya.

## Kapan ML layak dipakai?

✅ Cocok kalau:
- Aturannya rumit atau terus berubah (deteksi penipuan, rekomendasi)
- Polanya ada tapi sulit ditulis manusia (mengenali wajah)
- Datanya banyak dan berlabel

❌ Tidak cocok kalau:
- Aturannya sederhana dan tetap — `if umur >= 17` tidak butuh ML
- Datanya sedikit atau tidak berlabel
- Kesalahan fatal dan keputusan harus 100% bisa dijelaskan

## Kosakata wajib

```python
import numpy as np

X = np.array([[165, 55],     # fitur (input)
              [170, 65],
              [158, 48]])

y = np.array([0, 1, 0])      # label / target (jawaban)
```

| Istilah | Artinya |
|---|---|
| **Fitur (X)** | kolom input, selalu huruf besar karena matriks |
| **Label (y)** | jawaban yang ingin diprediksi, huruf kecil karena vektor |
| **Sampel** | satu baris data |
| **Model** | fungsi hasil belajar yang memetakan X → y |
| **Training** | proses mencari parameter terbaik |
| **Inference** | memakai model untuk memprediksi data baru |

## Tiga jenis machine learning

### 1. Supervised — belajar dari jawaban

Datanya punya label. Ini 90% kasus di dunia nyata.

| Jenis | Keluaran | Contoh |
|---|---|---|
| **Regresi** | angka kontinu | harga rumah, suhu besok |
| **Klasifikasi** | kategori | spam/bukan, jenis penyakit |

Aturan sederhananya: kalau jawabannya "berapa" → regresi. Kalau "yang mana" → klasifikasi.

### 2. Unsupervised — belajar tanpa jawaban

Tidak ada label; model mencari struktur sendiri.

- **Clustering** — mengelompokkan pelanggan mirip (K-Means)
- **Reduksi dimensi** — meringkas 100 fitur jadi 2 (PCA)
- **Deteksi anomali** — menemukan transaksi tidak wajar

### 3. Reinforcement — belajar dari hadiah

Agen mencoba, dapat reward atau penalti, lalu memperbaiki strateginya. Dipakai di game, robotika, dan tahap akhir pelatihan LLM (RLHF).

## scikit-learn: satu pola untuk semua model

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()     # 1. buat
model.fit(X, y)                # 2. latih
model.predict(X_baru)          # 3. prediksi
model.score(X, y)              # 4. nilai
```

Pola `fit` / `predict` / `score` **identik** untuk semua model di scikit-learn. Ganti `LinearRegression()` jadi `RandomForestClassifier()`, sisa kodenya tidak berubah. Ini yang membuat eksperimen jadi cepat.

## Ringkasan

- ML membalik arah: dari data + jawaban, mesin menemukan aturannya.
- X = fitur (matriks), y = label (vektor).
- Supervised (regresi/klasifikasi), unsupervised, reinforcement.
- scikit-learn memakai pola `fit` → `predict` → `score` untuk semua model.

## Kesalahan umum

- Memakai ML untuk masalah yang aturannya sudah jelas.
- Tertukar regresi (angka) dan klasifikasi (kategori).
- Mengira model bagus itu soal algoritma, padahal kualitas data lebih menentukan.
