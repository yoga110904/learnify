## Satu variabel, banyak isi

Kalau kamu punya nilai 30 siswa, masa bikin 30 variabel? **List** adalah wadah yang bisa menampung banyak nilai berurutan.

```python
nilai = [80, 75, 92, 60]
buah = ["apel", "jeruk", "mangga"]
campur = [1, "dua", 3.0, True]      # boleh campur tipe
kosong = []
```

## Akses dan ubah

Sama seperti string, index dimulai dari 0.

```python
buah = ["apel", "jeruk", "mangga"]
print(buah[0])      # apel
print(buah[-1])     # mangga
print(buah[0:2])    # ['apel', 'jeruk']
```

Bedanya dengan string: list **mutable** (bisa diubah di tempat).

```python
buah[1] = "pisang"
print(buah)         # ['apel', 'pisang', 'mangga']
```

## Method yang wajib hafal

```python
b = ["apel", "jeruk"]

b.append("mangga")      # tambah di akhir  -> ['apel','jeruk','mangga']
b.insert(1, "nanas")    # sisipkan di index 1
b.remove("jeruk")       # hapus berdasarkan NILAI
x = b.pop()             # ambil & hapus elemen terakhir
y = b.pop(0)            # ambil & hapus index 0
```

```python
n = [3, 1, 2]
n.sort()                # [1, 2, 3]        mengubah list asli
n.sort(reverse=True)    # [3, 2, 1]
n.reverse()             # membalik urutan
n.index(2)              # posisi nilai 2
n.count(3)              # berapa kali 3 muncul
```

### `sorted()` vs `.sort()`

Ini sering ditanya waktu interview:

```python
a = [3, 1, 2]
b = sorted(a)      # b = [1,2,3], a TETAP [3,1,2]  -> bikin list BARU
a.sort()           # a jadi [1,2,3], mengembalikan None
```

Jebakannya:

```python
a = [3, 1, 2]
a = a.sort()
print(a)     # None 😱
```

Karena `.sort()` mengembalikan `None`, bukan listnya.

## Fungsi agregat

```python
n = [80, 75, 92, 60]
print(len(n))    # 4
print(sum(n))    # 307
print(max(n))    # 92
print(min(n))    # 60
print(sum(n) / len(n))   # 76.75
```

Hati-hati `sum(n) / len(n)` saat list kosong → `ZeroDivisionError`. Selalu cek dulu:

```python
def rata(n):
    if not n:          # list kosong = falsy
        return 0
    return sum(n) / len(n)
```

## Jebakan: list itu "titipan alamat"

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)     # [1, 2, 3, 4]  <- ikut berubah!
```

`b = a` tidak menyalin isi, cuma menempelkan label baru ke kotak yang sama. Kalau mau salinan asli:

```python
b = a.copy()      # atau list(a), atau a[:]
```

## Ringkasan

- List menyimpan banyak nilai berurutan dan bisa diubah (mutable).
- `append`, `insert`, `remove`, `pop` untuk menambah/menghapus.
- `sorted()` bikin list baru; `.sort()` mengubah list asli dan mengembalikan `None`.
- `b = a` berbagi list yang sama — pakai `.copy()` untuk menyalin.

## Kesalahan umum

- `a = a.sort()` lalu heran hasilnya `None`.
- Menghapus elemen sambil melakukan loop pada list yang sama.
- Lupa mengecek list kosong sebelum membagi dengan `len()`.
