## Kalau list itu absen, dictionary itu kamus

Di list kamu cari data pakai nomor urut. Di **dictionary** kamu cari pakai **kata kunci** — persis kamus: cari kata, dapat artinya.

```python
siswa = {
    "nama": "Salsa",
    "umur": 21,
    "aktif": True
}
print(siswa["nama"])    # Salsa
```

Formatnya `{kunci: nilai, ...}`. Kunci biasanya string, nilainya bebas.

## Menambah, mengubah, menghapus

```python
siswa["kota"] = "Bandung"     # tambah kunci baru
siswa["umur"] = 22            # ubah nilai kunci yang ada
del siswa["aktif"]            # hapus
nilai = siswa.pop("kota")     # ambil sekaligus hapus
```

## `.get()` — akses yang tidak bikin crash

```python
print(siswa["email"])        # 💥 KeyError
print(siswa.get("email"))    # None  — aman
print(siswa.get("email", "-"))  # "-"  — pakai default
```

Ini sangat penting waktu memproses data dari API: field-nya belum tentu selalu ada.

## Looping dictionary

```python
d = {"a": 1, "b": 2}

for k in d:               # default: looping kunci
    print(k)              # a b

for k in d.keys():        # sama saja, lebih eksplisit
    print(k)

for v in d.values():
    print(v)              # 1 2

for k, v in d.items():    # ⭐ paling sering dipakai
    print(k, "=", v)      # a = 1 / b = 2
```

## Pola menghitung frekuensi

Ini pola klasik yang muncul di mana-mana:

```python
kalimat = "aku dan kamu dan dia"
hitung = {}
for kata in kalimat.split():
    hitung[kata] = hitung.get(kata, 0) + 1
print(hitung)
# {'aku': 1, 'dan': 2, 'kamu': 1, 'dia': 1}
```

Bacanya: *ambil nilai lama (kalau belum ada anggap 0), tambah 1, simpan lagi.*

## Dictionary bersarang = bentuk asli JSON

Data dari API hampir selalu berbentuk seperti ini:

```python
response = {
    "status": 200,
    "data": {
        "user": {"id": 7, "nama": "Salsa"},
        "roles": ["admin", "qa"]
    }
}

print(response["data"]["user"]["nama"])   # Salsa
print(response["data"]["roles"][0])       # admin
```

Baca dari luar ke dalam, satu lapis per satu lapis. Pakai `.get()` berantai kalau strukturnya nggak pasti:

```python
nama = response.get("data", {}).get("user", {}).get("nama", "tidak ada")
```

## Aturan kunci

Kunci harus bertipe **immutable**: string, angka, atau tuple. List nggak bisa jadi kunci.

```python
{"a": 1}          # ✅
{(1, 2): "titik"} # ✅
{[1, 2]: "x"}     # 💥 TypeError: unhashable type
```

## Ringkasan

- Dictionary menyimpan pasangan kunci–nilai; diakses lewat kunci.
- `.get(kunci, default)` aman dari `KeyError`.
- `.items()` untuk looping kunci dan nilai sekaligus.
- Dictionary bersarang adalah bentuk data JSON/API.

## Kesalahan umum

- Mengakses kunci yang belum tentu ada dengan `d["x"]` → `KeyError`.
- Mengira dictionary bisa diakses pakai index angka.
- Lupa bahwa kunci harus unik — kunci yang sama akan saling menimpa.
