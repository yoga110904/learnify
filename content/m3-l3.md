## Satu file ribuan baris = mimpi buruk

Begitu program membesar, kodenya dipecah jadi beberapa file. Di Python, **satu file `.py` = satu modul**.

```
proyek/
├── main.py
├── kalkulator.py
└── utils/
    ├── __init__.py
    └── teks.py
```

`kalkulator.py`:

```python
def tambah(a, b):
    return a + b

PI = 3.14159
```

`main.py`:

```python
import kalkulator

print(kalkulator.tambah(2, 3))   # 5
print(kalkulator.PI)
```

## Tiga gaya import

```python
import math                 # semua isi, dipanggil math.sqrt()
from math import sqrt       # cuma sqrt, dipanggil sqrt()
from math import sqrt, pi   # beberapa sekaligus
import numpy as np          # alias — biar pendek
from math import *          # ❌ hindari: nama bisa bentrokan
```

Aturan praktis: `import modul` bikin asal-usul fungsi jelas; `from ... import` bikin kode lebih pendek. Jangan pernah `import *` di kode serius.

## Package = folder berisi modul

Folder dengan file `__init__.py` di dalamnya dianggap sebagai **package**:

```python
from utils.teks import bersihkan
```

Di Python 3 modern `__init__.py` boleh kosong dan bahkan opsional, tapi menaruhnya bikin niat kita jelas dan aman di semua tool.

## `if __name__ == "__main__":`

Setiap modul punya variabel bawaan `__name__`:

- Kalau file itu **dijalankan langsung** → `__name__` bernilai `"__main__"`.
- Kalau file itu **di-import** → `__name__` bernilai nama modulnya.

```python
# kalkulator.py
def tambah(a, b):
    return a + b

if __name__ == "__main__":
    print("tes cepat:", tambah(2, 3))
```

Jalankan `python kalkulator.py` → baris tes ikut tercetak.
Tapi waktu `import kalkulator` dari file lain → baris tes **tidak** ikut jalan.

Tanpa penjaga ini, semua kode di level atas modul akan ikut dieksekusi setiap kali di-import — bikin efek samping yang bikin pusing (dan bikin pytest berulah).

## Python nyari modul di mana?

Berurutan: folder file yang sedang dijalankan → folder di `PYTHONPATH` → folder instalasi library.

```python
import sys
print(sys.path)
```

Karena itu **jangan menamai file kamu sama dengan modul bawaan** — `random.py`, `json.py`, atau `math.py` buatan sendiri akan menutupi yang asli dan bikin error aneh.

## Ringkasan

- Satu file `.py` = satu modul; folder ber-`__init__.py` = package.
- `import x`, `from x import y`, dan alias `as` adalah tiga gaya import.
- `if __name__ == "__main__":` memisahkan kode "dijalankan langsung" dari "di-import".
- Hindari `from x import *` dan nama file yang bentrok dengan modul bawaan.

## Kesalahan umum

- Menamai file `random.py` lalu `import random` jadi error.
- Lupa `__main__` guard sehingga kode uji ikut jalan saat di-import.
- Import melingkar (A import B, B import A).
