## Program yang bisa mengambil keputusan

Sampai sekarang program kita jalan lurus dari atas ke bawah. Sekarang kita kasih dia percabangan — kayak Google Maps yang bilang "kalau macet, lewat jalan alternatif".

```python
umur = 20

if umur >= 17:
    print("Boleh bikin SIM")
else:
    print("Belum cukup umur")
```

Struktur dasarnya:

```
if  <kondisi>:
    <dijalankan kalau kondisi True>
else:
    <dijalankan kalau kondisi False>
```

Dua hal wajib: **titik dua** `:` di akhir baris, dan **indentasi** (menjorok) di baris dalamnya.

`else` itu opsional. Kalau tidak ada dan kondisinya `False`, Python cuma melewatinya:

```python
if umur >= 17:
    print("Dewasa")
print("Selesai")       # selalu jalan
```

## Indentasi itu sintaks, bukan hiasan

Bahasa lain pakai kurung kurawal `{}` buat menandai blok. Python pakai **spasi**.

```python
if True:
    print("A")     # bagian dari if
    print("B")     # bagian dari if
print("C")         # di luar if, selalu jalan
```

Standarnya **4 spasi**. Yang penting konsisten dalam satu file — campur tab dan spasi bikin `IndentationError` atau, lebih parah, kode yang jalan tapi salah.

Setel editormu sekali saja: di VS Code, klik "Spaces: 4" di status bar bawah → *Indent Using Spaces* → 4.

Dua error indentasi yang sering muncul:

```python
if True:
print("halo")        # 💥 IndentationError: expected an indented block

if True:
    print("a")
      print("b")     # 💥 IndentationError: unexpected indent
```

## `elif` untuk banyak pilihan

`elif` = "else if". Python mengecek dari atas, dan **berhenti di kecocokan pertama**.

```python
nilai = 82

if nilai >= 85:
    print("A")
elif nilai >= 70:
    print("B")
elif nilai >= 55:
    print("C")
else:
    print("D")
# Output: B
```

Urutannya sangat penting. Kalau dibalik:

```python
if nilai >= 55:      # ❌ nilai 95 pun kena "C"
    print("C")
elif nilai >= 70:    # tidak pernah tercapai
    print("B")
```

Aturan praktis untuk rentang bertingkat: **mulai dari kondisi paling ketat** (nilai terbesar untuk `>=`, terkecil untuk `<=`).

Kenapa `elif` lebih baik daripada `if` beruntun?

```python
# ❌ semua kondisi tetap dicek, dan bisa mencetak dua kali
if nilai >= 85: print("A")
if nilai >= 70: print("B")

# ✅ berhenti di yang pertama cocok
if nilai >= 85: print("A")
elif nilai >= 70: print("B")
```

## Kondisi bersarang (nested)

```python
punya_tiket = True
umur = 15

if punya_tiket:
    if umur >= 17:
        print("Masuk bioskop")
    else:
        print("Film ini 17+")
else:
    print("Beli tiket dulu")
```

Kalau bersarangnya sudah 3 tingkat ke dalam, biasanya ada cara yang lebih rapi:

```python
# opsi 1: gabung dengan and
if punya_tiket and umur >= 17:
    print("Masuk bioskop")

# opsi 2: keluar lebih awal (guard clause)
if not punya_tiket:
    print("Beli tiket dulu")
elif umur < 17:
    print("Film ini 17+")
else:
    print("Masuk bioskop")
```

Pola **guard clause** (tangani kasus gagal dulu, lalu keluar) membuat kode jauh lebih datar dan mudah dibaca. Ini kebiasaan yang membedakan kode pemula dan kode profesional.

## Rantai perbandingan

Python bisa menulis rentang seperti di matematika:

```python
nilai = 75
if 70 <= nilai < 85:
    print("B")     # jalan
```

Jauh lebih terbaca daripada `nilai >= 70 and nilai < 85`.

## Ternary — `if` satu baris

Kalau cuma memilih antara dua **nilai**:

```python
nilai = 80
status = "lulus" if nilai >= 70 else "gagal"
print(status)     # lulus
```

Bacanya: *ambil "lulus" kalau nilai >= 70, kalau nggak ambil "gagal"*.

Bisa langsung di dalam f-string:

```python
print(f"Kamu {'lulus' if nilai >= 70 else 'gagal'}")
```

Jangan dipakai kalau kondisinya berlapis — ini sah tapi menyiksa pembacanya:

```python
# ❌ jangan
x = "A" if n >= 85 else "B" if n >= 70 else "C" if n >= 55 else "D"
```

## Memilih dari dict

Untuk pemetaan nilai yang banyak, dict sering lebih rapi daripada rantai `elif`:

```python
# ❌ panjang
if hari == 1: nama = "Senin"
elif hari == 2: nama = "Selasa"
elif hari == 3: nama = "Rabu"
...

# ✅ ringkas
HARI = {1: "Senin", 2: "Selasa", 3: "Rabu"}
nama = HARI.get(hari, "Tidak diketahui")
```

Dict dibahas di Modul 2 — ingat polanya, nanti akan sering kepakai.

## `pass` — placeholder

Blok kosong bikin error. Kalau belum mau nulis isinya:

```python
if umur < 0:
    pass   # nanti diisi validasi
else:
    print("ok")
```

## Ringkasan

- `if` / `elif` / `else` bikin program memilih jalur; blok ditandai indentasi 4 spasi dan `:`.
- `elif` berhenti di kecocokan pertama — urutkan dari kondisi paling ketat.
- Guard clause (tangani kasus gagal dulu) membuat kode datar dan mudah dibaca.
- Ternary `a if kondisi else b` untuk memilih dua **nilai**, bukan dua blok kode.
- Pemetaan nilai yang banyak lebih rapi memakai dict daripada rantai `elif`.

## Kesalahan umum

- Lupa titik dua di akhir `if`.
- Indentasi campur tab dan spasi → `IndentationError`.
- Menulis rentang `elif` dari yang paling longgar sehingga cabang lain tak pernah tercapai.
- Bersarang tiga tingkat padahal bisa digabung `and` atau diratakan dengan guard clause.
