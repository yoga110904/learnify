## Mencari pola di dalam teks

"Ambil semua nomor telepon dari dokumen ini." Dengan `find` dan `split` itu menyakitkan. **Regular expression** (regex) dibuat persis untuk itu: bahasa kecil untuk mendeskripsikan pola teks.

```python
import re

teks = "Hubungi 0812-3456-7890 atau 0857-1111-2222"
print(re.findall(r"\d{4}-\d{4}-\d{4}", teks))
# ['0812-3456-7890', '0857-1111-2222']
```

Perhatikan `r"..."` — *raw string*, supaya `\d` tidak dianggap escape character oleh Python. Selalu pakai `r` untuk regex.

## Kosakata dasar

| Pola | Arti |
|---|---|
| `\d` | satu digit angka (`\D` = bukan digit) |
| `\w` | huruf/angka/underscore (`\W` = selainnya) |
| `\s` | spasi/tab/enter (`\S` = bukan spasi) |
| `.` | karakter apa pun (kecuali newline) |
| `[abc]` | salah satu dari a, b, c |
| `[a-z]` | rentang huruf kecil |
| `[^abc]` | apa pun **kecuali** a, b, c |

Pengulangan:

| Pola | Arti |
|---|---|
| `+` | satu atau lebih |
| `*` | nol atau lebih |
| `?` | nol atau satu (opsional) |
| `{3}` | tepat 3 kali |
| `{2,5}` | 2 sampai 5 kali |

Jangkar:

| Pola | Arti |
|---|---|
| `^` | awal teks |
| `$` | akhir teks |

```python
import re

if re.search(r"error", "ada ERROR di sini", re.IGNORECASE):
    print("ketemu")

print(re.sub(r"\s+", " ", "terlalu    banyak   spasi"))
# 'terlalu banyak spasi'

# ['a', 'b', 'c']
```

## Grup — mengambil bagian tertentu

```python
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "tanggal 2026-09-20")
print(m.group(0))    # 2026-09-20   (seluruhnya)
print(m.group(1))    # 2026
print(m.groups())    # ('2026', '09', '20')
```

Grup bernama bikin kode jauh lebih terbaca:

```python
m = re.search(r"(?P<tahun>\d{4})-(?P<bulan>\d{2})", "2026-09")
print(m.group("tahun"))    # 2026
```

## Validasi email sederhana

```python
POLA_EMAIL = r"^[\w.+-]+@[\w-]+\.[\w.-]+$"

def valid_email(s):
    return re.fullmatch(POLA_EMAIL, s) is not None

print(valid_email("a@b.com"))    # True
print(valid_email("a@b"))        # False — tidak ada titik setelah domain
print(valid_email("@b.com"))     # False — tidak ada nama sebelum @
```

Catatan jujur: validasi email yang benar-benar sesuai standar itu sangat rumit. Di dunia nyata, pakai pola sederhana lalu kirim email verifikasi.

## Ringkasan

- Regex mendeskripsikan pola teks, dipakai lewat modul `re`.
- Selalu tulis pola sebagai raw string `r"..."`.
- `search` mencari di mana saja, `fullmatch` mengharuskan seluruh teks cocok.
- Grup `( )` mengambil bagian tertentu dari kecocokan.

## Kesalahan umum

- Lupa `r` sehingga `\d` salah diartikan.
- Memakai `match` padahal maksudnya `search`.
- Membuat regex raksasa yang tak terbaca — pecah jadi beberapa langkah.
