## Mengukur seberapa salah

Setelah forward pass, model punya tebakan. **Loss function** mengubah seberapa jauh tebakan itu dari jawaban benar menjadi satu angka yang bisa dikecilkan.

## MSE — untuk regresi

$$L = \frac{1}{n}\sum (\hat{y} - y)^2$$

```python
import numpy as np

def mse(y_pred, y_asli):
    return np.mean((y_pred - y_asli) ** 2)
```

## Binary Cross-Entropy — untuk klasifikasi biner

$$L = -\frac{1}{n}\sum [y\log(\hat{y}) + (1-y)\log(1-\hat{y})]$$

```python
def bce(y_pred, y_asli, eps=1e-9):
    y_pred = np.clip(y_pred, eps, 1 - eps)     # cegah log(0)
    return -np.mean(y_asli * np.log(y_pred) + (1 - y_asli) * np.log(1 - y_pred))
```

`np.clip` itu wajib — `log(0)` menghasilkan `-inf` dan seluruh pelatihan langsung rusak.

Kenapa tidak pakai MSE saja untuk klasifikasi? Karena cross-entropy **menghukum keyakinan yang salah jauh lebih keras**. Menebak 0,99 padahal jawabannya 0 menghasilkan loss yang sangat besar, sehingga koreksinya juga besar.

## Backpropagation

Kita punya loss. Sekarang: bobot mana yang harus digeser, ke mana, dan seberapa jauh?

Jawabannya adalah gradien loss terhadap tiap bobot. Menghitungnya memakai **aturan rantai** dari kalkulus, dijalankan mundur dari keluaran ke input — karena itu namanya *backpropagation*.

$$\frac{\partial L}{\partial W_1} = \frac{\partial L}{\partial A_2} \times \frac{\partial A_2}{\partial Z_2} \times \frac{\partial Z_2}{\partial A_1} \times \frac{\partial A_1}{\partial Z_1} \times \frac{\partial Z_1}{\partial W_1}$$

Terlihat menakutkan, tapi praktiknya cuma beberapa baris kode yang dikalikan berurutan.

## Turunan yang perlu dihafal

| Operasi | Turunan |
|---|---|
| `Z = A @ W + b` | `dW = A.T @ dZ`, `db = dZ.sum(axis=0)`, `dA = dZ @ W.T` |
| `A = relu(Z)` | `dZ = dA * (Z > 0)` |
| `A = sigmoid(Z)` | `dZ = dA * A * (1 - A)` |
| sigmoid + BCE | `dZ = (A - y) / n` ← hasilnya sederhana sekali |

Baris terakhir itu berkah: kombinasi sigmoid dengan binary cross-entropy membuat suku-sukunya saling menghapus, menyisakan selisih sederhana `prediksi − jawaban`. Hal yang sama berlaku untuk softmax + categorical cross-entropy.

## Backward pass lengkap

```python
def backward(cache, y, params):
    X, A1, A2 = cache['X'], cache['A1'], cache['A2']
    n = X.shape[0]
    grads = {}

    # lapisan keluaran (sigmoid + BCE)
    dZ2 = (A2 - y.reshape(-1, 1)) / n
    grads['W2'] = A1.T @ dZ2
    grads['b2'] = dZ2.sum(axis=0)

    # mundur ke lapisan tersembunyi
    dA1 = dZ2 @ params['W2'].T
    dZ1 = dA1 * (cache['Z1'] > 0)          # turunan ReLU
    grads['W1'] = X.T @ dZ1
    grads['b1'] = dZ1.sum(axis=0)

    return grads
```

Perhatikan simetrinya: forward memakai `X @ W`, backward memakai `X.T @ dZ` dan `dZ @ W.T`. Transpose muncul karena arah alirannya dibalik.

## Memeriksa gradien

Kalau ragu implementasimu benar, bandingkan dengan turunan numerik:

```python
def cek_gradien(f, w, h=1e-5):
    return (f(w + h) - f(w - h)) / (2 * h)
```

Kalau selisihnya di bawah `1e-6`, implementasimu kemungkinan besar benar. Teknik ini menyelamatkan banyak jam debugging.

## Vanishing & exploding gradient

Gradien dikalikan berulang saat melewati lapisan:

- Kalau tiap pengali < 1 → gradien menyusut jadi nol → lapisan awal berhenti belajar
- Kalau tiap pengali > 1 → gradien meledak jadi `NaN`

Penangkalnya: ReLU, inisialisasi yang tepat, normalisasi, dan pemotongan gradien (`np.clip`).

## Ringkasan

- Loss mengubah kesalahan jadi satu angka yang bisa dikecilkan.
- MSE untuk regresi, cross-entropy untuk klasifikasi.
- Backpropagation menghitung gradien mundur memakai aturan rantai.
- Sigmoid + BCE menyederhanakan gradien keluaran jadi `(prediksi − jawaban) / n`.

## Kesalahan umum

- `log(0)` tanpa `clip` sehingga loss jadi `-inf`.
- Lupa transpose sehingga bentuk gradien tidak cocok.
- Lupa membagi jumlah sampel sehingga besaran gradien bergantung ukuran batch.
