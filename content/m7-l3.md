## Data nyata itu kotor

Sebelum dipakai melatih model, data harus dibersihkan. Kenyataannya, **70% waktu proyek AI habis di sini**, bukan di modelnya.

Tiga masalah paling sering: nilai kosong, duplikat, dan tipe data yang salah.

## Mendeteksi nilai kosong

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'nama':  ['Budi', 'Ani', None],
    'umur':  [20, np.nan, 21],
    'nilai': [80, 90, 70]
})

df.isna()             # tabel True/False
df.isna().sum()       # berapa nilai kosong per kolom  <- paling sering dipakai
df.isna().mean()      # proporsinya (0–1)
```

`df.isna().sum()` adalah perintah kedua yang kamu jalankan setelah `df.info()`.

## Menangani nilai kosong

### Buang

```python
df.dropna()                      # buang baris yang punya nilai kosong
df.dropna(subset=['umur'])       # hanya kalau kolom umur kosong
df.dropna(axis=1)                # buang KOLOM-nya
df.dropna(thresh=2)              # simpan baris dengan minimal 2 nilai terisi
```

Aman kalau yang hilang sedikit. Kalau 40% data hilang, membuangnya berarti membuang informasi.

### Isi

```python
df['umur'].fillna(0)                        # isi dengan konstanta
df['umur'].fillna(df['umur'].mean())        # isi dengan rata-rata
df['umur'].fillna(df['umur'].median())      # median — lebih tahan outlier
df['nama'].fillna('tidak diketahui')
```

Untuk data numerik, **median biasanya lebih aman dari mean** karena tidak tertarik nilai ekstrem.

⚠️ Aturan penting: hitung nilai pengisi dari **data latih saja**, lalu pakai nilai yang sama untuk data uji. Kalau tidak, informasi dari data uji "bocor" ke proses latihan (*data leakage*) dan skor modelmu jadi terlalu bagus untuk dipercaya.

## Duplikat

```python
df.duplicated().sum()              # berapa baris kembar
df.drop_duplicates()               # buang, sisakan yang pertama
df.drop_duplicates(subset=['nama'])          # kembar berdasarkan kolom tertentu
df.drop_duplicates(subset=['nama'], keep='last')
```

## Tipe data salah

Kolom angka sering terbaca sebagai teks gara-gara satu baris berisi `"-"` atau `"N/A"`:

```python
df['umur'] = df['umur'].astype(int)                       # error kalau ada teks
df['umur'] = pd.to_numeric(df['umur'], errors='coerce')   # ✅ yang gagal jadi NaN
df['tanggal'] = pd.to_datetime(df['tanggal'], errors='coerce')
```

`errors='coerce'` adalah teman terbaikmu: alih-alih program mati, nilai yang bermasalah ditandai `NaN` dan bisa ditangani belakangan.

## Membersihkan teks

```python
df['nama'] = df['nama'].str.strip().str.title()
df['kota'] = df['kota'].str.lower().replace({'jkt': 'jakarta'})
```

`"Jakarta "`, `"jakarta"`, dan `"JKT"` akan dianggap tiga kategori berbeda kalau tidak dinormalisasi lebih dulu.

## Outlier

```python
q1 = df['nilai'].quantile(0.25)
q3 = df['nilai'].quantile(0.75)
iqr = q3 - q1
batas_bawah, batas_atas = q1 - 1.5 * iqr, q3 + 1.5 * iqr

bersih = df[df['nilai'].between(batas_bawah, batas_atas)]
```

Metode IQR ini standar untuk menandai nilai yang jauh menyimpang. Tapi jangan langsung buang — periksa dulu, kadang outlier justru datanya yang paling menarik.

## Ringkasan

- `df.isna().sum()` untuk memetakan nilai kosong per kolom.
- `dropna` membuang, `fillna` mengisi; median lebih aman dari mean.
- Hitung nilai pengisi dari data latih saja untuk menghindari data leakage.
- `pd.to_numeric(..., errors='coerce')` menyelamatkan kolom angka yang kotor.

## Kesalahan umum

- Langsung `dropna()` tanpa mengecek berapa banyak data yang hilang.
- Mengisi nilai kosong memakai statistik dari seluruh data (termasuk data uji).
- Lupa menormalisasi teks sehingga satu kategori terpecah jadi beberapa.
