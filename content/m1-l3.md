## Program yang bisa diajak ngobrol

Sejauh ini program kita cuma "ngomong sendiri" pakai `print()`. Sekarang kita bikin dia bisa "dengar" pakai `input()`.

```python
nama = input("Siapa namamu? ")
print("Halo", nama)
```

```
Siapa namamu? Salsa
Halo Salsa
```

Alurnya: program **berhenti** di baris `input()`, menunggu user mengetik dan menekan Enter, lalu melanjutkan dengan isi ketikannya.

### `input()` selalu menghasilkan teks

Ini jebakan nomor satu buat pemula:

```python
umur = input("Umur: ")   # user ketik 20
print(umur + 5)          # 💥 TypeError
```

Karena `umur` isinya string `"20"`, bukan angka `20`. Solusinya dibungkus `int()`:

```python
umur = int(input("Umur: "))
print(umur + 5)   # 25
```

Bacanya dari dalam ke luar: `input()` ambil teks → `int()` ubah jadi angka → simpan ke `umur`.

⚠️ Kalau user mengetik huruf, `int()` akan error. Cara menanganinya dibahas di Modul 3 (error handling).

### Beberapa input sekaligus

```python
data = input("Masukkan 3 angka dipisah spasi: ")   # "10 20 30"
a, b, c = data.split()
print(int(a) + int(b) + int(c))    # 60
```

Atau versi ringkasnya:

```python
angka = [int(x) for x in input().split()]
print(sum(angka))
```

Baris kedua itu *list comprehension* — dibahas di Modul 2. Kenali bentuknya dulu.

## `print()` lebih dalam

```python
print("a", "b", "c")                 # a b c   (dipisah spasi)
print("a", "b", sep="-")             # a-b
print("a", "b", sep="")              # ab
print("loading", end="...")          # nggak pindah baris
print("selesai")                     # loading...selesai
```

Default-nya `sep=" "` dan `end="\n"` (pindah baris).

`end=""` sangat berguna untuk mencetak dalam satu baris dari dalam loop:

```python
for i in range(5):
    print(i, end=" ")
print()          # pindah baris di akhir
# 0 1 2 3 4
```

### Karakter khusus (escape sequence)

| Kode | Artinya |
|---|---|
| `\n` | pindah baris |
| `\t` | tab |
| `\\` | backslash literal |
| `\"` | tanda kutip ganda |
| `\'` | tanda kutip tunggal |

```python
print("baris 1\nbaris 2")
print("Nama:\tBudi")
print("Dia bilang \"hai\"")
print("C:\\Users\\Salsa")      # C:\Users\Salsa
```

Kalau backslash-nya banyak (misalnya path Windows atau regex), pakai **raw string** dengan awalan `r`:

```python
print(r"C:\Users\Salsa\nama")   # backslash apa adanya, \n tidak jadi enter
```

### String multi-baris

```python
pesan = """Halo,
Ini baris kedua.
Ini baris ketiga."""
print(pesan)
```

## f-string: cara modern merangkai teks

Sebelum f-string, orang nyambung teks pakai `+` dan itu berantakan:

```python
nama = "Budi"; umur = 20
print("Halo " + nama + ", umurmu " + str(umur) + " tahun")   # 😩
```

Dengan **f-string** (tambahkan `f` sebelum kutip, variabel ditaruh di `{}`):

```python
print(f"Halo {nama}, umurmu {umur} tahun")
# Halo Budi, umurmu 20 tahun
```

Perhatikan: `str(umur)` tidak perlu lagi — f-string otomatis mengubah apa pun jadi teks.

Di dalam `{}` boleh ada ekspresi apa saja:

```python
x = 5
print(f"Dua kali {x} adalah {x * 2}")       # Dua kali 5 adalah 10
print(f"Dewasa? {umur >= 17}")              # Dewasa? True
print(f"Huruf besar: {nama.upper()}")       # Huruf besar: BUDI
print(f"Total: {sum([1, 2, 3])}")           # Total: 6
```

### Format angka

Aturannya `{nilai:format}`:

```python
harga = 1234567.891
print(f"{harga:,.2f}")    # 1,234,567.89   pemisah ribuan + 2 desimal
print(f"{harga:.0f}")     # 1234568        tanpa desimal
print(f"{0.25:.1%}")      # 25.0%          persentase
print(f"{7:03d}")         # 007            3 digit, isi nol di depan
print(f"{255:x}")         # ff             heksadesimal
print(f"{1234:e}")        # 1.234000e+03   notasi ilmiah
```

### Perataan teks

```python
print(f"{'Nama':<10}|{'Nilai':>6}")     # rata kiri 10, rata kanan 6
print(f"{'Budi':<10}|{80:>6}")
print(f"{'Ani':<10}|{92:>6}")
```

```
Nama      | Nilai
Budi      |    80
Ani       |    92
```

| Format | Arti |
|---|---|
| `:<10` | rata kiri selebar 10 |
| `:>10` | rata kanan |
| `:^10` | rata tengah |
| `:*^10` | rata tengah, sisa diisi `*` |

Ini cara termudah membuat tabel rapi di terminal tanpa library apa pun.

### `=` untuk debugging (Python 3.8+)

```python
umur = 20
print(f"{umur=}")          # umur=20
print(f"{umur * 2 = }")    # umur * 2 = 40
```

Sangat berguna saat debugging — nama variabel dan nilainya tercetak sekaligus, jadi kamu tidak perlu mengetik labelnya manual.

## Ringkasan

- `input()` menghentikan program sampai user menekan Enter, dan **selalu** mengembalikan `str`.
- Bungkus dengan `int()` / `float()` kalau butuh angka.
- `print()` punya `sep` dan `end`; `end=""` berguna untuk mencetak dalam satu baris.
- f-string (`f"... {variabel} ..."`) adalah cara paling rapi merangkai teks, dan bisa memuat ekspresi.
- Format angka `:,.2f`, perataan `:<10` / `:>10`, dan `f"{x=}"` untuk debugging.

## Kesalahan umum

- Menghitung langsung dari hasil `input()` tanpa konversi.
- Lupa huruf `f` di depan string, jadi `{nama}` ikut tercetak apa adanya.
- Nyampur kutip yang sama di dalam f-string: `f"{d["k"]}"` → error. Pakai kutip berbeda.
- Lupa `print()` kosong setelah loop yang memakai `end=""`.
