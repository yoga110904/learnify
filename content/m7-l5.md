## Menyatukan data dari banyak sumber

Data nyata jarang ada di satu tabel. Ada tabel transaksi, tabel pelanggan, tabel produk. `merge` menyatukannya — konsepnya sama persis dengan `JOIN` di SQL.

```python
import pandas as pd

siswa = pd.DataFrame({'id': [1, 2, 3], 'nama': ['Budi', 'Ani', 'Citra']})
nilai = pd.DataFrame({'id': [1, 2, 4], 'skor': [80, 90, 70]})

pd.merge(siswa, nilai, on='id')
```

```
   id  nama  skor
0   1  Budi    80
1   2   Ani    90
```

Default-nya `inner` — hanya id yang ada di **kedua** tabel.

## Empat jenis join

```python
pd.merge(siswa, nilai, on='id', how='inner')   # irisan (default)
pd.merge(siswa, nilai, on='id', how='left')    # semua baris kiri
pd.merge(siswa, nilai, on='id', how='right')   # semua baris kanan
pd.merge(siswa, nilai, on='id', how='outer')   # gabungan semuanya
```

`how='left'` yang paling sering dipakai: *pertahankan semua data utamaku, tempelkan info tambahan kalau ada.* Yang tidak ketemu pasangannya diisi `NaN`.

Kalau nama kolom kuncinya beda:

```python
pd.merge(a, b, left_on='id_siswa', right_on='siswa_id', how='left')
```

Selalu cek jumlah baris setelah merge:

```python
print(len(siswa), '->', len(hasil))
```

Kalau tiba-tiba membengkak, berarti kuncinya tidak unik dan barisnya berlipat ganda — bug klasik yang diam-diam merusak dataset.

## `concat` — menumpuk

Merge menyatukan **ke samping** berdasarkan kunci. `concat` menumpuk **ke bawah**:

```python
pd.concat([df_januari, df_februari], ignore_index=True)
```

`ignore_index=True` menomori ulang barisnya supaya tidak ada index kembar.

## Rekayasa fitur

Inilah bagian yang paling menentukan kualitas model. Model bagus dengan fitur jelek tetap kalah dari model sederhana dengan fitur bagus.

### Dari tanggal

```python
df['tanggal'] = pd.to_datetime(df['tanggal'])
df['bulan'] = df['tanggal'].dt.month
df['hari'] = df['tanggal'].dt.dayofweek       # 0 = Senin
df['akhir_pekan'] = df['hari'] >= 5
```

### Dari angka

```python
df['harga_per_unit'] = df['total'] / df['jumlah']
df['log_harga'] = np.log1p(df['harga'])       # menjinakkan distribusi miring
```

### Membuat kategori dari angka

```python
df['kelompok_umur'] = pd.cut(
    df['umur'],
    bins=[0, 17, 35, 60, 100],
    labels=['anak', 'muda', 'dewasa', 'senior']
)
```

`pd.cut` memotong berdasarkan rentang nilai; `pd.qcut` memotong berdasarkan kuantil sehingga tiap kelompok berisi jumlah data yang sama.

### Mengubah kategori jadi angka

Model hanya paham angka. Untuk kategori tanpa urutan, pakai one-hot:

```python
pd.get_dummies(df, columns=['kota'], drop_first=True)
```

```
   nilai  kota_Jakarta  kota_Surabaya
0     80          True          False
```

`drop_first=True` membuang satu kolom karena informasinya sudah bisa disimpulkan dari sisanya — mencegah kolom yang saling bergantung sempurna.

Untuk kategori **berurutan** (rendah < sedang < tinggi), pakai pemetaan manual supaya urutannya tidak hilang:

```python
df['tingkat'] = df['tingkat'].map({'rendah': 0, 'sedang': 1, 'tinggi': 2})
```

## Ringkasan

- `merge` menyatukan tabel berdasarkan kunci; `how='left'` paling sering dipakai.
- Selalu cek jumlah baris sebelum dan sesudah merge.
- `concat` menumpuk data ke bawah.
- `pd.get_dummies` untuk kategori tanpa urutan, `.map()` untuk kategori berurutan.

## Kesalahan umum

- Merge dengan kunci yang tidak unik sehingga baris berlipat ganda.
- Memakai one-hot untuk kategori yang sebenarnya berurutan.
- Membuat fitur dari seluruh data (termasuk data uji) → data leakage.
