## Bagaimana model "belajar"?

Jawabannya satu kalimat: **model menebak, mengukur kesalahannya, lalu menggeser parameternya sedikit ke arah yang mengurangi kesalahan.** Diulang ribuan kali.

Alat untuk menentukan "arah" itu adalah **turunan**.

## Turunan = kemiringan

Turunan menjawab: *kalau input naik sedikit, output berubah ke mana dan seberapa cepat?*

| Fungsi | Turunan |
|---|---|
| $x^2$ | $2x$ |
| $3x$ | $3$ |
| konstanta | $0$ |

Kalau rumusnya susah, hitung secara numerik saja:

```python
def turunan(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

f = lambda x: x ** 2
turunan(f, 3)      # ≈ 6.0
```

Tanda turunannya yang penting:

- turunan **positif** → fungsi naik → untuk mengecilkan, **geser ke kiri**
- turunan **negatif** → fungsi turun → untuk mengecilkan, **geser ke kanan**

Dua-duanya berarti: **bergerak berlawanan arah turunan.**

## Gradient descent

Bayangkan kamu di lereng bukit dalam kabut tebal dan ingin turun. Kamu tidak bisa melihat lembahnya, tapi bisa merasakan kemiringan di bawah kakimu. Strateginya: melangkah kecil ke arah paling menurun, ulangi.

```python
def gradient_descent(f, x0, lr=0.1, langkah=50):
    x = x0
    for _ in range(langkah):
        g = turunan(f, x)
        x = x - lr * g          # <- inti seluruh machine learning
    return x

gradient_descent(lambda x: (x - 3) ** 2, x0=0)    # ≈ 3.0
```

Baris `x = x - lr * g` itulah yang dijalankan miliaran kali saat melatih model besar.

## Learning rate

`lr` menentukan panjang langkah, dan ini hyperparameter paling berpengaruh:

| lr | Akibat |
|---|---|
| terlalu kecil | belajar sangat lambat, mungkin tidak sampai |
| pas | turun mulus ke titik terendah |
| terlalu besar | melompati lembah, nilai meledak jadi `NaN` |

Kalau loss-mu berubah jadi `NaN` saat training, tersangka pertama selalu learning rate yang kebesaran.

## Gradien untuk banyak parameter

Model nyata punya banyak parameter. Turunan terhadap tiap parameter, dikumpulkan jadi satu vektor, namanya **gradien**.

```python
import numpy as np

def gradien(f, params, h=1e-5):
    g = np.zeros_like(params, dtype=float)
    for i in range(len(params)):
        maju, mundur = params.copy(), params.copy()
        maju[i] += h
        mundur[i] -= h
        g[i] = (f(maju) - f(mundur)) / (2 * h)
    return g
```

Aturan pembaruannya tetap sama persis: `params = params - lr * gradien`.

## Contoh: melatih regresi linear

```python
import numpy as np

X = np.array([[1.], [2.], [3.], [4.]])
y = np.array([3., 5., 7., 9.])          # pola sebenarnya: y = 2x + 1

w, b = 0.0, 0.0
lr = 0.05

for _ in range(500):
    pred = X.ravel() * w + b
    error = pred - y
    # turunan MSE terhadap w dan b
    dw = 2 * (error * X.ravel()).mean()
    db = 2 * error.mean()
    w -= lr * dw
    b -= lr * db

print(round(w, 2), round(b, 2))     # 2.0 1.0  ✅
```

Model menemukan sendiri bahwa `y = 2x + 1`, cuma dari data. Itulah "belajar".

## Ringkasan

- Turunan memberi tahu arah dan kecepatan perubahan sebuah fungsi.
- Gradient descent bergerak berlawanan arah gradien untuk mengecilkan loss.
- `params = params - lr * gradien` adalah inti pelatihan semua model modern.
- Learning rate terlalu besar membuat nilai meledak; terlalu kecil membuat lambat.

## Kesalahan umum

- Memakai `+` alih-alih `-` pada pembaruan parameter (jadi malah naik bukit).
- Learning rate kebesaran sehingga loss jadi `NaN`.
- Tidak menyamakan skala fitur, sehingga gradiennya timpang dan sulit konvergen.
