## Variabel = kotak berlabel

Bayangin lemari dengan banyak kotak. Tiap kotak ditempelin label, dan di dalamnya ada isi. Kalau kamu butuh isinya, kamu tinggal sebut labelnya.

```python
umur = 20
nama = "Salsa"
```

`umur` dan `nama` adalah **label** (nama variabel). `20` dan `"Salsa"` adalah **isinya** (nilai). Tanda `=` di sini bukan "sama dengan" ala matematika, tapi **"isi kotak ini dengan"**.

Isi kotak bisa diganti kapan saja:

```python
skor = 10
skor = 75
print(skor)   # 75
```

## Empat tipe data dasar

| Tipe | Arti | Contoh |
|---|---|---|
| `int` | bilangan bulat | `20`, `-5`, `0` |
| `float` | bilangan desimal | `3.14`, `-0.5`, `10.0` |
| `str` | teks (string) | `"halo"`, `'Salsa'` |
| `bool` | benar/salah | `True`, `False` |

```python
umur = 21          # int
tinggi = 165.5     # float
nama = "Salsa"     # str
aktif = True       # bool
```

Perhatikan `True` dan `False` **huruf besar di depan**. `true` bakal error.

## Cek tipe dengan `type()`

```python
print(type(21))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("21"))      # <class 'str'>
print(type(True))      # <class 'bool'>
```

Hati-hati: `21` dan `"21"` beda. Yang pertama angka, yang kedua teks yang kebetulan berbentuk angka.

## Aturan penamaan variabel

Aturan wajib (kalau dilanggar → error):

- Nggak boleh diawali angka: `2nama` ❌, `nama2` ✅
- Nggak boleh ada spasi atau tanda baca selain `_`: `nama user` ❌, `nama_user` ✅
- Nggak boleh pakai kata kunci Python: `class`, `if`, `for`, `return`, `def`

Konvensi (nggak error, tapi bikin kode enak dibaca) — pakai **snake_case**:

```python
total_harga = 50000     # ✅ gaya Python
totalHarga = 50000      # 😐 gaya JavaScript
TotalHarga = 50000      # ❌ ini gaya penamaan class
```

Dan pilih nama yang jujur:

```python
x = 3600000     # 3,6 juta apa?
gaji_pokok = 3600000   # jelas
```

## Beberapa variabel sekaligus

```python
a, b = 1, 2
print(a, b)     # 1 2

a, b = b, a     # tukar isi, trik khas Python
print(a, b)     # 2 1
```

## Ringkasan

- Variabel adalah kotak berlabel; `=` artinya "isi dengan".
- Tipe dasar: `int`, `float`, `str`, `bool`.
- `type()` dipakai buat mengecek tipe data.
- Nama variabel pakai snake_case, nggak boleh diawali angka.

## Kesalahan umum

- Menulis `True` jadi `true` → `NameError`.
- Menganggap `"10"` sama dengan `10`.
- Memakai nama variabel satu huruf yang nggak jelas maksudnya.
