## Masalah: data yang nggak muat di memori

Mau memproses file log 10 GB? Kalau kamu `read()` semuanya, laptopmu menyerah. **Generator** menyelesaikan ini: dia memberi data **satu per satu saat diminta**, bukan sekaligus.

```python
# boros: 10 juta angka disiapkan dulu di memori
angka = [x * x for x in range(10_000_000)]

# hemat: dihitung saat diminta saja
angka = (x * x for x in range(10_000_000))    # kurung biasa = generator
```

## Protokol iterator

Semua yang bisa di-`for` (list, string, dict, file) memenuhi dua aturan:

- punya `__iter__()` yang mengembalikan iterator
- iterator punya `__next__()` yang memberi item berikutnya, dan melempar `StopIteration` kalau habis

```python
it = iter([1, 2])
print(next(it))   # 1
print(next(it))   # 2
print(next(it))   # 💥 StopIteration
```

`for` sebenarnya cuma pembungkus rapi dari proses itu.

Iterator buatan sendiri:

```python
class Mundur:
    def __init__(self, n):
        self.n = n
    def __iter__(self):
        return self
    def __next__(self):
        if self.n <= 0:
            raise StopIteration
        self.n -= 1
        return self.n + 1

print(list(Mundur(3)))   # [3, 2, 1]
```

## `yield` — jalan pintas bikin iterator

Class di atas bisa diringkas jadi beberapa baris dengan `yield`:

```python
def mundur(n):
    while n > 0:
        yield n
        n -= 1

print(list(mundur(3)))   # [3, 2, 1]
```

Bedanya `yield` dengan `return`: `return` mengakhiri fungsi, `yield` **menjeda** fungsi dan mengingat posisinya. Saat diminta lagi, eksekusi lanjut dari baris setelah `yield`.

```python
def contoh():
    print("mulai")
    yield 1
    print("lanjut")
    yield 2

g = contoh()
print(next(g))   # cetak "mulai", lalu 1
print(next(g))   # cetak "lanjut", lalu 2
```

Perhatikan: memanggil `contoh()` **tidak menjalankan apa pun**. Kode baru jalan saat `next()` dipanggil — itu disebut *lazy evaluation*.

## Contoh yang mirip kerjaan nyata

```python
def fib_gen(n):
    a, b = 0, 1
    for _ in range(n):
        yield a
        a, b = b, a + b

print(list(fib_gen(6)))    # [0, 1, 1, 2, 3, 5]
```

```python
def baca_log(path):
    with open(path) as f:
        for baris in f:
            if "ERROR" in baris:
                yield baris.strip()

# file 10 GB pun aman: hanya satu baris di memori setiap saat
for err in baca_log("app.log"):
    print(err)
```

## Batasan yang harus diingat

Generator **habis sekali pakai**:

```python
g = fib_gen(3)
print(list(g))    # [0, 1, 1]
print(list(g))    # []  <- sudah habis
```

Dan generator tidak punya `len()` maupun index. Kalau butuh itu, bungkus dengan `list(g)`.

## Ringkasan

- Generator menghasilkan nilai satu per satu, hemat memori.
- `yield` menjeda fungsi dan melanjutkan dari titik yang sama.
- Generator expression: `(x for x in data)` dengan kurung biasa.
- Generator hanya bisa dilewati sekali dan tidak punya `len()`.

## Kesalahan umum

- Melakukan `list()` pada generator besar — semua keuntungan memorinya hilang.
- Mengulang generator yang sudah habis lalu heran hasilnya kosong.
- Mengira memanggil fungsi generator langsung menjalankan isinya.
