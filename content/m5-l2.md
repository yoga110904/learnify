## Fungsi juga sekadar objek

Di Python, fungsi bisa disimpan di variabel, dimasukkan ke list, dan dikirim sebagai argumen:

```python
def sapa():
    return "halo"

f = sapa            # tanpa kurung = objeknya sendiri
print(f())          # halo
```

Fungsi juga bisa mengembalikan fungsi lain. Fungsi dalam yang "mengingat" variabel di luarnya disebut **closure**:

```python
def pengali(n):
    def kali(x):
        return x * n     # n diingat walaupun pengali() sudah selesai
    return kali

dua_kali = pengali(2)
print(dua_kali(5))    # 10
```

## Decorator = pembungkus fungsi

Misal kamu mau mencatat setiap pemanggilan fungsi. Tanpa decorator kamu harus menempel `print` di setiap fungsi. Dengan decorator:

```python
def catat(fn):
    def pembungkus(*args, **kwargs):
        print(f"memanggil {fn.__name__}")
        hasil = fn(*args, **kwargs)
        print("selesai")
        return hasil
    return pembungkus

@catat
def tambah(a, b):
    return a + b

print(tambah(2, 3))
```

```
memanggil tambah
selesai
5
```

Sintaks `@catat` di atas `def tambah` hanyalah cara singkat untuk:

```python
tambah = catat(tambah)
```

`*args, **kwargs` membuat pembungkusnya cocok untuk fungsi apa pun.

## Jangan lupa `functools.wraps`

Tanpa itu, identitas fungsi aslinya hilang:

```python
print(tambah.__name__)    # 'pembungkus'  😒
```

Perbaikannya:

```python
from functools import wraps

def catat(fn):
    @wraps(fn)
    def pembungkus(*args, **kwargs):
        return fn(*args, **kwargs)
    return pembungkus
```

Sekarang `tambah.__name__` kembali `'tambah'`. Ini penting karena pytest dan banyak tool lain membaca nama serta docstring fungsi.

## Menyimpan data di fungsi

Karena fungsi adalah objek, dia bisa punya atribut:

```python
from functools import wraps

def hitung_panggilan(fn):
    @wraps(fn)
    def pembungkus(*args, **kwargs):
        pembungkus.jumlah += 1
        return fn(*args, **kwargs)
    pembungkus.jumlah = 0
    return pembungkus

@hitung_panggilan
def halo():
    pass

halo(); halo(); halo()
print(halo.jumlah)    # 3
```

## Decorator dengan argumen

Butuh satu lapis tambahan: fungsi yang mengembalikan decorator.

```python
def ulangi(n):
    def decorator(fn):
        @wraps(fn)
        def pembungkus(*a, **k):
            for _ in range(n):
                hasil = fn(*a, **k)
            return hasil
        return pembungkus
    return decorator

@ulangi(3)
def tes():
    print("jalan")
```

Pola ini persis yang dipakai `@pytest.mark.parametrize` dan `@app.route("/")` di Flask.

## Decorator bawaan yang sering dipakai

```python
@property          # OOP (Modul 4)
@staticmethod      # method tanpa self
@classmethod       # method yang menerima cls
@lru_cache         # menyimpan hasil pemanggilan (cache)
@dataclass         # Modul 4
```

## Ringkasan

- Fungsi adalah objek: bisa disimpan, dikirim, dan dikembalikan.
- Decorator membungkus fungsi untuk menambah perilaku tanpa mengubah isinya.
- `@wraps(fn)` menjaga nama dan docstring fungsi asli.
- Decorator berargumen butuh tiga tingkat fungsi.

## Kesalahan umum

- Lupa `return hasil` di pembungkus sehingga fungsi jadi mengembalikan `None`.
- Lupa `@wraps` sehingga metadata fungsi hilang.
- Menulis `@catat()` padahal decorator-nya tidak menerima argumen.
