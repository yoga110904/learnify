## Fungsi = kode yang dibungkus dan diberi nama

Kalau kamu menulis logika yang sama di tiga tempat, dan besok logikanya berubah, kamu harus memperbaikinya di tiga tempat. Fungsi menyelesaikan masalah itu.

```python
def sapa(nama):
    return f"Halo {nama}"

print(sapa("Salsa"))    # Halo Salsa
print(sapa("Budi"))     # Halo Budi
```

Bagian-bagiannya:

| Bagian | Fungsinya |
|---|---|
| `def` | kata kunci pembuat fungsi |
| `sapa` | nama fungsi (snake_case, sebaiknya kata kerja) |
| `(nama)` | **parameter** — variabel lokal yang diisi saat dipanggil |
| `return` | nilai yang dikirim balik ke pemanggil |

Istilah yang sering tertukar:

- **Parameter** = nama di definisi (`nama`)
- **Argumen** = nilai saat dipanggil (`"Salsa"`)

## `return` vs `print` — beda besar!

```python
def tambah_print(a, b):
    print(a + b)

def tambah_return(a, b):
    return a + b

x = tambah_print(2, 3)     # tercetak 5, tapi x = None
y = tambah_return(2, 3)    # tidak tercetak, tapi y = 5
print(y * 2)               # 10 — bisa dipakai lagi
```

`print` hanya menampilkan ke layar; hasilnya tidak bisa dipakai lagi. `return` memberi **nilai** yang bisa disimpan, dihitung, atau diuji.

Aturan praktis: **fungsi menghitung, pemanggil yang mencetak.**

```python
def luas(p, l):
    return p * l            # ✅ fungsi murni

print(f"Luasnya {luas(3, 4)}")   # pencetakan di pemanggil
```

Fungsi seperti itu jauh lebih mudah diuji, digabung, dan dipakai ulang. Itu sebabnya semua latihan di kurikulum ini memakai `return`.

### `return` menghentikan fungsi

```python
def cek(n):
    if n < 0:
        return "negatif"
    return "positif"        # baris ini tidak jalan kalau sudah return di atas
```

Fungsi tanpa `return` otomatis mengembalikan `None`:

```python
def tanpa_return():
    pass

print(tanpa_return())    # None
```

### Mengembalikan beberapa nilai

```python
def bagi(a, b):
    return a // b, a % b      # sebenarnya satu tuple

hasil, sisa = bagi(7, 2)
print(hasil, sisa)            # 3 1
```

## Default argument

```python
def sapa(nama, salam="Halo"):
    return f"{salam} {nama}"

sapa("Budi")                  # Halo Budi
sapa("Budi", "Selamat pagi")  # Selamat pagi Budi
```

Parameter berdefault harus ditaruh **setelah** yang tanpa default:

```python
def f(a=1, b):     # 💥 SyntaxError
def f(a, b=1):     # ✅
```

> ⚠️ Jangan pakai list/dict sebagai nilai default (`def f(x=[])`) — objeknya dibuat sekali dan dipakai ulang antar pemanggilan. Pakai `None` lalu isi di dalam fungsi. Alasannya dibahas di lesson Mutability.

## Keyword argument

Memanggil dengan menyebut nama parameternya bikin kode jauh lebih jelas:

```python
def buat_user(nama, admin=False, aktif=True):
    return (nama, admin, aktif)

buat_user("Salsa", admin=True)         # jelas
buat_user("Salsa", True, False)        # True-nya yang mana?
```

Keyword argument juga membebaskan urutannya:

```python
buat_user(admin=True, nama="Salsa")    # sah
```

Aturannya: argumen posisional harus mendahului keyword argument.

```python
buat_user(admin=True, "Salsa")    # 💥 SyntaxError
```

## Docstring

Penjelasan singkat di baris pertama fungsi, dibaca lewat `help()` dan editor:

```python
def luas_lingkaran(r):
    """Mengembalikan luas lingkaran dengan jari-jari r."""
    return 3.14159 * r ** 2

help(luas_lingkaran)
print(luas_lingkaran.__doc__)
```

Untuk fungsi yang lebih rumit, gaya yang umum:

```python
def bagi(a, b):
    """Membagi a dengan b.

    Args:
        a: bilangan yang dibagi
        b: pembagi, tidak boleh nol

    Returns:
        Hasil bagi sebagai float

    Raises:
        ZeroDivisionError: kalau b bernilai nol
    """
    return a / b
```

Docstring berbeda dari komentar: dia **bagian dari objek fungsi** dan bisa dibaca program lain.

## Fungsi yang baik itu seperti apa?

1. **Satu tugas saja.** Kalau namanya mengandung "dan", biasanya perlu dipecah.
2. **Nama berupa kata kerja.** `hitung_total`, `ambil_user`, `validasi_email`.
3. **Parameter sedikit.** Lebih dari 4 biasanya tanda perlu dikelompokkan jadi dict atau objek.
4. **Tidak mengandalkan variabel global.** Semua yang dibutuhkan masuk lewat parameter.
5. **Konsisten mengembalikan tipe yang sama.** Jangan kadang `int` kadang `None` tanpa alasan.

```python
# ❌ terlalu banyak tugas
def proses(data):
    bersih = [d.strip() for d in data]
    total = sum(len(d) for d in bersih)
    print(f"Total: {total}")
    simpan_ke_file(bersih)
    return total

# ✅ dipecah
def bersihkan(data):
    return [d.strip() for d in data]

def hitung_total(data):
    return sum(len(d) for d in data)
```

## Fungsi memanggil fungsi

```python
def bersihkan(teks):
    return teks.strip().lower()

def valid_email(teks):
    teks = bersihkan(teks)
    return "@" in teks and "." in teks.split("@")[-1]

print(valid_email("  Salsa@Mail.COM  "))    # True
```

Menyusun program dari fungsi-fungsi kecil yang saling memanggil adalah inti dari kode yang bisa dirawat.

```python
def konversi_suhu(nilai, dari="C", ke="F"):
    """Mengubah suhu antara Celcius dan Fahrenheit."""
    if dari == ke:
        return nilai
    if dari == "C" and ke == "F":
        return nilai * 9 / 5 + 32
    if dari == "F" and ke == "C":
        return (nilai - 32) * 5 / 9
    raise ValueError(f"Konversi {dari} ke {ke} tidak didukung")

print(konversi_suhu(100))            # 212.0
print(konversi_suhu(32, "F", "C"))   # 0.0
```
</details>

## Ringkasan

- Fungsi membungkus logika supaya bisa dipakai ulang; `def` + `return`.
- `return` mengirim nilai yang bisa dipakai lagi; `print` hanya menampilkan.
- Parameter berdefault harus setelah yang tanpa default; jangan pakai list/dict sebagai default.
- Keyword argument membuat pemanggilan jauh lebih jelas.
- Fungsi yang baik: satu tugas, nama kata kerja, parameter sedikit, tipe kembalian konsisten.

## Kesalahan umum

- Memakai `print` padahal dibutuhkan `return`.
- Lupa memanggil fungsinya (`sapa` vs `sapa()`).
- Memakai list sebagai nilai default parameter.
- Menulis fungsi yang melakukan lima hal sekaligus.
