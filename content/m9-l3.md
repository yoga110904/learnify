## Memprediksi kategori, bukan angka

Regresi menjawab "berapa". Klasifikasi menjawab "yang mana": spam atau bukan, lulus atau gagal, kucing/anjing/burung.

## Logistic Regression

Namanya menipu — ini algoritma **klasifikasi**, bukan regresi. Cara kerjanya: hitung garis seperti regresi linear, lalu peras hasilnya ke rentang 0–1 memakai fungsi **sigmoid**.

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

X = np.array([[1], [2], [3], [6], [7], [8]])
y = np.array([0, 0, 0, 1, 1, 1])

model = LogisticRegression().fit(X, y)

model.predict([[2.5]])         # [0]
model.predict([[6.5]])         # [1]
model.predict_proba([[4.5]])   # [[0.52, 0.48]]  peluang tiap kelas
```

`predict_proba` jauh lebih berguna dari `predict`. Prediksi 0,51 dan 0,99 sama-sama dilaporkan sebagai kelas 1, padahal keyakinannya beda jauh.

Ambang batasnya juga bisa digeser sesuai kebutuhan:

```python
peluang = model.predict_proba(X)[:, 1]
prediksi = (peluang >= 0.3).astype(int)   # lebih sensitif
```

Turunkan ambang kalau melewatkan kasus positif itu mahal (deteksi penyakit). Naikkan kalau alarm palsu yang mahal.

## Decision Tree

Model yang bertanya berulang kali, seperti permainan tebak-tebakan:

```
umur < 30?
├── ya  → gaji > 5jt? → ya: beli / tidak: tidak beli
└── tidak → tidak beli
```

```python
from sklearn.tree import DecisionTreeClassifier

model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X, y)
model.feature_importances_       # fitur mana yang paling menentukan
```

Kelebihannya: mudah dijelaskan, tidak butuh penyamaan skala, bisa menangkap hubungan non-linear.
Kelemahannya: tanpa `max_depth`, pohon akan tumbuh sampai **menghafal** setiap baris data latih.

## Random Forest

Gabungan banyak decision tree yang masing-masing dilatih pada potongan data dan fitur berbeda, lalu hasilnya divoting.

```python
from sklearn.ensemble import RandomForestClassifier

model = RandomForestClassifier(n_estimators=100, random_state=42)
model.fit(X, y)
```

Satu pohon gampang salah; seratus pohon yang salahnya berbeda-beda saling mengoreksi. Ini pilihan default yang sangat baik untuk data tabel — sering mengalahkan neural network pada data terstruktur.

## K-Nearest Neighbors

"Kamu adalah rata-rata dari tetangga terdekatmu."

```python
from sklearn.neighbors import KNeighborsClassifier

model = KNeighborsClassifier(n_neighbors=5)
model.fit(X, y)
```

Tidak ada proses belajar — semua data disimpan, dan prediksi dilakukan dengan mencari k tetangga terdekat. **Wajib menyamakan skala fitur** karena berbasis jarak.

## Memilih model

| Model | Kapan dipakai | Perlu skala sama? |
|---|---|---|
| Logistic Regression | baseline, butuh interpretasi | ya |
| Decision Tree | butuh penjelasan visual | tidak |
| Random Forest | data tabel, akurasi tinggi | tidak |
| KNN | data kecil, pola lokal | ya |

Mulailah dari Logistic Regression sebagai pembanding. Kalau model rumitmu tidak mengalahkannya, kerumitan itu tidak ada gunanya.

## Klasifikasi lebih dari dua kelas

Sama saja — scikit-learn menanganinya otomatis:

```python
y = np.array([0, 1, 2, 1, 0])     # tiga kelas
model = LogisticRegression().fit(X, y)
model.predict_proba(X)            # satu kolom per kelas
model.classes_                    # urutan kelasnya
```

## Ringkasan

- Logistic Regression memakai sigmoid untuk menghasilkan peluang 0–1.
- `predict_proba` memberi keyakinan, bukan cuma jawaban.
- Decision tree mudah dijelaskan tapi gampang menghafal tanpa `max_depth`.
- Random Forest adalah pilihan default yang kuat untuk data tabel.

## Kesalahan umum

- Mengira Logistic Regression itu model regresi.
- Memakai KNN atau Logistic Regression tanpa menyamakan skala fitur.
- Membiarkan decision tree tumbuh tanpa batas kedalaman.
