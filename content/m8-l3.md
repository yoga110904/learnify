## Mengenali data sebelum memodelkannya

Sebelum melatih apa pun, kamu harus tahu bentuk datanya. Statistik deskriptif adalah alatnya.

```python
import numpy as np
gaji = np.array([3, 4, 4, 5, 5, 5, 6, 50])   # dalam juta
```

## Ukuran pemusatan

```python
np.mean(gaji)     # 10.25   rata-rata
np.median(gaji)   # 5.0     nilai tengah
```

Lihat bedanya: satu orang bergaji 50 juta menarik **mean** ke 10,25 — padahal 7 dari 8 orang bergaji di bawah 6. **Median** tidak tertipu.

Aturan praktis: kalau mean dan median jauh berbeda, datamu **miring** (*skewed*) atau punya outlier.

Modus (nilai paling sering) untuk data kategori:

```python
nilai, jumlah = np.unique(gaji, return_counts=True)
modus = nilai[jumlah.argmax()]      # 5
```

## Ukuran sebaran

```python
np.std(gaji)      # 15.0   standar deviasi
np.var(gaji)      # 225.0  varians = std²
np.ptp(gaji)      # 47     jarak min ke max
```

**Standar deviasi** menjawab: "rata-rata, seberapa jauh data menyimpang dari mean?" Std kecil = data berkumpul; std besar = data menyebar.

Kuartil membelah data terurut jadi empat bagian:

```python
q1 = np.percentile(gaji, 25)    # 4.25
q3 = np.percentile(gaji, 75)    # 5.25
iqr = q3 - q1                   # 1.0
```

IQR lebih tahan outlier daripada std, jadi dipakai untuk mendeteksi nilai menyimpang:

```python
batas_atas = q3 + 1.5 * iqr
outlier = gaji[gaji > batas_atas]    # [50]
```

## Distribusi normal

Banyak fenomena alami (tinggi badan, error pengukuran) membentuk lonceng simetris. Ciri-cirinya:

- ±68% data ada dalam 1 standar deviasi dari mean
- ±95% dalam 2 standar deviasi
- ±99,7% dalam 3 standar deviasi

```python
rng = np.random.default_rng(42)
data = rng.normal(loc=170, scale=10, size=1000)   # mean 170, std 10
```

Aturan 68–95–99,7 ini yang membuat "di luar 3 sigma" jadi definisi umum anomali.

## Normalisasi vs standardisasi

Model seperti KNN, SVM, dan neural network **sensitif terhadap skala**. Kolom gaji (jutaan) akan menenggelamkan kolom umur (puluhan) kalau tidak disamakan dulu.

**Min-Max Normalization** — peras ke rentang 0–1:

$$x' = \frac{x - min}{max - min}$$

```python
(x - x.min()) / (x.max() - x.min())
```

Cocok kalau batas datanya jelas (misal nilai ujian 0–100). Kelemahannya: satu outlier ekstrem menggencet semua data lain ke ujung.

**Standardization (Z-score)** — geser ke mean 0, std 1:

$$z = \frac{x - \mu}{\sigma}$$

```python
(x - x.mean()) / x.std()
```

Ini pilihan default di sebagian besar kasus, dan lebih tahan outlier daripada min-max.

Z-score juga langsung memberi tahu seberapa tidak biasa sebuah nilai: `z = 3` berarti 3 standar deviasi di atas rata-rata — sangat jarang.

## Korelasi

Seberapa erat dua variabel bergerak bersama?

```python
tinggi = np.array([160, 165, 170, 175])
berat  = np.array([50, 55, 62, 70])
np.corrcoef(tinggi, berat)[0, 1]     # 0.99
```

Rentangnya −1 sampai 1. Mendekati 0 artinya tidak ada hubungan **linear**.

⚠️ Dua peringatan: korelasi bukan sebab-akibat, dan korelasi mendekati 0 tidak berarti tidak berhubungan — bisa jadi hubungannya melengkung, bukan lurus.

## Ringkasan

- Mean sensitif outlier, median tidak. Kalau keduanya beda jauh, datanya miring.
- Std mengukur sebaran; IQR versi yang tahan outlier.
- Standardisasi (z-score) adalah default; min-max kalau batas datanya jelas.
- Korelasi mengukur hubungan linear, dan bukan bukti sebab-akibat.

## Kesalahan umum

- Melaporkan mean untuk data yang jelas-jelas miring.
- Melatih model berbasis jarak tanpa menyamakan skala fitur.
- Menyimpulkan sebab-akibat dari korelasi tinggi.
