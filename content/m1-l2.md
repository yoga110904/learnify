## Kalkulator bawaan Python

Python bisa langsung dipakai berhitung. Operator aritmatikanya mirip yang kamu pelajari di sekolah, plus tiga tambahan yang sering bikin bingung pemula.

```python
print(7 + 2)    # 9   tambah
print(7 - 2)    # 5   kurang
print(7 * 2)    # 14  kali
print(7 / 2)    # 3.5 bagi  -> hasilnya SELALU float
print(7 // 2)   # 3   bagi bulat (pembulatan ke bawah)
print(7 % 2)    # 1   sisa bagi (modulo)
print(7 ** 2)   # 49  pangkat
```

### `/` selalu menghasilkan float

```python
print(10 / 2)        # 5.0   bukan 5
print(type(10 / 2))  # <class 'float'>
```

Ini sering mengagetkan. Kalau kamu butuh bilangan bulat, pakai `//` atau bungkus dengan `int()`.

### `//` dan `%` itu kembar

Ingat pembagian jaman SD: 7 dibagi 2 = 3 sisa 1.

- `//` ngasih **hasil bagi**-nya → `3`
- `%` ngasih **sisanya** → `1`

```python
print(7 // 2)   # 3
print(7 % 2)    # 1
print(7 // 2 * 2 + 7 % 2)    # 7  -> kembali utuh
```

⚠️ Untuk angka negatif, `//` membulatkan **ke bawah** (menjauhi nol), bukan memotong:

```python
print(-7 // 2)   # -4, bukan -3
print(int(-7 / 2))  # -3  <- kalau mau memotong, pakai ini
```

### Kegunaan nyata `%`

```python
# ganjil / genap
print(10 % 2 == 0)      # True  -> genap

# kelipatan
print(15 % 5 == 0)      # True  -> kelipatan 5

# ambil digit terakhir
print(1234 % 10)        # 4

# jam 24 ke format 12
print(15 % 12)          # 3

# giliran berputar dari 4 orang
for i in range(6):
    print(i % 4, end=" ")   # 0 1 2 3 0 1
```

Pola terakhir itu dipakai di mana-mana: memutar warna, membagi giliran, memilih server, dan membuat animasi berulang.

### `**` pangkat

```python
print(2 ** 10)     # 1024
print(9 ** 0.5)    # 3.0   akar kuadrat
print(2 ** -1)     # 0.5
```

`x ** 0.5` adalah cara singkat menghitung akar tanpa perlu `import math`.

## Urutan operasi

Sama kayak matematika: **kurung → pangkat → kali/bagi/modulo → tambah/kurang**.

```python
print(2 + 3 * 4)      # 14, bukan 20
print((2 + 3) * 4)    # 20
print(2 ** 3 * 2)     # 16   (pangkat duluan: 8*2)
print(10 - 3 - 2)     # 5    (kiri ke kanan)
print(2 ** 3 ** 2)    # 512  (pangkat: KANAN ke kiri! 3**2=9, lalu 2**9)
```

Baris terakhir itu pengecualian yang bagus untuk diingat: **pangkat dievaluasi dari kanan**.

Kalau ragu, **pakai kurung**. Kurung tambahan nggak pernah bikin kode lebih buruk, dan menghemat waktu orang yang membaca kodemu nanti — termasuk kamu tiga bulan lagi.

## Operator gabungan

```python
skor = 10
skor += 5    # sama dengan: skor = skor + 5
skor -= 3    # 12
skor *= 2    # 24
skor //= 5   # 4
skor **= 2   # 16
print(skor)  # 16
```

Bentuk ini bukan cuma lebih pendek — dia juga mengurangi risiko salah ketik nama variabel.

```python
total_pendapatan = total_pendapatan + 100    # nama ditulis dua kali
total_pendapatan += 100                       # sekali saja
```

Operator `+=` juga jalan untuk string dan list:

```python
pesan = "Halo"
pesan += " dunia"
print(pesan)      # Halo dunia
```

## Masalah bilangan desimal

Ini bukan bug Python, tapi keterbatasan cara komputer menyimpan pecahan:

```python
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False  😱
```

Komputer menyimpan angka dalam biner, dan 0,1 tidak bisa dinyatakan persis dalam biner — sama seperti 1/3 tidak bisa ditulis persis dalam desimal.

Tiga cara menanganinya:

```python
# 1. bandingkan dengan toleransi
print(abs((0.1 + 0.2) - 0.3) < 1e-9)     # True

# 2. bulatkan saat menampilkan
print(round(0.1 + 0.2, 2))               # 0.3

# 3. untuk uang, pakai Decimal
from decimal import Decimal
print(Decimal("0.1") + Decimal("0.2"))   # 0.3  persis
```

Aturan praktis: **jangan pernah membandingkan float dengan `==`**, dan untuk uang jangan pakai float sama sekali.

## Pembulatan

```python
print(round(3.7))        # 4
print(round(3.14159, 2)) # 3.14
print(int(3.9))          # 3    memotong, bukan membulatkan

import math
print(math.ceil(3.1))    # 4    selalu ke atas
print(math.floor(3.9))   # 3    selalu ke bawah
```

⚠️ `round()` Python memakai *banker's rounding* — angka tepat di tengah dibulatkan ke genap terdekat:

```python
print(round(0.5))    # 0   bukan 1
print(round(1.5))    # 2
print(round(2.5))    # 2   bukan 3
```

Ini disengaja untuk mengurangi bias statistik saat membulatkan banyak angka. Kalau butuh pembulatan "sekolah", tambahkan sendiri: `math.floor(x + 0.5)`.

## Sekilas tentang `def` dan `return`

Di latihan-latihan berikutnya kamu bakal sering diminta bikin **fungsi** — anggap saja "wadah jawaban" yang diuji otomatis:

```python
def luas_persegi(sisi):
    return sisi * sisi

print(luas_persegi(4))   # 16
```

`def` bikin fungsi, `return` mengembalikan hasil ke pemanggilnya. Perbedaan `return` dan `print` dibahas tuntas di Modul 2 — sekarang cukup ikuti polanya: hitung, lalu `return`.

## Ringkasan

- `/` selalu menghasilkan float; `//` bulat (membulatkan ke bawah), `%` sisanya.
- `%` dipakai untuk ganjil/genap, kelipatan, digit terakhir, dan giliran berputar.
- Urutan: kurung → pangkat (dari kanan) → kali/bagi → tambah/kurang.
- `+=` dan kawan-kawannya memperpendek kode dan mengurangi salah ketik.
- Float tidak presisi — jangan bandingkan dengan `==`, dan untuk uang pakai `Decimal`.

## Kesalahan umum

- Kaget `10 / 2` menghasilkan `5.0` bukan `5`.
- Mengira `-7 // 2` sama dengan `-3` (padahal `-4`).
- Membandingkan hasil perhitungan float dengan `==`.
- Mengira `round(2.5)` menghasilkan 3 (Python membulatkan ke genap terdekat).
