## Hitung tanpa loop

Operasi NumPy berlaku ke **seluruh elemen sekaligus**. Ini namanya *vektorisasi*.

```python
import numpy as np
x = np.array([1, 2, 3])

x + 10        # [11 12 13]
x * 2         # [2 4 6]
x ** 2        # [1 4 9]
x / 2         # [0.5 1.  1.5]
np.sqrt(x)    # [1.   1.41 1.73]
np.exp(x)     # [ 2.72  7.39 20.09]
np.log(x)     # [0.   0.69 1.1 ]
```

Dua array dengan bentuk sama dioperasikan elemen demi elemen:

```python
a = np.array([1, 2, 3])
b = np.array([10, 20, 30])
a + b        # [11 22 33]
a * b        # [10 40 90]   <- bukan perkalian matriks!
```

Perhatikan: `*` adalah perkalian **per elemen**. Perkalian matriks pakai `@`, dibahas di lesson berikutnya.

## Broadcasting: bentuk beda tetap bisa dihitung

Kenapa `x + 10` bisa jalan padahal `10` cuma satu angka? Karena NumPy diam-diam "merentangkan" angka itu agar bentuknya cocok. Mekanisme ini disebut **broadcasting**.

```python
harga = np.array([[100, 200],
                  [300, 400]])      # shape (2, 2)
diskon = np.array([0.1, 0.5])       # shape (2,)

harga * diskon
# [[ 10. 100.]
#  [ 30. 200.]]
```

`diskon` diterapkan ke **tiap baris**, kolom demi kolom.

### Aturannya

Bandingkan shape dari **kanan ke kiri**. Dua dimensi cocok kalau:

1. angkanya sama, **atau**
2. salah satunya bernilai 1

```
(3, 4)  +  (4,)    ->  ✅  (4,) dianggap (1, 4), direntangkan jadi 3 baris
(3, 4)  +  (3, 1)  ->  ✅  kolom direntangkan jadi 4
(3, 4)  +  (3,)    ->  ❌  4 vs 3 tidak cocok
```

Kalau bentuknya tidak cocok:

```
ValueError: operands could not be broadcast together with shapes (3,4) (3,)
```

Solusinya biasanya menambah dimensi:

```python
x = np.array([1, 2, 3])
x.shape            # (3,)
x[:, None].shape   # (3, 1)   -> jadi kolom
x.reshape(-1, 1)   # sama saja
```

## Contoh nyata: standardisasi data

Ini langkah wajib sebelum melatih hampir semua model:

```python
data = np.array([[1.0, 100.0],
                 [2.0, 200.0],
                 [3.0, 300.0]])

rata = data.mean(axis=0)     # [2. 200.]   rata-rata tiap kolom
std  = data.std(axis=0)      # [0.82 81.6]

hasil = (data - rata) / std
```

`data` bentuknya `(3, 2)`, `rata` bentuknya `(2,)` → broadcasting membuat pengurangan berlaku ke tiap baris. Tanpa NumPy, ini butuh dua loop bersarang.

## Kenapa vektorisasi lebih cepat?

```python
# ❌ lambat
hasil = []
for nilai in data:
    hasil.append(nilai * 2)

# ✅ cepat
hasil = data * 2
```

Versi pertama menjalankan loop di Python (lambat). Versi kedua menjalankan loop di C (cepat). Aturan praktis: **kalau kamu menulis `for` di atas array NumPy, biasanya ada cara yang lebih baik.**

## Ringkasan

- Operasi NumPy berlaku ke seluruh elemen sekaligus tanpa loop.
- `*` adalah perkalian per elemen, bukan perkalian matriks.
- Broadcasting mencocokkan bentuk dari kanan ke kiri; dimensi bernilai 1 direntangkan.
- Pakai `reshape(-1, 1)` atau `[:, None]` untuk menambah dimensi.

## Kesalahan umum

- Mengira `a * b` adalah perkalian matriks.
- Panik melihat error broadcasting padahal cuma perlu `reshape`.
- Menulis loop Python untuk hal yang sudah ada operasi NumPy-nya.
