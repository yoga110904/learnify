## Ngoding itu kayak nulis resep masakan

Bayangin kamu nyuruh adik kamu bikin mie instan. Kamu nggak bisa cuma bilang "bikinin mie". Kamu harus ngasih langkah: *rebus air → masukin mie → tunggu 3 menit → tiriskan → campur bumbu*. Urutannya penting, dan satu langkah kelewat bisa bikin hasilnya aneh.

**Bahasa pemrograman** itu cara kita ngasih resep ke komputer. Komputer super patuh tapi super bodoh: dia cuma ngerjain persis apa yang kita tulis, nggak lebih.

## Kenapa Python?

Python dipilih jutaan orang sebagai bahasa pertama karena sintaksnya mirip bahasa Inggris sehari-hari. Bandingin nyetak tulisan di layar:

```python
# Python
print("Halo Dunia")
```

```java
// Java
public class Main {
    public static void main(String[] args) {
        System.out.println("Halo Dunia");
    }
}
```

Hasilnya sama, tapi Python jauh lebih pendek. Lebih sedikit yang diketik = lebih sedikit yang bisa salah.

## Interpreted vs compiled

Python adalah bahasa **interpreted** (diterjemahkan). Kodenya dibaca dan dijalankan **baris per baris** oleh program bernama *interpreter*.

Analogi: interpreter itu kayak penerjemah lisan yang nerjemahin kalimat demi kalimat saat kamu ngomong. Sedangkan bahasa *compiled* (C, Java) kayak nerjemahin seluruh buku dulu sampai selesai, baru bukunya dibaca.

Konsekuensinya:

- ✅ Kamu bisa langsung jalanin kode tanpa nunggu proses build.
- ✅ Error langsung kelihatan pas baris itu dieksekusi.
- ⚠️ Jalannya lebih lambat dibanding C — tapi buat 95% kebutuhan, nggak kerasa.

```python
print("baris 1")
print("baris 2")
prin("baris 3")   # typo di sini
```

Output:

```
baris 1
baris 2
NameError: name 'prin' is not defined
```

Lihat? Baris 1 dan 2 tetap jalan duluan, baru error muncul di baris 3. Itu ciri khas interpreted.

## Ringkasan

- Bahasa pemrograman = cara ngasih instruksi berurutan ke komputer.
- Python populer karena sintaksnya singkat dan gampang dibaca.
- Python dipakai di web, data, AI, otomasi, dan automation testing.
- Python bersifat *interpreted*: dijalankan baris per baris.

## Kesalahan umum

- Mengira Python cuma buat data science. Padahal serba bisa.
- Lupa bahwa komputer nggak bisa nebak maksud kita — urutan langkah harus jelas.
