## Ketika jumlah argumennya tidak pasti

Fungsi seperti `print()` bisa menerima berapa pun argumen:

```python
print("a")
print("a", "b", "c")
```

Bagaimana caranya? Dengan `*args` dan `**kwargs`.

## `*args` — argumen posisional tak terbatas

```python
def total(*angka):          # angka menjadi TUPLE
    return sum(angka)

total(1, 2)          # 3
total(1, 2, 3, 4)    # 10
total()              # 0
```

Di dalam fungsi, `angka` adalah tuple berisi semua argumen posisional yang dikirim.

```python
def info(*args):
    print(type(args), args)

info(1, "a", True)    # <class 'tuple'> (1, 'a', True)
```

Nama `args` cuma konvensi — yang punya arti khusus adalah tanda `*`. Tapi tetap pakai `args` supaya kodemu familiar bagi orang lain.

## `**kwargs` — keyword argument tak terbatas

```python
def info(**data):           # data menjadi DICT
    for k, v in data.items():
        print(f"{k}: {v}")

info(nama="Salsa", umur=21)
# nama: Salsa
# umur: 21
```

Sering dipakai untuk meneruskan opsi tanpa harus mendaftarkan semuanya satu per satu.

## Menggabungkan semuanya

Urutan parameter di Python itu baku:

```python
def f(wajib, opsional=0, *args, keyword_only=None, **kwargs):
    ...
```

| Urutan | Bentuk | Contoh |
|---|---|---|
| 1 | parameter biasa | `wajib` |
| 2 | parameter berdefault | `opsional=0` |
| 3 | `*args` | sisa posisional |
| 4 | keyword-only | wajib disebut namanya |
| 5 | `**kwargs` | sisa keyword |

Contoh nyata:

```python
def belanja(*harga, diskon=0):
    subtotal = sum(harga)
    return subtotal - subtotal * diskon / 100

belanja(100, 200)              # 300
belanja(100, 100, diskon=10)   # 180
```

Perhatikan: setelah `*args`, parameter apa pun menjadi **keyword-only** — harus disebut namanya. `belanja(100, 100, 10)` akan menganggap 10 sebagai harga, bukan diskon.

## Keyword-only tanpa `*args`

Kalau kamu ingin memaksa pemanggil menyebut nama parameter, pakai `*` telanjang:

```python
def buat_user(nama, *, admin=False, aktif=True):
    return nama, admin, aktif

buat_user("Salsa", admin=True)     # ✅
buat_user("Salsa", True)           # 💥 TypeError
```

Ini praktik yang sangat baik untuk parameter boolean — `buat_user("Salsa", True, False)` tidak ada yang tahu artinya apa.

## Positional-only (Python 3.8+)

Kebalikannya, `/` memaksa parameter sebelumnya hanya boleh posisional:

```python
def bagi(a, b, /):
    return a / b

bagi(10, 2)          # ✅
bagi(a=10, b=2)      # 💥 TypeError
```

Berguna untuk fungsi library yang nama parameternya ingin bisa diubah di masa depan tanpa merusak kode orang.

## Unpacking saat memanggil

`*` dan `**` juga bekerja di sisi **pemanggilan** — kali ini untuk membongkar:

```python
def luas(p, l):
    return p * l

ukuran = (3, 4)
print(luas(*ukuran))       # 12   -> luas(3, 4)

data = {"p": 3, "l": 4}
print(luas(**data))        # 12   -> luas(p=3, l=4)
```

Sangat berguna kalau argumennya sudah tersimpan dalam struktur data:

```python
titik = [(1, 2), (3, 4)]
for t in titik:
    print(luas(*t))
```

## Meneruskan argumen ke fungsi lain

Ini kegunaan `*args`/`**kwargs` yang paling sering di kode nyata:

```python
def catat_lalu_jalankan(fn, *args, **kwargs):
    print(f"Memanggil {fn.__name__}")
    hasil = fn(*args, **kwargs)
    print(f"Hasil: {hasil}")
    return hasil

catat_lalu_jalankan(luas, 3, l=4)
# Memanggil luas
# Hasil: 12
```

Pembungkus seperti ini tidak perlu tahu parameter apa saja yang dimiliki `fn` — dia cuma meneruskan semuanya. Pola inilah yang nanti jadi dasar **decorator** di Modul 5.

## Memberi tipe pada argumen (sekilas)

```python
def total(*angka: float, diskon: float = 0) -> float:
    ...
```

Anotasi tipe tidak memaksa apa pun saat program jalan, tapi sangat membantu editor dan pembaca. Dibahas tuntas di Modul 5.

## Ringkasan

- `*args` menampung argumen posisional sisa sebagai **tuple**; `**kwargs` sebagai **dict**.
- Urutan baku: biasa → berdefault → `*args` → keyword-only → `**kwargs`.
- Parameter setelah `*args` (atau setelah `*` telanjang) menjadi keyword-only.
- Di sisi pemanggilan, `*` dan `**` justru **membongkar** tuple/dict jadi argumen.
- Meneruskan `*args, **kwargs` ke fungsi lain adalah dasar pola pembungkus (decorator).

## Kesalahan umum

- Mengira parameter setelah `*args` masih bisa diisi secara posisional.
- Salah urutan parameter sehingga `SyntaxError`.
- Tertukar arti `*` di definisi (mengumpulkan) dan di pemanggilan (membongkar).
- Kunci dict tidak cocok dengan nama parameter saat memakai `**`.
