## Dari satu neuron ke satu lapisan

Satu neuron menghasilkan satu angka. Satu **lapisan** berisi banyak neuron yang melihat input yang sama tapi punya bobot masing-masing.

Alih-alih menyimpan bobot tiap neuron terpisah, susun jadi satu matriks:

```python
import numpy as np

X = np.array([[1.0, 2.0]])          # 1 sampel, 2 fitur
W = np.array([[0.5, -0.2, 0.1],     # 2 fitur -> 3 neuron
              [0.3,  0.8, -0.4]])
b = np.array([0.0, 0.1, -0.1])      # satu bias per neuron

Z = X @ W + b                       # (1, 3)
A = np.maximum(0, Z)                # ReLU
```

Satu perkalian matriks = seluruh lapisan, untuk seluruh batch data sekaligus.

## Aturan bentuk

Ini bagian yang paling sering bikin error, jadi hafalkan:

| Objek | Bentuk |
|---|---|
| Input `X` | `(n_sampel, n_fitur)` |
| Bobot `W` | `(n_input, n_neuron)` |
| Bias `b` | `(n_neuron,)` |
| Keluaran | `(n_sampel, n_neuron)` |

Kalau muncul `shapes not aligned`, cetak ketiga bentuknya dan cocokkan angka tengahnya.

## Forward pass

Mengalirkan data dari input sampai keluaran:

```python
def forward(X, W1, b1, W2, b2):
    Z1 = X @ W1 + b1
    A1 = np.maximum(0, Z1)          # aktivasi lapisan tersembunyi
    Z2 = A1 @ W2 + b2
    A2 = 1 / (1 + np.exp(-Z2))      # sigmoid di keluaran
    return A2
```

Perhatikan polanya: **linear → aktivasi → linear → aktivasi**. Sedalam apa pun jaringannya, pola ini cuma diulang.

## Inisialisasi bobot

Jangan mulai dari nol — kalau semua bobot sama, semua neuron akan menghitung hal yang persis sama dan tetap begitu selamanya (*symmetry problem*). Mulai dari nilai acak kecil:

```python
rng = np.random.default_rng(42)

# He initialization — pasangan yang tepat untuk ReLU
W1 = rng.normal(0, np.sqrt(2 / n_input), (n_input, n_hidden))
b1 = np.zeros(n_hidden)
```

Kenapa dibagi akar `n_input`? Supaya besaran sinyalnya tetap stabil saat melewati banyak lapisan. Kalau bobot awal terlalu besar, nilainya meledak; kalau terlalu kecil, sinyalnya hilang.

| Aktivasi | Inisialisasi |
|---|---|
| ReLU | He: `sqrt(2 / n_input)` |
| tanh / sigmoid | Xavier: `sqrt(1 / n_input)` |

Bias boleh mulai dari nol — dia tidak punya masalah simetri.

## Menyimpan nilai antara

Saat melatih nanti, backpropagation butuh nilai-nilai di tengah jalan. Jadi simpan semuanya:

```python
def forward(X, params):
    cache = {'X': X}
    cache['Z1'] = X @ params['W1'] + params['b1']
    cache['A1'] = np.maximum(0, cache['Z1'])
    cache['Z2'] = cache['A1'] @ params['W2'] + params['b2']
    cache['A2'] = 1 / (1 + np.exp(-cache['Z2']))
    return cache['A2'], cache
```

Inilah alasan melatih model butuh memori jauh lebih besar daripada sekadar memakainya.

## Menghitung jumlah parameter

Untuk jaringan 2 → 4 → 1:

```
W1: 2×4 = 8      b1: 4
W2: 4×1 = 4      b2: 1
total = 17 parameter
```

GPT-3 punya 175 miliar parameter dengan pola perhitungan yang persis sama — cuma lapisannya jauh lebih banyak dan lebih lebar.

## Ringkasan

- Satu lapisan = satu perkalian matriks `X @ W + b`, lalu aktivasi.
- Bentuknya: `(n_sampel, n_fitur) @ (n_fitur, n_neuron)` → `(n_sampel, n_neuron)`.
- Bobot diinisialisasi acak kecil; nol membuat semua neuron identik.
- Simpan nilai antara (cache) karena dibutuhkan saat backpropagation.

## Kesalahan umum

- Menginisialisasi semua bobot dengan nol.
- Tertukar urutan `W` sehingga bentuknya tidak cocok.
- Memberi bias satu angka untuk seluruh lapisan, bukan satu per neuron.
