## Males nulis berulang? Pakai loop

Kalau harus nyetak "Halo" 100 kali, nggak mungkin kita copy-paste 100 baris. Di situ gunanya **perulangan**.

Lesson ini fokus ke `for` — perulangan yang dipakai kalau kamu tahu **apa** yang mau dilewati.

## `for` di atas sebuah koleksi

Bentuk paling dasar: "untuk tiap item di dalam sesuatu, lakukan ini".

```python
for buah in ["apel", "jeruk", "mangga"]:
    print(buah)
```

```
apel
jeruk
mangga
```

`buah` adalah variabel sementara yang berisi item saat ini. Namanya bebas, tapi pilih yang bermakna.

Python bisa melakukan `for` di atas hampir semua hal yang "berisi banyak":

```python
for huruf in "abc":            # string -> per karakter
    print(huruf)

for x in (1, 2, 3):            # tuple
    print(x)

for kunci in {"a": 1, "b": 2}: # dict -> per KUNCI
    print(kunci)
```

## `range()` — deret angka

```python
for i in range(3):
    print("Halo", i)
```

```
Halo 0
Halo 1
Halo 2
```

| Penulisan | Menghasilkan |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 5)` | 1, 2, 3, 4 |
| `range(1, 10, 2)` | 1, 3, 5, 7, 9 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |
| `range(0)` | (kosong, loop tidak jalan) |

Ingat: **angka akhir tidak ikut** (eksklusif). `range(1, 5)` berhenti di 4.

Kenapa eksklusif? Supaya `range(len(x))` pas dengan index list yang dimulai dari 0, dan supaya `range(a, b)` punya tepat `b - a` elemen.

`range` tidak membuat list di memori — dia menghasilkan angka satu per satu saat diminta. Makanya `range(10_000_000)` instan dan hemat memori.

```python
print(range(5))          # range(0, 5)   bukan daftar angka
print(list(range(5)))    # [0, 1, 2, 3, 4]
```

## `enumerate` — nomor urut + isinya

Butuh index sekaligus nilainya? Jangan pakai `range(len(...))`:

```python
buah = ["apel", "jeruk"]

# 😐 cara yang kurang Pythonic
for i in range(len(buah)):
    print(i, buah[i])

# ✅ cara yang benar
for i, b in enumerate(buah):
    print(i, b)

# mulai dari 1
for i, b in enumerate(buah, start=1):
    print(f"{i}. {b}")      # 1. apel / 2. jeruk
```

## `zip` — dua koleksi sekaligus

```python
nama = ["Budi", "Ani", "Citra"]
nilai = [80, 92, 75]

for n, v in zip(nama, nilai):
    print(f"{n}: {v}")
```

`zip` berhenti di koleksi terpendek — kalau `nama` 3 item dan `nilai` cuma 2, hasilnya 2 pasang. Perilaku ini bisa menyembunyikan bug data, jadi cek panjangnya kalau penting.

## Pola akumulator

Ini pola paling sering dipakai: siapkan wadah sebelum loop, isi di dalam loop.

```python
# menjumlah
total = 0
for n in [10, 20, 30]:
    total += n
print(total)     # 60

# mengumpulkan
hasil = []
for n in range(5):
    hasil.append(n * n)
print(hasil)     # [0, 1, 4, 9, 16]

# mencari yang terbesar
tertinggi = nilai[0]
for n in nilai:
    if n > tertinggi:
        tertinggi = n

# menghitung yang memenuhi syarat
lulus = 0
for n in nilai:
    if n >= 70:
        lulus += 1
```

⚠️ Kesalahan klasik: menaruh wadahnya **di dalam** loop.

```python
for n in [10, 20, 30]:
    total = 0        # ❌ direset tiap putaran
    total += n
print(total)         # 30, bukan 60
```

Python sebenarnya sudah menyediakan yang siap pakai untuk kasus umum:

```python
print(sum([10, 20, 30]))    # 60
print(max(nilai))
print(min(nilai))
print(len(nilai))
```

Pakai yang bawaan kalau ada — lebih pendek, lebih cepat, dan lebih jelas maksudnya.

## Loop bersarang

Loop di dalam loop. Loop dalam selesai penuh untuk **setiap** putaran loop luar.

```python
for i in range(1, 4):
    baris = ""
    for j in range(1, 4):
        baris += f"{i*j:4}"
    print(baris)
```

```
   1   2   3
   2   4   6
   3   6   9
```

Jumlah total putarannya adalah perkalian: 3 × 3 = 9. Hati-hati — loop bersarang di atas 10.000 data berarti 100 juta operasi.

## `for ... else`

Sintaks khas Python yang jarang dikenal: blok `else` pada loop dijalankan kalau loop **selesai tanpa `break`**.

```python
for n in [1, 3, 5]:
    if n % 2 == 0:
        print("ada yang genap")
        break
else:
    print("semua ganjil")     # ini yang tercetak
```

Berguna untuk pola "cari sesuatu, kalau tidak ketemu lakukan X" tanpa perlu variabel penanda.

## Jangan ubah list yang sedang di-loop

```python
angka = [1, 2, 3, 4]
for n in angka:
    if n % 2 == 0:
        angka.remove(n)     # ❌ hasilnya tidak terduga
print(angka)                # [1, 3, 4]  -> 4 lolos!
```

Python melacak posisi lewat index. Saat sebuah elemen dihapus, sisanya bergeser dan satu elemen terlewat.

Cara yang benar: buat list baru.

```python
angka = [n for n in angka if n % 2 != 0]     # comprehension (Modul 2)
# atau
hasil = []
for n in angka:
    if n % 2 != 0:
        hasil.append(n)
```

## Ringkasan

- `for item in koleksi` melewati isi apa pun yang bisa diurut.
- `range(a, b)` berhenti **sebelum** b; hemat memori karena tidak membuat list.
- `enumerate` untuk index + nilai, `zip` untuk dua koleksi sekaligus.
- Pola akumulator: siapkan wadah **di luar** loop, isi di dalam.
- Jangan menghapus elemen dari list yang sedang di-loop — buat list baru.

## Kesalahan umum

- Mengira `range(1, 5)` menghasilkan 1–5.
- Menaruh inisialisasi akumulator di dalam loop.
- Memakai `range(len(x))` padahal `enumerate` lebih jelas.
- Mengubah list yang sedang diiterasi sehingga ada elemen terlewat.
