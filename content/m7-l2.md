## Mengambil baris yang kamu butuh

Ada dua cara memilih baris di pandas, dan bedanya sering bikin pemula tersandung.

| Cara | Pakai | Contoh |
|---|---|---|
| `.loc` | **label** index | `df.loc[2, 'nama']` |
| `.iloc` | **posisi** angka | `df.iloc[0, 1]` |

```python
import pandas as pd
df = pd.DataFrame({
    'nama':  ['Budi', 'Ani', 'Citra'],
    'umur':  [20, 22, 21],
    'nilai': [80, 90, 70]
})

df.loc[0]                 # baris berlabel 0 (Series)
df.loc[0, 'nama']         # 'Budi'
df.loc[0:1]               # baris 0 SAMPAI 1 — ujungnya IKUT
df.loc[:, 'nama']         # seluruh kolom nama

df.iloc[0]                # baris posisi 0
df.iloc[0, 1]             # baris 0, kolom 1 -> 20
df.iloc[0:2]              # posisi 0 dan 1 — ujungnya TIDAK ikut
df.iloc[-1]               # baris terakhir
```

⚠️ Beda halus yang penting: `.loc[0:1]` mengambil **dua** baris, `.iloc[0:2]` juga dua baris. `.loc` inklusif karena bekerja dengan label, `.iloc` eksklusif karena bekerja dengan posisi seperti list Python.

## Menyaring baris

Sama seperti boolean mask NumPy:

```python
df[df['nilai'] >= 80]
df[df['nama'] == 'Ani']
```

Gabungkan kondisi dengan `&`, `|`, `~` dan selalu pakai kurung:

```python
df[(df['nilai'] >= 75) & (df['umur'] < 22)]
```

Dua helper yang bikin kode jauh lebih bersih:

```python
df[df['nama'].isin(['Budi', 'Citra'])]        # salah satu dari daftar
df[df['umur'].between(20, 21)]                # rentang, inklusif
df[df['nama'].str.startswith('B')]            # operasi teks lewat .str
df[df['nama'].str.contains('an', case=False)]
```

## `.query()` — versi yang lebih enak dibaca

```python
df.query('nilai >= 75 and umur < 22')
df.query('nama in ["Budi", "Ani"]')
```

Untuk kondisi panjang, `.query()` jauh lebih terbaca daripada tumpukan kurung.

## Mengurutkan

```python
df.sort_values('nilai')                     # menaik
df.sort_values('nilai', ascending=False)    # menurun
df.sort_values(['umur', 'nilai'])           # dua kriteria
df.nlargest(2, 'nilai')                     # 2 nilai tertinggi
df.nsmallest(2, 'nilai')
```

## Menyaring lalu memilih kolom sekaligus

```python
df.loc[df['nilai'] >= 80, ['nama', 'nilai']]
```

Pola `df.loc[kondisi, kolom]` adalah bentuk paling jelas dan paling aman.

## SettingWithCopyWarning

```python
sub = df[df['nilai'] > 75]
sub['bonus'] = 10        # ⚠️ SettingWithCopyWarning
```

pandas tidak yakin apakah `sub` itu salinan atau jendela ke `df`. Cara aman:

```python
sub = df[df['nilai'] > 75].copy()
sub['bonus'] = 10
```

Atau ubah langsung di aslinya:

```python
df.loc[df['nilai'] > 75, 'bonus'] = 10
```

## Ringkasan

- `.loc` memakai label dan ujungnya ikut; `.iloc` memakai posisi dan ujungnya tidak ikut.
- Menyaring baris memakai boolean mask, gabungkan dengan `&`, `|`, `~`.
- `.isin()`, `.between()`, `.str` dan `.query()` bikin filter lebih bersih.
- Pakai `.copy()` saat hasil filter mau diubah, atau ubah lewat `df.loc[...]`.

## Kesalahan umum

- Tertukar `.loc` dan `.iloc`.
- Memakai `and`/`or` pada filter DataFrame.
- Mengubah hasil filter langsung sehingga muncul `SettingWithCopyWarning`.
