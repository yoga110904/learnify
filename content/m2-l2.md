## Tuple: list yang dikunci

**Tuple** mirip list, tapi setelah dibuat isinya **tidak bisa diubah** (immutable). Ditulis dengan kurung biasa:

```python
titik = (10, 20)
warna = ("merah", "hijau", "biru")
satu = (5,)        # perhatikan koma! tanpa koma itu cuma angka 5
```

```python
titik[0] = 99     # 💥 TypeError
```

Kapan pakai tuple?

- Data yang memang nggak boleh berubah: koordinat, tanggal, konfigurasi.
- Lebih hemat memori dan sedikit lebih cepat dari list.
- Bisa dipakai jadi **kunci dictionary** (list nggak bisa).

## Unpacking

Membongkar isi tuple ke beberapa variabel sekaligus:

```python
titik = (10, 20)
x, y = titik
print(x, y)     # 10 20
```

Ini yang bikin trik tukar nilai jalan:

```python
a, b = b, a       # sisi kanan otomatis jadi tuple
```

Fungsi yang "mengembalikan dua nilai" sebenarnya mengembalikan tuple:

```python
def bagi(a, b):
    return a // b, a % b

hasil, sisa = bagi(7, 2)
print(hasil, sisa)     # 3 1
```

## Set: koleksi unik tanpa urutan

**Set** otomatis membuang duplikat. Ditulis dengan kurung kurawal:

```python
angka = {1, 2, 2, 3, 3, 3}
print(angka)        # {1, 2, 3}
print(len({1, 1, 2, 3}))   # 3
```

⚠️ Set **tidak punya urutan** dan **tidak bisa diakses pakai index**:

```python
angka[0]     # 💥 TypeError
```

Set kosong harus ditulis `set()`, karena `{}` itu dictionary kosong.

### Operasi himpunan

Ini persis pelajaran himpunan di sekolah:

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)   # {1,2,3,4,5}   union (gabungan)
print(a & b)   # {3}           intersection (irisan)
print(a - b)   # {1,2}         difference (selisih)
print(a ^ b)   # {1,2,4,5}     symmetric difference
```

Bentuk method-nya: `a.union(b)`, `a.intersection(b)`, `a.difference(b)`.

### Set cepat banget buat mengecek keanggotaan

```python
data = {1, 2, 3}
print(2 in data)     # True — pengecekan ini sangat cepat
```

Kalau kamu harus mengecek `x in ...` ribuan kali pada data besar, set jauh lebih cepat daripada list.

## Menghapus duplikat

```python
data = [3, 1, 3, 2, 1]
print(list(set(data)))    # [1, 2, 3]  -> urutannya BISA berubah!
```

Kalau urutan kemunculan pertama harus dipertahankan, jangan pakai `set()` langsung — pakai set hanya sebagai catatan "sudah pernah dilihat":

```python
def hapus_duplikat(data):
    seen = set()
    hasil = []
    for x in data:
        if x not in seen:
            seen.add(x)
            hasil.append(x)
    return hasil
```

## Ringkasan

- Tuple = urutan yang tidak bisa diubah; ditulis dengan `()`.
- Unpacking membongkar tuple ke beberapa variabel.
- Set = koleksi unik, tanpa urutan, tanpa index.
- Set mendukung union `|`, intersection `&`, difference `-`.

## Kesalahan umum

- Menulis tuple satu elemen tanpa koma: `(5)` bukan tuple.
- Mengira `list(set(x))` mempertahankan urutan asli.
- Membuat set kosong dengan `{}` (itu dict).
