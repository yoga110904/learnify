## Membandingkan dua nilai

Operator perbandingan selalu menghasilkan `bool` — `True` atau `False`.

```python
print(5 == 5)    # True   sama dengan
print(5 != 3)    # True   tidak sama dengan
print(5 > 10)    # False  lebih besar
print(5 < 10)    # True   lebih kecil
print(5 >= 5)    # True   lebih besar atau sama
print(5 <= 4)    # False  lebih kecil atau sama
```

⚠️ `=` (satu) buat **mengisi** variabel, `==` (dua) buat **membandingkan**. Ini salah satu typo paling sering, dan Python akan menegurmu:

```python
if x = 5:        # 💥 SyntaxError: invalid syntax
if x == 5:       # ✅
```

## Membandingkan tipe lain

```python
print("apel" == "apel")     # True
print("apel" < "jeruk")     # True   urutan alfabet
print("Apel" < "apel")      # True   huruf besar lebih dulu
print([1, 2] == [1, 2])     # True   isi dibandingkan
```

String dibandingkan **karakter demi karakter** berdasarkan kode karakternya. Karena huruf besar punya kode lebih kecil, `"Zebra" < "apel"` bernilai `True` — sering bikin hasil pengurutan terlihat aneh. Solusinya: samakan dulu dengan `.lower()`.

Membandingkan tipe yang tidak sebanding akan error:

```python
print(5 > "3")       # 💥 TypeError
```

Tapi `==` tidak error, cuma menghasilkan `False`:

```python
print(5 == "5")      # False
```

Itu sebabnya `input()` yang menghasilkan string sering bikin perbandingan diam-diam gagal.

## Rantai perbandingan

Python bisa menulis rentang seperti di matematika — banyak bahasa lain tidak bisa:

```python
nilai = 75
print(70 <= nilai < 85)      # True
```

Ini setara dengan `70 <= nilai and nilai < 85`, tapi jauh lebih terbaca.

## `==` vs `is`

Dua hal yang kelihatan mirip tapi berbeda:

| Operator | Menanyakan |
|---|---|
| `==` | apakah **isinya** sama? |
| `is` | apakah ini **objek yang sama persis** di memori? |

```python
a = [1, 2, 3]
b = [1, 2, 3]
c = a

print(a == b)    # True   isinya sama
print(a is b)    # False  dua objek berbeda
print(a is c)    # True   c menunjuk objek yang sama dengan a
```

Aturan praktis: **pakai `==` untuk membandingkan nilai, `is` hanya untuk `None`, `True`, dan `False`.**

```python
if hasil is None:       # ✅ cara baku
if hasil == None:       # 😐 jalan, tapi tidak idiomatis
```

Jebakan klasik: Python menyimpan cache untuk bilangan bulat kecil, jadi `is` kadang terlihat "berhasil" padahal kebetulan.

```python
a = 256; b = 256
print(a is b)     # True   (di-cache)

a = 257; b = 257
print(a is b)     # False  (tidak di-cache)
```

Jangan pernah mengandalkan perilaku ini.

## Operator logika

Buat menggabungkan beberapa kondisi:

| Operator | `True` kalau | Analogi |
|---|---|---|
| `and` | **semua** kondisi benar | "harus bawa KTP **dan** tiket" |
| `or` | **minimal satu** benar | "bayar pakai cash **atau** QRIS" |
| `not` | membalik nilai | "**bukan** anggota" |

```python
umur = 20
punya_ktp = True

print(umur >= 17 and punya_ktp)   # True
print(umur < 17 or punya_ktp)     # True
print(not punya_ktp)              # False
print(True and not False)         # True
```

Tabel kebenaran lengkapnya:

```
A       B       A and B    A or B
True    True    True       True
True    False   False      True
False   True    False      True
False   False   False      False
```

Urutan prioritas: `not` → `and` → `or`. Jadi:

```python
print(True or False and False)      # True
# dibaca: True or (False and False) -> True or False -> True
```

Sekali lagi: kalau ragu, pakai kurung.

## Short-circuit — hemat dan menyelamatkan

Python berhenti mengevaluasi begitu jawabannya sudah pasti:

```python
# 'and': kalau yang kiri False, yang kanan tidak dijalankan sama sekali
False and print("ini tidak dicetak")

# 'or': kalau yang kiri True, yang kanan tidak dijalankan
True or print("ini juga tidak")
```

Ini bukan sekadar optimasi — ini dipakai untuk melindungi kode dari error:

```python
nilai = []
if len(nilai) > 0 and nilai[0] > 5:     # aman
    print("besar")
```

Kalau urutannya dibalik jadi `nilai[0] > 5 and len(nilai) > 0`, program langsung `IndexError`. Urutan kondisi itu penting.

Pola yang sama untuk nilai default:

```python
nama = input_user or "Tanpa Nama"     # kalau input_user kosong, pakai default
```

## Nilai truthy & falsy

Setiap nilai punya "rasa" benar atau salah waktu dipakai sebagai kondisi. Yang dianggap **falsy** cuma sedikit:

```python
bool(0)         # False
bool(0.0)       # False
bool("")        # False   string kosong
bool([])        # False   list kosong
bool({})        # False   dict kosong
bool(None)      # False

bool(-5)        # True    angka negatif tetap True!
bool("0")       # True    string berisi "0" tetap True!
bool(" ")       # True    spasi juga isi
bool([0])       # True    list berisi satu elemen
```

Makanya pengecekan data kosong bisa sesingkat ini:

```python
if not daftar:
    print("daftarnya kosong")
```

⚠️ Tapi hati-hati saat nol adalah nilai yang sah:

```python
nilai = 0
if nilai:                  # ❌ dianggap kosong padahal nilainya valid
    print(nilai)
if nilai is not None:      # ✅ pengecekan yang tepat
    print(nilai)
```

## Operator keanggotaan & identitas

```python
print("a" in "apel")            # True
print(3 in [1, 2, 3])           # True
print("x" not in "apel")        # True
print("nama" in {"nama": "A"})  # True   -> mengecek KUNCI-nya
```

`in` jauh lebih ringkas daripada menulis rantai `or`:

```python
if hari == "Sabtu" or hari == "Minggu":     # 😐
if hari in ("Sabtu", "Minggu"):             # ✅
```

<div class="latihan"><b>Latihan 4.</b> Kapan sebaiknya memakai <code>is</code> alih-alih <code>==</code>?</div>

<details>
<summary>Lihat jawaban</summary>

Hanya untuk membandingkan dengan `None`, `True`, dan `False` — karena ketiganya adalah objek tunggal (*singleton*) di Python.


Untuk semua perbandingan nilai lainnya, pakai `==`. Memakai `is` pada angka atau string bisa "kebetulan benar" karena caching, lalu tiba-tiba gagal dengan nilai berbeda.
</details>

## Ringkasan

- Perbandingan menghasilkan `bool`; `=` mengisi, `==` membandingkan.
- Rantai `a <= x < b` sah di Python dan lebih terbaca.
- `==` membandingkan isi, `is` membandingkan identitas objek — pakai `is` hanya untuk `None`/`True`/`False`.
- `and`/`or` melakukan short-circuit; urutan kondisi bisa menyelamatkan dari error.
- Falsy: `0`, `0.0`, `""`, `[]`, `{}`, `None`. Selain itu truthy.

## Kesalahan umum

- Menulis `=` waktu maksudnya `==`.
- Memakai `is` untuk membandingkan angka atau string.
- Menaruh pengecekan panjang setelah pengaksesan index.
- Memakai `if nilai:` padahal 0 adalah nilai yang sah.
