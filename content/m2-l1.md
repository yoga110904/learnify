## Satu variabel, banyak isi

Kalau kamu punya nilai 30 siswa, masa bikin 30 variabel? **List** adalah wadah yang bisa menampung banyak nilai berurutan.

```python
nilai = [80, 75, 92, 60]
buah = ["apel", "jeruk", "mangga"]
campur = [1, "dua", 3.0, True]      # boleh campur tipe
bersarang = [[1, 2], [3, 4]]        # list di dalam list
kosong = []
```

Tiga sifat yang membedakan list dari tipe koleksi lain:

| Sifat | Artinya |
|---|---|
| **Berurutan** | posisi tiap elemen tetap dan bisa diandalkan |
| **Mutable** | isinya bisa diubah setelah dibuat |
| **Boleh duplikat** | `[1, 1, 1]` itu sah |

## Akses dan ubah

Sama seperti string, index dimulai dari 0.

```python
buah = ["apel", "jeruk", "mangga"]
print(buah[0])      # apel
print(buah[-1])     # mangga
print(buah[0:2])    # ['apel', 'jeruk']
print(buah[5])      # 💥 IndexError: list index out of range
```

Bedanya dengan string: list **mutable** (bisa diubah di tempat).

```python
buah[1] = "pisang"
print(buah)         # ['apel', 'pisang', 'mangga']

buah[0:2] = ["a", "b", "c"]    # slicing juga bisa ditimpa
print(buah)                    # ['a', 'b', 'c', 'mangga']
```

Untuk list bersarang, pakai kurung siku berlapis:

```python
matriks = [[1, 2, 3],
           [4, 5, 6]]
print(matriks[1][2])    # 6   -> baris 1, kolom 2
```

## Menambah elemen

```python
b = ["apel"]

b.append("jeruk")           # tambah SATU di akhir  -> ['apel', 'jeruk']
b.insert(1, "nanas")        # sisipkan di index 1
b.extend(["a", "b"])        # tambah BANYAK di akhir
b += ["c"]                  # sama dengan extend
```

⚠️ Beda `append` dan `extend` sering bikin bingung:

```python
x = [1, 2]
x.append([3, 4])     # [1, 2, [3, 4]]   -> masuk sebagai SATU elemen
x = [1, 2]
x.extend([3, 4])     # [1, 2, 3, 4]     -> isinya dibongkar
```

## Menghapus elemen

```python
b = ["a", "b", "c", "b"]

b.remove("b")     # hapus KEMUNCULAN PERTAMA  -> ['a', 'c', 'b']
x = b.pop()       # ambil & hapus yang terakhir, kembalikan nilainya
y = b.pop(0)      # ambil & hapus index 0
del b[0]          # hapus berdasarkan index, tidak mengembalikan apa-apa
b.clear()         # kosongkan
```

Ringkasnya:

| Perintah | Berdasarkan | Mengembalikan nilai? |
|---|---|---|
| `remove(x)` | nilai | tidak |
| `pop(i)` | index | ya |
| `del lst[i]` | index | tidak |

`remove()` error kalau nilainya tidak ada, jadi cek dulu:

```python
if "b" in b:
    b.remove("b")
```

## Mengurutkan

```python
n = [3, 1, 2]
n.sort()                # [1, 2, 3]        mengubah list asli
n.sort(reverse=True)    # [3, 2, 1]
n.reverse()             # membalik urutan (tanpa mengurutkan)
```

### `sorted()` vs `.sort()`

Ini sering ditanya waktu wawancara:

```python
a = [3, 1, 2]
b = sorted(a)      # b = [1,2,3], a TETAP [3,1,2]  -> bikin list BARU
a.sort()           # a jadi [1,2,3], mengembalikan None
```

Jebakannya:

```python
a = [3, 1, 2]
a = a.sort()
print(a)     # None 😱
```

Karena `.sort()` mengembalikan `None`, bukan listnya. Aturan umum Python: **method yang mengubah objek di tempat mengembalikan `None`.**

## Mencari & menghitung

```python
n = [10, 20, 30, 20]

print(n.index(20))    # 1    posisi kemunculan pertama
print(n.count(20))    # 2    berapa kali muncul
print(20 in n)        # True
print(n.index(99))    # 💥 ValueError kalau tidak ada
```

## Fungsi agregat

```python
n = [80, 75, 92, 60]
print(len(n))    # 4
print(sum(n))    # 307
print(max(n))    # 92
print(min(n))    # 60
print(sum(n) / len(n))   # 76.75
```

Hati-hati `sum(n) / len(n)` saat list kosong → `ZeroDivisionError`. Selalu cek dulu:

```python
def rata(n):
    if not n:          # list kosong = falsy
        return 0
    return sum(n) / len(n)
```

## Jebakan: list itu "titipan alamat"

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)     # [1, 2, 3, 4]  <- ikut berubah!
```

`b = a` tidak menyalin isi, cuma menempelkan label baru ke kotak yang sama. Kalau mau salinan asli:

```python
b = a.copy()      # atau list(a), atau a[:]
```

Ini dibahas tuntas di lesson **Mutability & Referensi** nanti — untuk sekarang, ingat saja bahwa `=` pada list itu berbagi, bukan menyalin.

## Membuat list dengan cepat

```python
[0] * 5             # [0, 0, 0, 0, 0]
list(range(5))      # [0, 1, 2, 3, 4]
list("abc")         # ['a', 'b', 'c']
"a,b".split(",")    # ['a', 'b']
```

⚠️ Jebakan `*` pada list bersarang:

```python
grid = [[0] * 3] * 2
grid[0][0] = 9
print(grid)     # [[9, 0, 0], [9, 0, 0]]   😱 dua-duanya berubah
```

Karena `* 2` menyalin **referensi** ke list yang sama. Cara benar:

```python
grid = [[0] * 3 for _ in range(2)]
```

## Ringkasan

- List menyimpan banyak nilai berurutan, bisa diubah (mutable), dan boleh duplikat.
- `append` menambah satu elemen, `extend` membongkar isinya.
- `remove` berdasarkan nilai, `pop` berdasarkan index dan mengembalikan nilainya.
- `sorted()` bikin list baru; `.sort()` mengubah list asli dan mengembalikan `None`.
- `b = a` berbagi list yang sama — pakai `.copy()` untuk menyalin.

## Kesalahan umum

- `a = a.sort()` lalu heran hasilnya `None`.
- Tertukar `append` dan `extend`.
- Menghapus elemen sambil melakukan loop pada list yang sama.
- Memakai `[[0]*3]*3` untuk membuat matriks.
- Lupa mengecek list kosong sebelum membagi dengan `len()`.
