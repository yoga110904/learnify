## Pertanyaan yang selalu muncul

"Rata-rata pembelian **per kota** berapa?"
"Produk mana yang paling laku **per bulan**?"

Polanya selalu sama: **belah → hitung → gabung**. Di pandas namanya `groupby`.

```python
import pandas as pd

df = pd.DataFrame({
    'kota':   ['Bandung', 'Jakarta', 'Bandung', 'Jakarta'],
    'produk': ['A', 'A', 'B', 'B'],
    'jumlah': [10, 20, 30, 40]
})

df.groupby('kota')['jumlah'].sum()
```

```
kota
Bandung    40
Jakarta    60
```

Bacanya: *kelompokkan berdasarkan kota, ambil kolom jumlah, jumlahkan tiap kelompok.*

## Fungsi agregasi

```python
df.groupby('kota')['jumlah'].mean()
df.groupby('kota')['jumlah'].count()     # berapa baris per kelompok
df.groupby('kota')['jumlah'].max()
df.groupby('kota')['jumlah'].nunique()   # berapa nilai unik
df.groupby('kota').size()                # ukuran tiap kelompok
```

## Beberapa agregasi sekaligus

```python
df.groupby('kota')['jumlah'].agg(['sum', 'mean', 'count'])
```

```
          sum  mean  count
kota
Bandung    40  20.0      2
Jakarta    60  30.0      2
```

Beda kolom, beda perlakuan:

```python
df.groupby('kota').agg({
    'jumlah': ['sum', 'mean'],
    'produk': 'nunique'
})
```

Kasih nama kolom hasilnya supaya rapi (*named aggregation*):

```python
df.groupby('kota').agg(
    total=('jumlah', 'sum'),
    rata=('jumlah', 'mean'),
    n_produk=('produk', 'nunique')
).reset_index()
```

`reset_index()` mengubah hasil groupby kembali jadi DataFrame biasa dengan kolom `kota` — hampir selalu kamu butuhkan sebelum data dipakai lebih lanjut.

## Mengelompokkan berdasarkan beberapa kolom

```python
df.groupby(['kota', 'produk'])['jumlah'].sum()
```

```
kota     produk
Bandung  A         10
         B         30
Jakarta  A         20
         B         40
```

## `transform` — hasil sepanjang data asli

`agg` meringkas (baris jadi sedikit). `transform` mengembalikan hasil dengan **panjang yang sama** seperti data asli — cocok untuk membuat fitur baru:

```python
df['total_kota'] = df.groupby('kota')['jumlah'].transform('sum')
df['persen'] = df['jumlah'] / df['total_kota'] * 100
```

Sekarang tiap baris tahu porsinya terhadap kotanya sendiri. Ini teknik rekayasa fitur yang sering dipakai sebelum melatih model.

## `apply` — logika bebas

```python
df.groupby('kota')['jumlah'].apply(lambda s: s.max() - s.min())
```

Fleksibel tapi paling lambat. Pakai hanya kalau `agg` dan `transform` tidak cukup.

## Pivot table

Versi tabel silang, seperti di Excel:

```python
df.pivot_table(index='kota', columns='produk', values='jumlah', aggfunc='sum')
```

```
produk    A   B
kota
Bandung  10  30
Jakarta  20  40
```

Tambahkan `fill_value=0` supaya kombinasi yang kosong tidak jadi `NaN`.

## Ringkasan

- `groupby` bekerja dengan pola belah → hitung → gabung.
- `agg` meringkas, `transform` mengembalikan hasil sepanjang data asli.
- Named aggregation membuat nama kolom hasil jadi jelas.
- `reset_index()` mengubah hasil groupby kembali jadi DataFrame biasa.

## Kesalahan umum

- Lupa `reset_index()` lalu bingung kenapa kolom kuncinya hilang.
- Memakai `apply` padahal `agg` sudah cukup (dan jauh lebih cepat).
- Tertukar `agg` dan `transform` saat membuat kolom fitur baru.
