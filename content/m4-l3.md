## Jangan tulis ulang yang sudah ada

Misal kamu punya class `Karyawan`. Lalu muncul `Manajer` — sama persis, cuma punya tunjangan tambahan. Copy-paste seluruh class? Jangan. Pakai **inheritance** (pewarisan).

```python
class Karyawan:
    def __init__(self, nama, gaji):
        self.nama = nama
        self.gaji = gaji

    def info(self):
        return f"{self.nama} - {self.gaji}"


class Manajer(Karyawan):          # Manajer mewarisi Karyawan
    pass

m = Manajer("Salsa", 100)
print(m.info())        # Salsa - 100  <- gratis, tanpa nulis ulang
```

Istilahnya: `Karyawan` adalah **parent/superclass/induk**, `Manajer` adalah **child/subclass/turunan**.

## `super().__init__()`

Kalau child punya atribut tambahan, dia butuh `__init__` sendiri — sekaligus tetap menjalankan `__init__` milik induk:

```python
class Manajer(Karyawan):
    def __init__(self, nama, gaji, tunjangan):
        super().__init__(nama, gaji)     # jalankan __init__ induk
        self.tunjangan = tunjangan

    def total_gaji(self):
        return self.gaji + self.tunjangan

m = Manajer("Salsa", 100, 50)
print(m.total_gaji())    # 150
print(m.info())          # Salsa - 100
```

Tanpa `super().__init__(...)`, atribut `nama` dan `gaji` tidak pernah dibuat, dan `m.info()` akan `AttributeError`.

## Override — menimpa method induk

Child boleh menulis ulang method dengan nama yang sama:

```python
class Manajer(Karyawan):
    def info(self):
        return f"[Manajer] {self.nama}"

print(Manajer("Salsa", 100).info())   # [Manajer] Salsa
```

Sering kita mau **menambah**, bukan mengganti total. Panggil versi induk lalu tambahkan:

```python
class Manajer(Karyawan):
    def info(self):
        return super().info() + " (manajer)"
```

## Mengecek hubungan

```python
m = Manajer("A", 100, 10)

isinstance(m, Manajer)     # True
isinstance(m, Karyawan)    # True  <- turunan tetap dianggap induk
issubclass(Manajer, Karyawan)   # True
```

## Sedalam apa boleh mewarisi?

Secara teknis Python mendukung banyak tingkat dan bahkan **multiple inheritance** (`class A(B, C)`). Tapi rantai warisan yang dalam bikin pusing: kamu harus buka lima file cuma buat tahu satu method datang dari mana.

Pedoman praktis:

- Pakai inheritance kalau hubungannya benar-benar **"adalah sebuah"** — Manajer *adalah* Karyawan.
- Kalau hubungannya "punya" — Mobil *punya* Mesin — pakai **composition** (simpan objek lain sebagai atribut), bukan inheritance.

```python
class Mobil:
    def __init__(self):
        self.mesin = Mesin()    # composition
```

## Ringkasan

- `class Anak(Induk)` mewarisi semua atribut dan method induk.
- `super().__init__()` menjalankan constructor induk — hampir selalu perlu.
- Override mengganti method; `super().method()` memperluasnya.
- Pakai inheritance untuk relasi "adalah", composition untuk relasi "punya".

## Kesalahan umum

- Lupa memanggil `super().__init__()` sehingga atribut induk tidak ada.
- Membuat rantai warisan terlalu dalam.
- Memakai inheritance hanya demi berbagi satu fungsi kecil.
