## Variabel = kotak berlabel

Bayangin lemari dengan banyak kotak. Tiap kotak ditempelin label, dan di dalamnya ada isi. Kalau kamu butuh isinya, kamu tinggal sebut labelnya.

```python
umur = 20
nama = "Salsa"
```

`umur` dan `nama` adalah **label** (nama variabel). `20` dan `"Salsa"` adalah **isinya** (nilai). Tanda `=` di sini bukan "sama dengan" ala matematika, tapi **"isi kotak ini dengan"**.

Bacanya dari kanan ke kiri: *hitung dulu sisi kanannya, lalu simpan hasilnya ke label di kiri.* Itu sebabnya baris ini masuk akal:

```python
skor = 10
skor = skor + 5      # ambil isi skor (10), tambah 5, simpan lagi ke skor
print(skor)          # 15
```

Kalau `=` berarti "sama dengan", baris kedua itu mustahil. Tapi karena artinya "isi dengan", dia sah.

## Empat tipe data dasar

| Tipe | Arti | Contoh | Ditulis |
|---|---|---|---|
| `int` | bilangan bulat | `20`, `-5`, `0` | tanpa kutip, tanpa titik |
| `float` | bilangan desimal | `3.14`, `-0.5`, `10.0` | pakai titik, bukan koma |
| `str` | teks (string) | `"halo"`, `'Salsa'` | diapit kutip |
| `bool` | benar/salah | `True`, `False` | huruf besar di depan |

```python
umur = 21          # int
tinggi = 165.5     # float
nama = "Salsa"     # str
aktif = True       # bool
```

Tiga jebakan penulisan yang sering kena:

```python
harga = 10,5       # ❌ ini tuple, bukan float! Pakai titik: 10.5
aktif = true       # ❌ NameError — harus True
nama = Salsa       # ❌ NameError — teks harus diapit kutip
```

Kutip tunggal dan ganda sama saja. Pilih salah satu dan konsisten; pakai yang satunya kalau isinya mengandung kutip:

```python
pesan = "Dia bilang 'halo'"
pesan = 'Dia bilang "halo"'
```

## Cek tipe dengan `type()`

```python
print(type(21))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("21"))      # <class 'str'>
print(type(True))      # <class 'bool'>
```

Hati-hati: `21` dan `"21"` beda. Yang pertama angka, yang kedua teks yang kebetulan berbentuk angka. Ini penyebab bug nomor satu buat pemula:

```python
a = 21
b = "21"
print(a + 1)      # 22
print(b + 1)      # 💥 TypeError
print(b + "1")    # "211"  <- disambung, bukan dijumlah
```

Kalau hasilnya aneh, `print(type(x))` biasanya langsung menjawab kenapa.

### Bonus: `bool` sebenarnya angka

```python
print(True + True)     # 2
print(int(False))      # 0
print(isinstance(True, int))   # True
```

Di balik layar, `True` adalah 1 dan `False` adalah 0. Ini terdengar aneh, tapi nanti sangat berguna — `(nilai > 70).sum()` bisa langsung menghitung berapa siswa yang lulus.

## Aturan penamaan variabel

Aturan wajib (kalau dilanggar → error):

- Nggak boleh diawali angka: `2nama` ❌, `nama2` ✅
- Nggak boleh ada spasi atau tanda baca selain `_`: `nama user` ❌, `nama_user` ✅
- Nggak boleh pakai kata kunci Python: `class`, `if`, `for`, `return`, `def`, `lambda`, `import`

Mau lihat semua kata terlarangnya?

```python
import keyword
print(keyword.kwlist)
```

Konvensi (nggak error, tapi bikin kode enak dibaca):

```python
total_harga = 50000     # ✅ snake_case — gaya Python
totalHarga = 50000      # 😐 camelCase — gaya JavaScript
TotalHarga = 50000      # ❌ PascalCase — ini gaya penamaan class
TOTAL_HARGA = 50000     # ✅ SCREAMING_CASE — khusus konstanta
```

Dan pilih nama yang jujur. Ini bukan soal estetika — nama yang baik menghemat berjam-jam waktu debugging:

```python
x = 3600000            # 3,6 juta apa?
gaji_pokok = 3600000   # jelas
```

⚠️ Satu kesalahan yang diam-diam berbahaya: menimpa nama bawaan Python.

```python
list = [1, 2, 3]       # sekarang fungsi list() rusak
print(list("abc"))     # 💥 TypeError: 'list' object is not callable
```

Nama yang sering tidak sengaja ditimpa: `list`, `dict`, `str`, `sum`, `max`, `min`, `id`, `type`, `input`. Editor biasanya mewarnainya berbeda — perhatikan warnanya.

## Beberapa variabel sekaligus

```python
a, b = 1, 2
print(a, b)     # 1 2

a, b = b, a     # tukar isi, trik khas Python
print(a, b)     # 2 1

x = y = z = 0   # tiga-tiganya jadi 0
```

Jumlah kiri dan kanan harus sama:

```python
a, b = 1, 2, 3     # 💥 ValueError: too many values to unpack
```

## Menghapus & mengganti tipe

Variabel Python **tidak terikat tipe**. Satu variabel boleh ganti tipe kapan saja:

```python
x = 10        # int
x = "halo"    # sekarang str, dan itu sah
```

Fleksibel, tapi rawan bug — makanya di Modul 5 kita belajar *type hints* untuk menandai tipe yang diharapkan.

```python
del x         # hapus variabelnya
print(x)      # 💥 NameError
```

## Konstanta

Python tidak punya konstanta sungguhan. Yang ada cuma kesepakatan: **huruf besar semua = jangan diubah**.

```python
PPN = 0.11
BATAS_LULUS = 70
```

Secara teknis masih bisa diubah, tapi programmer lain akan tahu bahwa itu tidak seharusnya.


## Ringkasan

- Variabel adalah kotak berlabel; `=` artinya "isi dengan", dievaluasi dari kanan ke kiri.
- Tipe dasar: `int`, `float`, `str`, `bool`. Desimal pakai titik, `True`/`False` huruf besar.
- `type()` dipakai buat mengecek tipe — perintah pertama saat hasil terasa aneh.
- Nama variabel pakai snake_case, tidak diawali angka, dan jangan menimpa nama bawaan.
- Konstanta ditulis HURUF_BESAR sebagai kesepakatan, bukan aturan teknis.

## Kesalahan umum

- Menulis `True` jadi `true` → `NameError`.
- Memakai koma untuk desimal (`10,5`) — itu malah bikin tuple.
- Menganggap `"10"` sama dengan `10`.
- Menimpa nama bawaan seperti `list`, `str`, atau `sum`.
- Memakai nama satu huruf yang nggak jelas maksudnya.
