## Mengubah bentuk tanpa mengubah isi

`reshape` menyusun ulang elemen ke bentuk baru. Jumlah elemennya harus tetap sama.

```python
import numpy as np
x = np.arange(6)          # [0 1 2 3 4 5]

x.reshape(2, 3)
# [[0 1 2]
#  [3 4 5]]

x.reshape(3, 2)
# [[0 1]
#  [2 3]
#  [4 5]]

x.reshape(2, 4)           # 💥 ValueError: cannot reshape size 6 into (2,4)
```

Angka `-1` berarti "hitung sendiri":

```python
x.reshape(-1, 2)     # jadi 3 baris, 2 kolom
x.reshape(1, -1)     # jadi 1 baris  (1, 6)  -> satu sampel
x.reshape(-1, 1)     # jadi 1 kolom  (6, 1)  -> satu fitur
x.ravel()            # kembali jadi 1 dimensi
```

`reshape(1, -1)` dan `reshape(-1, 1)` akan sering kamu pakai — scikit-learn menolak array 1 dimensi dan menyuruh kamu memilih salah satunya.

## Transpose

Menukar baris dan kolom:

```python
x = np.array([[1, 2, 3],
              [4, 5, 6]])      # (2, 3)

x.T
# [[1 4]
#  [2 5]
#  [3 6]]                      # (3, 2)
```

## Perkalian matriks

Inilah operasi inti di balik setiap neural network.

```python
a = np.array([[1, 2],
              [3, 4]])
b = np.array([[5, 6],
              [7, 8]])

a * b        # per elemen: [[5 12], [21 32]]
a @ b        # matriks:    [[19 22], [43 50]]
```

`@` sama dengan `np.dot(a, b)` atau `a.dot(b)`. Gunakan `@` — paling terbaca.

### Aturan bentuknya

```
(m, n) @ (n, p)  ->  (m, p)
```

Angka di tengah **harus sama**, dan angka itulah yang lenyap:

```python
X = np.zeros((100, 4))    # 100 sampel, 4 fitur
W = np.zeros((4, 3))      # bobot: 4 fitur -> 3 neuron
(X @ W).shape             # (100, 3)   ✅

W @ X                     # 💥 shapes (4,3) and (100,4) not aligned
```

Kalau kena error ini, cetak `shape` kedua array dan cek angka tengahnya.

Satu lapis neural network sebenarnya cuma satu baris:

```python
keluaran = X @ W + b
```

## Dot product untuk vektor

Untuk dua vektor 1 dimensi, `@` menghasilkan satu angka:

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
a @ b        # 32   = 1*4 + 2*5 + 3*6
```

Angka ini mengukur seberapa "searah" dua vektor — dasar dari **cosine similarity**, cara mencari teks yang mirip di sistem AI.

## Menggabungkan array

```python
a = np.array([[1, 2]])
b = np.array([[3, 4]])

np.vstack([a, b])     # tumpuk ke bawah  -> (2, 2)
np.hstack([a, b])     # sambung ke samping -> (1, 4)
np.concatenate([a, b], axis=0)   # bentuk umumnya
```

`vstack` dipakai menambah baris data baru, `hstack` untuk menambah kolom fitur baru.

## Ringkasan

- `reshape` mengubah bentuk; `-1` berarti dihitung otomatis.
- `.T` menukar baris dan kolom.
- `*` per elemen, `@` perkalian matriks.
- Aturan bentuk: `(m, n) @ (n, p)` → `(m, p)`; angka tengah harus sama.
- `vstack` menambah baris, `hstack` menambah kolom.

## Kesalahan umum

- Memakai `*` padahal butuh `@`.
- Lupa `.T` sehingga angka tengahnya tidak cocok.
- Memberi array 1 dimensi ke scikit-learn tanpa `reshape(-1, 1)`.
