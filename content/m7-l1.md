## Dari array ke tabel berlabel

NumPy hebat untuk angka, tapi data nyata punya **nama kolom** dan tipe campur: nama (teks), umur (angka), aktif (boolean). Di situ **pandas** masuk.

Anggap pandas sebagai Excel yang dikendalikan lewat kode: baris, kolom, filter, dan pivot — tapi bisa diulang, diversikan, dan jalan untuk jutaan baris.

## Series — satu kolom

```python
import pandas as pd

s = pd.Series([80, 90, 70], index=['Budi', 'Ani', 'Citra'])
print(s)
```

```
Budi      80
Ani       90
Citra     70
dtype: int64
```

Series = array NumPy + **index** (label untuk tiap baris).

```python
s['Ani']        # 90
s.mean()        # 80.0
s[s > 75]       # Budi 80, Ani 90     -> boolean mask tetap jalan
```

## DataFrame — tabel utuh

```python
df = pd.DataFrame({
    'nama':  ['Budi', 'Ani', 'Citra'],
    'umur':  [20, 22, 21],
    'nilai': [80, 90, 70]
})
print(df)
```

```
    nama  umur  nilai
0   Budi    20     80
1    Ani    22     90
2  Citra    21     70
```

DataFrame = kumpulan Series yang berbagi index yang sama. Tiap kolom boleh beda tipe.

## Mengintip data

Empat perintah yang selalu dijalankan pertama kali saat bertemu data baru:

```python
df.head()        # 5 baris pertama
df.shape         # (3, 3)  -> (baris, kolom)
df.info()        # nama kolom, tipe, dan jumlah nilai yang terisi
df.describe()    # statistik kolom angka: count, mean, std, min, kuartil, max
```

`df.info()` yang paling penting — dari situ kamu langsung tahu kolom mana yang punya nilai kosong dan mana yang tipenya salah (angka terbaca sebagai teks).

Info tambahan:

```python
df.columns           # daftar nama kolom
df.dtypes            # tipe tiap kolom
df['nama'].unique()  # nilai unik
df['nama'].value_counts()   # frekuensi tiap nilai
```

`value_counts()` adalah cara tercepat mengecek apakah data labelmu seimbang — penting sebelum melatih model klasifikasi.

## Mengambil kolom

```python
df['nilai']              # Series
df[['nama', 'nilai']]    # DataFrame (perhatikan dua kurung siku)
```

Satu kurung → Series (1 kolom). Dua kurung → DataFrame (banyak kolom). Perbedaan ini sering bikin bingung tapi penting: scikit-learn butuh DataFrame 2 dimensi untuk fitur.

## Membuat kolom baru

```python
df['lulus'] = df['nilai'] >= 75
df['nilai_akhir'] = df['nilai'] * 0.6 + 40
```

Operasinya vektorisasi, persis NumPy — tidak perlu loop.

## Membaca file

```python
df = pd.read_csv('data.csv')
df = pd.read_excel('data.xlsx')
df = pd.read_json('data.json')

df.to_csv('hasil.csv', index=False)   # index=False supaya nomor baris tidak ikut
```

Satu baris untuk memuat data — inilah kenapa pandas selalu jadi langkah pertama proyek AI.

## Ringkasan

- Series = satu kolom berlabel, DataFrame = tabel berisi banyak Series.
- `head`, `shape`, `info`, `describe` adalah empat perintah pengintip wajib.
- `df['kolom']` menghasilkan Series, `df[['a','b']]` menghasilkan DataFrame.
- Kolom baru dibuat dengan operasi vektorisasi, bukan loop.

## Kesalahan umum

- Tertukar satu vs dua kurung siku saat memilih kolom.
- Langsung melatih model tanpa menjalankan `df.info()` lebih dulu.
- Lupa `index=False` saat menyimpan CSV sehingga muncul kolom tak bernama.
