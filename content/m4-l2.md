## Jangan biarkan siapa pun menyentuh saldo

Bayangin class rekening bank seperti ini:

```python
class Rekening:
    def __init__(self, saldo):
        self.saldo = saldo

r = Rekening(100)
r.saldo = 999999999      # 😱 siapa pun bisa mengubah seenaknya
r.saldo = -50            # bahkan jadi tidak masuk akal
```

**Encapsulation** artinya menyembunyikan data di dalam objek, dan hanya membuka pintu yang aman untuk mengaksesnya.

## Konvensi garis bawah

Python tidak punya kata kunci `private` seperti Java. Yang dipakai adalah kesepakatan:

```python
class Rekening:
    def __init__(self, saldo):
        self.pemilik = "Salsa"    # publik — bebas diakses
        self._saldo = saldo       # "jangan disentuh dari luar, ya"
        self.__pin = "1234"       # name mangling
```

- `_satu_garis` → sinyal ke sesama programmer: ini internal. Python tidak melarang.
- `__dua_garis` → Python mengubah namanya jadi `_Rekening__pin` (*name mangling*), jadi `r.__pin` error. Bukan enkripsi, tapi cukup mencegah ketidaksengajaan.

## `@property` — atribut yang sebenarnya method

Kita mau `r.saldo` tetap enak dibaca, tapi tidak bisa ditimpa sembarangan:

```python
class Rekening:
    def __init__(self, saldo=0):
        self._saldo = saldo

    @property
    def saldo(self):
        return self._saldo        # read-only

    def setor(self, jumlah):
        if jumlah <= 0:
            raise ValueError("Setoran harus positif")
        self._saldo += jumlah

    def tarik(self, jumlah):
        if jumlah > self._saldo:
            raise ValueError("Saldo tidak cukup")
        self._saldo -= jumlah

r = Rekening(100)
r.setor(50)
print(r.saldo)      # 150 — dipanggil tanpa kurung!
r.saldo = 999       # 💥 AttributeError: property has no setter
```

Perhatikan: `r.saldo` dipanggil **tanpa tanda kurung** walaupun isinya method. Itu gunanya `@property`.

## Setter dengan validasi

Kalau memang perlu bisa diubah, tapi dengan syarat:

```python
class Produk:
    def __init__(self, harga):
        self.harga = harga           # ini memanggil setter di bawah

    @property
    def harga(self):
        return self._harga

    @harga.setter
    def harga(self, nilai):
        if nilai < 0:
            raise ValueError("Harga tidak boleh negatif")
        self._harga = nilai

p = Produk(100)
p.harga = 200      # ✅ lewat validasi
p.harga = -5       # 💥 ValueError
```

Keuntungannya: kode pemakainya tetap terlihat sederhana (`p.harga = 200`), tapi aturannya tetap dijaga di dalam class.

## Kenapa ini penting buat QA?

Di automation testing kamu akan bikin class halaman (Page Object). Selector dan driver disimpan sebagai atribut internal (`self._driver`), sedangkan yang dibuka ke test cuma aksi bermakna seperti `login()` atau `pesan_error`. Test jadi bersih dan tidak bergantung pada detail internal.

## Ringkasan

- Encapsulation = data disembunyikan, akses lewat pintu yang terkontrol.
- `_x` adalah konvensi internal; `__x` memicu name mangling.
- `@property` membuat method bisa diakses seperti atribut (read-only).
- `@x.setter` menambahkan validasi saat nilai diubah.

## Kesalahan umum

- Mengira `__x` benar-benar private dan aman secara keamanan.
- Membuat getter/setter untuk semua atribut tanpa alasan — di Python, atribut publik biasa itu wajar.
- Lupa bahwa `@property` diakses tanpa tanda kurung.
