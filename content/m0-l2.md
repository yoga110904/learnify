## Tiga tempat kode Python dijalankan

Sebelum ngoding beneran, kamu perlu tahu "di mana" kode itu dijalankan.

### 1. REPL — buat coba-coba cepat

REPL singkatan dari *Read–Eval–Print Loop*: baca, evaluasi, cetak, ulangi. Ketik `python3` di terminal, lalu muncul prompt `>>>`:

```
>>> 2 + 3
5
>>> nama = "Salsa"
>>> print(nama)
Salsa
>>> len(nama)
5
>>> exit()
```

Perhatikan: di REPL, hasil ekspresi **otomatis tercetak** tanpa perlu `print()`. Di file `.py` tidak begitu — harus eksplisit `print()`.

```
>>> 2 + 3        # REPL: langsung kelihatan
5
```
```python
# file .py: tidak muncul apa-apa
2 + 3
print(2 + 3)     # baru muncul
```

REPL cocok untuk: mengecek cara kerja sebuah fungsi, menghitung cepat, atau menguji satu baris yang kamu ragu. Begitu ditutup, semuanya hilang.

### 2. File `.py` — buat program beneran

Bikin file `app.py`, isi:

```python
print("Halo dari file")
```

Lalu jalankan di terminal:

```
python3 app.py
```

Di Windows biasanya cukup `python app.py`. Kalau bingung yang mana, cek dulu:

```
python3 --version
python --version
```

Pakai yang menghasilkan `Python 3.x`.

### 3. Editor / IDE — tempat kerja sehari-hari

**VS Code** adalah pilihan paling umum dan gratis:

1. Install **Python 3** dari [python.org](https://www.python.org/downloads/) — centang **"Add Python to PATH"** waktu install di Windows. Ini langkah yang paling sering kelewat dan penyebab error `python: command not found`.
2. Install **VS Code**.
3. Di VS Code, buka tab Extensions (`Cmd/Ctrl + Shift + X`), install ekstensi **Python** dari Microsoft.
4. Buka folder proyek (`File → Open Folder`), bikin file `.py`, tekan tombol ▶️ di pojok kanan atas.

> Di kelas ini kamu nggak wajib install apa-apa dulu — editor di sebelah kanan sudah menjalankan Python asli langsung di browser.

## Struktur file Python yang rapi

Kode dibaca dari atas ke bawah. Urutan yang jadi kebiasaan baik:

```python
"""Program menghitung rata-rata nilai siswa."""   # docstring: penjelasan file

import math                                        # 1. import di paling atas

BATAS_LULUS = 70                                   # 2. konstanta (HURUF BESAR)


def rata_rata(nilai):                              # 3. definisi fungsi
    return sum(nilai) / len(nilai)


nilai_kelas = [80, 75, 90]                         # 4. kode utama
print(rata_rata(nilai_kelas))
```

Belum semua bagian itu kamu pahami sekarang — yang penting kamu kenal bentuknya, karena semua kode Python yang kamu baca nanti mengikuti pola ini.

## Komentar

Komentar adalah catatan buat manusia; Python mengabaikannya total.

```python
# ini komentar satu baris
harga = 15000   # komentar juga bisa di belakang kode

"""
Kalau butuh beberapa baris,
orang biasa pakai triple-quote seperti ini.
"""
print(harga)
```

Teknisnya, triple-quote itu bukan komentar melainkan **string yang tidak disimpan ke mana-mana** — tapi efeknya sama dan sudah jadi kebiasaan umum.

Gunakan komentar buat menjelaskan **kenapa**, bukan **apa**:

```python
# ❌ kurang berguna — kodenya sudah bilang begitu
x = x + 1   # tambah 1 ke x

# ✅ berguna — menjelaskan alasan
x = x + 1   # kompensasi index yang dimulai dari 0
```

Komentar yang menjelaskan "apa" biasanya tanda kodenya kurang jelas. Perbaiki namanya, bukan tambah komentarnya:

```python
# ❌
d = 30       # durasi dalam hari

# ✅
durasi_hari = 30
```

### Komentar untuk mematikan kode sementara

```python
print("A")
# print("B")     <- dimatikan sementara
print("C")
```

Pintasan di VS Code: pilih barisnya, tekan `Cmd + /` (Mac) atau `Ctrl + /` (Windows).

## Menjalankan kode di Learnify

Di lesson-lesson berikutnya kamu akan ketemu editor dengan dua tombol:

| Tombol | Fungsinya |

## Ringkasan

- REPL untuk eksperimen singkat (hasil otomatis tercetak), file `.py` untuk program sesungguhnya.
- Jalankan file dengan `python3 nama_file.py`.
- Struktur file yang rapi: docstring → import → konstanta → fungsi → kode utama.
- Komentar satu baris pakai `#`; jelaskan **kenapa**, bukan **apa**.
- Kode yang butuh komentar "apa" biasanya cuma butuh nama variabel yang lebih baik.

## Kesalahan umum

- Menjalankan file dengan `run app.py` (nggak ada perintah itu).
- Lupa `Add Python to PATH` di Windows, akibatnya `python` nggak dikenali terminal.
- Mengira kode di file `.py` akan otomatis mencetak hasil seperti di REPL.
- Menulis komentar yang cuma mengulang apa yang sudah jelas dari kodenya.
