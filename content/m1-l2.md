## Kalkulator bawaan Python

Python bisa langsung dipakai berhitung. Operator aritmatikanya mirip yang kamu pelajari di sekolah, plus tiga tambahan yang sering bikin bingung pemula.

```python
print(7 + 2)    # 9   tambah
print(7 - 2)    # 5   kurang
print(7 * 2)    # 14  kali
print(7 / 2)    # 3.5 bagi  -> hasilnya SELALU float
print(7 // 2)   # 3   bagi bulat (pembulatan ke bawah)
print(7 % 2)    # 1   sisa bagi (modulo)
print(7 ** 2)   # 49  pangkat
```

### `//` dan `%` itu kembar

Ingat pembagian jaman SD: 7 dibagi 2 = 3 sisa 1.

- `//` ngasih **hasil bagi**-nya → `3`
- `%` ngasih **sisanya** → `1`

`%` sangat sering dipakai buat ngecek ganjil/genap:

```python
print(10 % 2)   # 0  -> genap
print(11 % 2)   # 1  -> ganjil
```

## Operator perbandingan

Hasilnya selalu `bool` (`True`/`False`):

```python
print(5 == 5)    # True   sama dengan
print(5 != 3)    # True   tidak sama dengan
print(5 > 10)    # False
print(5 <= 5)    # True
```

⚠️ `=` (satu) buat **mengisi** variabel, `==` (dua) buat **membandingkan**. Ini salah satu typo paling sering.

## Operator logika

Buat menggabungkan beberapa kondisi:

| Operator | Kapan `True` | Analogi |
|---|---|---|
| `and` | semua kondisi benar | "harus bawa KTP **dan** tiket" |
| `or` | minimal satu benar | "bayar pakai cash **atau** QRIS" |
| `not` | membalik nilai | "**bukan** anggota" |

```python
umur = 20
punya_ktp = True

print(umur >= 17 and punya_ktp)   # True
print(umur < 17 or punya_ktp)     # True
print(not punya_ktp)              # False
print(True and not False)         # True
```

## Urutan operasi

Sama kayak matematika: **kurung → pangkat → kali/bagi → tambah/kurang**.

```python
print(2 + 3 * 4)      # 14, bukan 20
print((2 + 3) * 4)    # 20
print(2 ** 3 * 2)     # 16  (pangkat duluan)
```

Kalau ragu, **pakai kurung**. Kurung tambahan nggak pernah bikin kode lebih buruk.

## Operator gabungan

```python
skor = 10
skor += 5    # sama dengan: skor = skor + 5
skor -= 3
skor *= 2
print(skor)  # 24
```

## Sekilas tentang `def` dan `return`

Di latihan-latihan berikutnya kamu bakal sering diminta bikin **fungsi** — anggap saja "wadah jawaban" yang diuji otomatis:

```python
def luas_persegi(sisi):
    return sisi * sisi
```

`def` bikin fungsi, `return` mengembalikan hasil ke pemanggilnya. Perbedaan `return` dan `print` dibahas tuntas di Modul 2 — sekarang cukup ikuti polanya.

## Ringkasan

- `/` selalu menghasilkan float, `//` menghasilkan bilangan bulat.
- `%` memberi sisa bagi — andalan buat cek ganjil/genap dan kelipatan.
- Perbandingan menghasilkan `bool`; `=` ≠ `==`.
- `and`, `or`, `not` menggabungkan kondisi.

## Kesalahan umum

- Pakai `=` waktu maksudnya `==`.
- Kaget `10 / 2` menghasilkan `5.0` bukan `5`.
- Lupa urutan operasi, akhirnya salah hitung.
