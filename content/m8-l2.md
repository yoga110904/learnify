## Matriks = kumpulan vektor

Satu vektor mewakili satu data. Kalau punya 100 data, susun jadi **matriks**:

```python
import numpy as np

X = np.array([[165, 55],     # siswa 1
              [170, 65],     # siswa 2
              [158, 48]])    # siswa 3
X.shape        # (3, 2)  -> 3 sampel, 2 fitur
```

Konvensi di seluruh dunia machine learning: **baris = sampel, kolom = fitur**. Hafalkan ini, semua library mengikutinya.

## Perkalian matriks sebagai transformasi

Perkalian matriks bukan sekadar hitungan — dia **mengubah data dari satu ruang ke ruang lain**.

```python
X = np.array([[1., 2.]])        # 1 sampel, 2 fitur
W = np.array([[0.5, 0.0, 1.0],  # bobot: 2 fitur -> 3 keluaran
              [0.0, 1.0, 1.0]])

X @ W          # [[0.5, 2.0, 3.0]]   sekarang 3 angka
```

Kita baru saja mengubah data 2 dimensi jadi 3 dimensi. Itulah yang dilakukan **satu lapis neural network**: mengubah representasi data lewat perkalian matriks.

Aturan bentuk (dari lesson NumPy):

```
(n_sampel, n_fitur) @ (n_fitur, n_keluaran)  ->  (n_sampel, n_keluaran)
```

## Kenapa satu operasi, bukan loop?

Menghitung 3 neuron untuk 100 sampel = 300 perhitungan. Dengan loop Python itu lambat. Dengan satu perkalian matriks, semuanya selesai dalam satu panggilan ke kode C teroptimasi — dan di GPU, ribuan perhitungan ini benar-benar terjadi bersamaan.

Inilah alasan GPU penting untuk deep learning: GPU sangat jago mengalikan matriks besar.

## Matriks identitas

Versi matriks dari angka 1 — dikalikan dengan apa pun, hasilnya tidak berubah:

```python
I = np.eye(3)
A = np.array([[1., 2., 3.]])
A @ I          # [[1. 2. 3.]]  sama persis
```

## Transpose untuk mencocokkan bentuk

```python
A = np.array([[1, 2, 3]])     # (1, 3)
B = np.array([[4, 5, 6]])     # (1, 3)

A @ B          # 💥 error: 3 vs 1 tidak cocok
A @ B.T        # [[32]]  ✅
```

Kalau ketemu error "shapes not aligned", 80% solusinya adalah menambahkan `.T` di salah satu sisi.

## Inverse & sistem persamaan

Regresi linear punya solusi tertutup yang memakai invers matriks:

```python
A = np.array([[2., 1.],
              [1., 3.]])
b = np.array([5., 10.])

x = np.linalg.solve(A, b)      # cari x sehingga A @ x = b
print(x)                       # [1. 3.]
```

Gunakan `np.linalg.solve`, **bukan** `np.linalg.inv(A) @ b` — lebih cepat dan jauh lebih stabil secara numerik.

Tidak semua matriks punya invers. Kalau ada kolom yang merupakan kelipatan kolom lain (*singular*), sistemnya tidak punya solusi tunggal. Di data nyata, ini terjadi kalau dua fitur sebenarnya informasi yang sama.

## Norm matriks & jejak

```python
np.linalg.norm(A)      # ukuran keseluruhan matriks
np.trace(A)            # jumlah diagonal
np.linalg.det(A)       # determinan; 0 berarti singular
```

## Ringkasan

- Baris = sampel, kolom = fitur. Konvensi ini berlaku di semua library ML.
- Perkalian matriks mengubah data ke ruang representasi baru — inti neural network.
- `.T` menyelamatkan sebagian besar error "shapes not aligned".
- Pakai `np.linalg.solve`, bukan invers eksplisit.

## Kesalahan umum

- Menyusun data sebagai fitur × sampel (terbalik).
- Memakai `np.linalg.inv` padahal `solve` lebih stabil.
- Memaksa perkalian matriks pada data yang dimensinya memang tidak cocok.
