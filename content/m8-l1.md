## Semua data di AI adalah vektor

Sebuah foto, satu kalimat, satu pelanggan — semuanya diubah jadi deretan angka sebelum bisa diproses model.

```python
import numpy as np

# satu siswa: [tinggi, berat, umur]
siswa = np.array([165, 55, 21])
```

Deretan angka itu namanya **vektor**. Dimensi vektor = berapa angka yang dikandungnya. Embedding teks modern biasanya 768 atau 1536 dimensi — konsepnya tetap sama persis.

## Operasi dasar

```python
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

a + b        # [5 7 9]     gabung dua arah
a - b        # [-3 -3 -3]  selisih arah
3 * a        # [3 6 9]     panjangnya dikali 3, arah tetap
```

## Panjang vektor (norm)

Seberapa "besar" sebuah vektor? Pakai teorema Pythagoras yang diperluas:

$$\|a\| = \sqrt{a_1^2 + a_2^2 + \dots + a_n^2}$$

```python
a = np.array([3, 4])
np.linalg.norm(a)      # 5.0   karena akar(9 + 16) = 5
```

Ini disebut **L2 norm** (Euclidean). Ada juga L1 norm (jumlah nilai mutlak) yang dipakai di regularisasi Lasso:

```python
np.linalg.norm(a, ord=1)    # 7.0  = |3| + |4|
```

## Dot product

Sudah kita kenal di NumPy. Rumusnya:

$$a \cdot b = a_1b_1 + a_2b_2 + \dots + a_nb_n$$

```python
a @ b        # 32
```

Maknanya: **seberapa searah** dua vektor.

| Dot product | Artinya |
|---|---|
| besar positif | arahnya mirip |
| nol | tegak lurus, tidak berhubungan |
| negatif | arahnya berlawanan |

## Jarak Euclidean

Seberapa jauh dua titik data?

```python
a = np.array([1, 2])
b = np.array([4, 6])
np.linalg.norm(a - b)      # 5.0
```

Ini dasar algoritma **K-Nearest Neighbors**: cari data latih yang jaraknya paling dekat, lalu ikuti labelnya.

## Cosine similarity — jantung pencarian AI

Masalah dengan jarak Euclidean pada teks: dokumen panjang punya vektor besar, dokumen pendek punya vektor kecil. Padahal yang kita mau tahu adalah **kemiripan topik**, bukan panjangnya.

Solusinya: ukur **sudut** antar vektor, abaikan panjangnya.

$$\cos(\theta) = \frac{a \cdot b}{\|a\| \times \|b\|}$$

```python
def cosine_similarity(a, b):
    return (a @ b) / (np.linalg.norm(a) * np.linalg.norm(b))

a = np.array([1, 2, 3])
b = np.array([2, 4, 6])      # arah sama, cuma 2x lebih panjang
cosine_similarity(a, b)      # 1.0  -> identik secara arah
```

Rentang nilainya:

| Nilai | Artinya |
|---|---|
| 1 | arah identik — sangat mirip |
| 0 | tegak lurus — tidak berhubungan |
| −1 | berlawanan total |

Inilah cara kerja pencarian semantik, rekomendasi, dan RAG: ubah semua dokumen jadi vektor, ubah pertanyaan jadi vektor, lalu ambil dokumen dengan cosine similarity tertinggi.

⚠️ Hati-hati dengan vektor nol — normnya 0 dan pembagiannya jadi `NaN`. Selalu jaga penyebutnya.

## Ringkasan

- Semua data di AI direpresentasikan sebagai vektor angka.
- Norm mengukur panjang vektor; `np.linalg.norm`.
- Dot product mengukur seberapa searah dua vektor.
- Cosine similarity mengukur sudut saja, sehingga tahan terhadap perbedaan panjang.

## Kesalahan umum

- Memakai jarak Euclidean untuk teks padahal cosine lebih tepat.
- Lupa menangani vektor nol sehingga muncul pembagian nol.
- Mengira dot product besar selalu berarti mirip — panjang vektor ikut mempengaruhi.
