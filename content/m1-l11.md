## Teks di dunia nyata itu berantakan

Data yang kamu terima nanti — dari form, CSV, atau API — hampir tidak pernah rapi. Lesson ini kumpulan teknik membereskannya.

## Membersihkan secara menyeluruh

```python
kotor = "  Budi   SANTOSO \n"

bersih = kotor.strip()             # buang spasi & newline di ujung
bersih = " ".join(bersih.split())  # rapatkan spasi berlebih di tengah
bersih = bersih.title()            # Budi Santoso
print(repr(bersih))                # 'Budi Santoso'
```

Trik `" ".join(teks.split())` itu penting: `.strip()` hanya membersihkan **ujung**, sedangkan spasi ganda di tengah tetap ada. Memecah lalu menyatukan ulang membereskan keduanya sekaligus.

Selalu cek hasilnya dengan `repr()` — spasi tersembunyi tidak terlihat di `print()` biasa.

```python
print("  halo  ")        # terlihat seperti "halo"
print(repr("  halo  "))  # '  halo  '   <- kelihatan
```

## Menghapus karakter tertentu

```python
"Rp 1.250.000".replace("Rp", "").replace(".", "").strip()   # "1250000"
```

Untuk pembersihan berlapis, `str.translate` lebih efisien:

```python
hapus = str.maketrans("", "", "Rp. ")
print("Rp 1.250.000".translate(hapus))    # 1250000
```

Argumen ketiga `maketrans` adalah daftar karakter yang dibuang.

## Memeriksa isi karakter

```python
"123".isdigit()      # True
"12.5".isdigit()     # False  -> titik bukan digit
"-5".isdigit()       # False  -> minus bukan digit
"abc".isalpha()      # True
"abc 123".isalnum()  # False  -> spasi bukan alfanumerik
```

Karena `isdigit()` terbatas, fungsi pengecek angka yang lebih jujur biasanya begini:

```python
def bisa_jadi_angka(teks):
    try:
        float(teks)
        return True
    except ValueError:
        return False

print(bisa_jadi_angka("-3.5"))    # True
```

## Mengurai baris data

Pola yang akan kamu pakai berkali-kali saat membaca file:

```python
baris = "Budi, 20 , Bandung"
bagian = [b.strip() for b in baris.split(",")]
print(bagian)      # ['Budi', '20', 'Bandung']

nama, umur, kota = bagian
print(f"{nama} ({umur}) dari {kota}")
```

`.strip()` untuk tiap bagian itu wajib — data nyata hampir selalu punya spasi setelah koma.

Untuk data multi-baris:

```python
data = """Budi,80
Ani,92
Citra,75"""

for baris in data.strip().splitlines():
    nama, nilai = baris.split(",")
    print(f"{nama:<8}{int(nilai):>4}")
```

## `zfill` & padding

```python
"7".zfill(3)         # "007"
"-7".zfill(4)        # "-007"   tanda minus dipertahankan
"abc".ljust(6, ".")  # "abc..."
"abc".rjust(6, ".")  # "...abc"
"abc".center(7, "-") # "--abc--"
```

`zfill` berguna untuk nomor urut, kode invoice, dan nama file supaya terurut dengan benar:

```python
for i in range(1, 4):
    print(f"INV-{str(i).zfill(5)}")
# INV-00001
# INV-00002
# INV-00003
```

Tanpa padding, pengurutan teks akan menaruh "10" sebelum "2".

## Template dengan `str.format` dan `%`

f-string adalah pilihan utama, tapi kamu akan ketemu dua gaya lama ini di kode orang:

```python
nama, umur = "Budi", 20

print(f"Halo {nama}, umur {umur}")                # ✅ modern
print("Halo {}, umur {}".format(nama, umur))       # gaya lama
print("Halo {n}, umur {u}".format(n=nama, u=umur)) # dengan nama
print("Halo %s, umur %d" % (nama, umur))           # gaya paling lama
```

`str.format` masih berguna kalau template-nya disimpan terpisah dari datanya:

```python
TEMPLATE = "Halo {nama}, tagihanmu {total:,}"
print(TEMPLATE.format(nama="Budi", total=1250000))
```

f-string tidak bisa begitu karena dia dievaluasi saat ditulis, bukan saat dipakai.

## Teks multi-baris rapi

```python
pesan = """
Halo Budi,

Tagihanmu bulan ini Rp1.250.000.
Terima kasih.
"""
print(pesan.strip())
```

Kalau indentasi kode ikut terbawa, `textwrap.dedent` membereskannya:

```python
from textwrap import dedent

def buat_pesan(nama):
    return dedent(f"""
        Halo {nama},
        Selamat datang.
    """).strip()
```

## Karakter non-ASCII

Python 3 menangani Unicode dengan baik, tapi ada beberapa hal yang perlu disadari:

```python
teks = "café"
print(len(teks))          # 4
print(teks.upper())       # CAFÉ
print("Ä".lower())        # ä
```

Yang sering jadi masalah justru saat membaca file — selalu sebutkan encoding-nya:

```python
open("data.txt", encoding="utf-8")
```

Tanpa itu, di Windows file berbahasa Indonesia bisa terbaca rusak.

## Ringkasan

- `.strip()` membersihkan ujung; `" ".join(teks.split())` merapatkan spasi di tengah.
- Selalu cek hasil pembersihan dengan `repr()` untuk melihat spasi tersembunyi.
- `.isdigit()` terbatas — untuk angka desimal/negatif pakai `try: float(...)`.
- `zfill` dan `ljust`/`rjust`/`center` untuk padding dan tabel rapi.
- `str.format` masih berguna kalau template-nya disimpan terpisah dari data.

## Kesalahan umum

- Mengira `.strip()` juga merapikan spasi di tengah.
- Memakai `.isdigit()` untuk memvalidasi angka desimal atau negatif.
- Lupa `.strip()` tiap bagian setelah `.split(",")`.
- Membaca file tanpa `encoding="utf-8"` sehingga karakter non-ASCII rusak.
