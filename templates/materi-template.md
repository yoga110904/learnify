## Mulai dari masalah sehari-hari

Buka dengan analogi atau masalah nyata sebelum menyebut sintaks apa pun.
Contoh: *"Bayangin kamu nyuruh adik bikin mie instan..."*

## Konsep pertama

Penjelasan singkat dalam 1–3 kalimat, lalu langsung contoh kode:

```python
nama = "Salsa"
print(f"Halo {nama}")
```

Output:

```
Halo Salsa
```

## Konsep kedua

Kalau ada perbandingan, pakai tabel:

| Penulisan | Hasil |
|---|---|
| `7 // 2` | `3` |
| `7 % 2` | `1` |

> Blockquote dipakai untuk catatan sampingan atau peringatan.

## Ringkasan

- Poin penting pertama
- Poin penting kedua
- Poin penting ketiga

## Kesalahan umum

- Kesalahan yang sering dilakukan pemula
- Kesalahan lain beserta cara menghindarinya
