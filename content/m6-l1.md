## List Python itu lambat untuk angka

Coba jumlahkan dua daftar berisi sejuta angka:

```python
a = list(range(1_000_000))
b = list(range(1_000_000))
c = [a[i] + b[i] for i in range(len(a))]   # ± 80 ms
```

Dengan **NumPy**:

```python
import numpy as np

a = np.arange(1_000_000)
b = np.arange(1_000_000)
c = a + b                                   # ± 2 ms
```

40× lebih cepat, dan kodenya lebih pendek. Ini alasan **semua** library AI — pandas, scikit-learn, PyTorch, TensorFlow — dibangun di atas NumPy.

## Kenapa bisa secepat itu?

List Python menyimpan **pointer** ke objek yang berserakan di memori, dan tiap objek punya tipe sendiri. NumPy menyimpan angka mentah **berdampingan dalam satu blok memori**, semuanya bertipe sama.

Akibatnya:

- CPU bisa memproses banyak angka sekaligus (instruksi SIMD)
- Loop-nya dijalankan di C, bukan di Python
- Hemat memori: 1 juta `int64` = 8 MB di NumPy, tapi ±36 MB kalau jadi list

## Membuat array

```python
import numpy as np

np.array([1, 2, 3])            # dari list
np.zeros(5)                    # [0. 0. 0. 0. 0.]
np.ones((2, 3))                # matriks 2×3 berisi 1
np.full(3, 7)                  # [7 7 7]
np.arange(0, 10, 2)            # [0 2 4 6 8]
np.linspace(0, 1, 5)           # [0.   0.25 0.5  0.75 1.  ]
np.eye(3)                      # matriks identitas 3×3
```

Untuk data acak (sering dipakai menginisialisasi bobot model):

```python
rng = np.random.default_rng(42)   # seed supaya hasilnya bisa diulang
rng.random(3)                     # 3 angka acak 0–1
rng.normal(0, 1, 3)               # distribusi normal
```

## Tiga atribut yang wajib dicek

```python
x = np.array([[1, 2, 3],
              [4, 5, 6]])

print(x.shape)   # (2, 3)   -> 2 baris, 3 kolom
print(x.ndim)    # 2        -> jumlah dimensi
print(x.dtype)   # int64    -> tipe isinya
print(x.size)    # 6        -> total elemen
```

**`shape` adalah hal pertama yang kamu cek setiap kali error.** 90% bug di kode AI berasal dari bentuk array yang tidak cocok.

Istilah dimensinya:

| ndim | Nama | Contoh di AI |
|---|---|---|
| 0 | skalar | nilai loss |
| 1 | vektor | satu baris data / embedding |
| 2 | matriks | tabel data (baris × fitur) |
| 3+ | tensor | batch gambar, batch teks |

## Semua elemen harus satu tipe

```python
np.array([1, 2, 3.5])        # dtype float64 — int ikut jadi float
np.array([1, 2, "a"])        # dtype <U21  — semua jadi string!
```

Kalau dtype-nya berubah jadi string tanpa kamu sadari, semua operasi matematika bakal gagal. Cek `dtype` kalau hasilnya aneh.

Konversi tipe:

```python
x = np.array([1.7, 2.9])
x.astype(int)      # [1 2]  — dipotong, bukan dibulatkan
```

## Ringkasan

- NumPy menyimpan angka dalam satu blok memori bertipe seragam → jauh lebih cepat dari list.
- Semua library AI dibangun di atas NumPy.
- `shape`, `ndim`, `dtype` adalah tiga hal pertama yang dicek saat debugging.
- `np.arange`, `np.zeros`, `np.linspace`, dan `default_rng` untuk membuat array.

## Kesalahan umum

- Tetap memakai loop Python padahal ada operasi NumPy-nya.
- Lupa mengecek `shape` sehingga bingung saat operasi gagal.
- Mencampur angka dan string dalam satu array tanpa sadar.
