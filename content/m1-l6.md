## Males nulis berulang? Pakai loop

Kalau harus nyetak "Halo" 100 kali, nggak mungkin kita copy-paste 100 baris. Di situ gunanya **perulangan**.

## `for` — kalau jumlah putarannya diketahui

```python
for i in range(3):
    print("Halo", i)
```

```
Halo 0
Halo 1
Halo 2
```

`range()` bikin deret angka:

| Penulisan | Menghasilkan |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 5)` | 1, 2, 3, 4 |
| `range(1, 10, 2)` | 1, 3, 5, 7, 9 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 |

Ingat: **angka akhir tidak ikut** (eksklusif). `range(1, 5)` berhenti di 4.

`for` juga bisa jalan di atas data apa pun yang bisa diurut:

```python
for buah in ["apel", "jeruk", "mangga"]:
    print(buah)

for huruf in "abc":
    print(huruf)
```

Butuh nomor urut sekaligus isinya? Pakai `enumerate`:

```python
for i, buah in enumerate(["apel", "jeruk"], start=1):
    print(i, buah)      # 1 apel / 2 jeruk
```

## `while` — kalau berhentinya tergantung kondisi

```python
sisa = 3
while sisa > 0:
    print("sisa:", sisa)
    sisa -= 1
print("habis")
```

⚠️ **Infinite loop**: kalau kondisinya nggak pernah jadi `False`, program nggak akan berhenti.

```python
sisa = 3
while sisa > 0:
    print("sisa:", sisa)   # lupa sisa -= 1  -> loop selamanya
```

Pastikan ada sesuatu di dalam loop yang mengubah kondisinya.

## `break` dan `continue`

- `break` = keluar dari loop sekarang juga.
- `continue` = lewati sisa baris, lanjut ke putaran berikutnya.

```python
for i in range(1, 8):
    if i == 5:
        break
    if i % 2 == 0:
        continue
    print(i)
# 1 3
```

## Loop bersarang

Loop di dalam loop. Loop dalam selesai penuh untuk **setiap** putaran loop luar.

```python
for i in range(1, 4):
    baris = ""
    for j in range(1, 4):
        baris += f"{i*j:3}"
    print(baris)
```

```
  1  2  3
  2  4  6
  3  6  9
```

## Pola paling sering dipakai: akumulator

Siapkan wadah sebelum loop, isi di dalam loop:

```python
total = 0
for n in [10, 20, 30]:
    total += n
print(total)     # 60

hasil = []
for n in range(5):
    hasil.append(n * n)
print(hasil)     # [0, 1, 4, 9, 16]
```

## Ringkasan

- `for` untuk jumlah putaran yang diketahui, `while` untuk kondisi.
- `range(a, b)` berhenti sebelum `b`.
- `break` keluar dari loop, `continue` lompat ke putaran berikutnya.
- Pola akumulator: siapkan wadah di luar loop, isi di dalam loop.

## Kesalahan umum

- Mengira `range(1, 5)` menghasilkan 1–5.
- `while` tanpa perubahan kondisi → program hang.
- Menaruh `return`/`print` hasil akhir di **dalam** loop padahal maunya setelah loop selesai.
