## Gaya functional: data mengalir lewat fungsi

Pola "ubah tiap elemen" dan "saring elemen" begitu umum sampai Python menyediakan fungsinya.

## `map` — ubah semua elemen

```python
angka = [1, 2, 3]
print(list(map(lambda x: x * 2, angka)))    # [2, 4, 6]
print(list(map(str, angka)))                # ['1', '2', '3']
```

## `filter` — saring elemen

```python
angka = [1, 2, 3, 4]
print(list(filter(lambda x: x % 2 == 0, angka)))   # [2, 4]
```

Keduanya menghasilkan iterator (lazy), jadi dibungkus `list()` kalau mau dilihat isinya.

> Di Python, comprehension biasanya **lebih disukai** daripada `map`/`filter` karena lebih mudah dibaca:
> ```python
> [x * 2 for x in angka]              # vs map
> [x for x in angka if x % 2 == 0]    # vs filter
> ```
> Tapi `map(str, angka)` tanpa lambda tetap enak dibaca. Dan kamu tetap harus mengenalinya saat membaca kode orang.

## `reduce` — meringkas jadi satu nilai

```python
from functools import reduce

reduce(lambda a, b: a + b, [1, 2, 3, 4])       # 10
reduce(lambda a, b: a * b, [1, 2, 3, 4])       # 24
reduce(lambda a, b: a + b, [], 0)              # 0  <- nilai awal
```

Cara kerjanya menumpuk dua-dua: `((1+2)+3)+4`. Untuk penjumlahan, `sum()` lebih jelas — `reduce` dipakai saat operasinya tidak punya fungsi bawaan.

## `itertools` — perkakas iterator

```python
from itertools import chain, combinations, groupby, count, cycle, islice
```

### `chain` — sambung beberapa iterable

```python
list(chain([1, 2], [3], [4]))     # [1, 2, 3, 4]
```

### `combinations` dan `permutations`

```python
list(combinations([1, 2, 3], 2))    # [(1,2), (1,3), (2,3)]  urutan tak penting
list(permutations([1, 2], 2))       # [(1,2), (2,1)]         urutan penting
```

Cocok untuk membuat pasangan data test.

### `groupby` — mengelompokkan

⚠️ Data harus **diurutkan dulu** berdasarkan kunci yang sama:

```python
from itertools import groupby

data = [("a", 1), ("b", 2), ("a", 3)]
data.sort(key=lambda x: x[0])          # WAJIB

for kunci, grup in groupby(data, key=lambda x: x[0]):
    print(kunci, [g[1] for g in grup])
# a [1, 3]
# b [2]
```

Kalau lupa mengurutkan, satu kelompok bisa muncul berkali-kali.

### Iterator tak terbatas

```python
list(islice(count(10), 3))       # [10, 11, 12]
list(islice(cycle("ab"), 5))     # ['a','b','a','b','a']
```

`count` dan `cycle` tidak pernah habis — selalu batasi dengan `islice` atau `break`.

## Contoh gabungan

```python
from itertools import combinations

def semua_pasangan(data):
    return list(combinations(data, 2))

print(semua_pasangan([1, 2, 3]))   # [(1, 2), (1, 3), (2, 3)]
```

## Ringkasan

- `map` mengubah, `filter` menyaring, `reduce` meringkas.
- Comprehension biasanya lebih terbaca daripada map/filter.
- `combinations`/`permutations` membuat kombinasi data.
- `groupby` butuh data yang sudah terurut lebih dulu.

## Kesalahan umum

- Lupa membungkus `map`/`filter` dengan `list()` lalu heran hasilnya objek aneh.
- Memakai `groupby` pada data yang belum diurutkan.
- Melakukan `list()` pada `count()` atau `cycle()` — program langsung hang.
